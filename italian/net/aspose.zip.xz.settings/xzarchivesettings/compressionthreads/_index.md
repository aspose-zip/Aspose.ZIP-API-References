## XzArchiveSettings.CompressionThreads property

Restituisce o imposta il numero di thread di compressione. Se il valore è maggiore di 1, verrà utilizzata la compressione multithread.

```csharp
public int CompressionThreads { get; set; }
```

### Eccezioni

| eccezione | condizione |
| --- | --- |
| ArgumentOutOfRangeException | Il numero di thread è superiore a 100. |

## Osservazioni

Non impostare questo numero più dei core della CPU.
