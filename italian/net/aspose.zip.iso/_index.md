Lo spazio dei nomi Iso contiene classi che rappresentano entità correlate a ISO.

## Classi

| Classe | Descrizione |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Argomenti dell'evento per eventi correlati alle voci. |
| [EventsBag](./eventsbag/) | Contenitore di eventi utilizzato durante il salvataggio di [`IsoArchive`](../aspose.zip.iso/isoarchive/). |
| [IsoArchive](./isoarchive/) | Rappresenta un archivio ISO (ISO 9660). |
| [IsoEntry](./isoentry/) | Rappresenta una voce (file o directory) all'interno di un archivio ISO. |
| [IsoLoadOptions](./isoloadoptions/) | Opzioni con cui [`IsoArchive`](../aspose.zip.iso/isoarchive/) viene caricato da un file compresso. Contiene l'evento sollevato durante l'estrazione. |
| [IsoSaveOptions](./isosaveoptions/) | Opzioni per salvare un archivio ISO. |
