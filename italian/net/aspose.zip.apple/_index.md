Lo spazio dei nomi Apple contiene classi che rappresentano entità correlate ad Apple Archive.

## Classi

| Classe | Descrizione |
| --- | --- |
| [AppleArchive](./applearchive/) | Questa classe rappresenta un file Apple Archive (.aar). Usala per creare file Apple Archive. |
| [AppleArchiveEntry](./applearchiveentry/) | Rappresenta una voce del filesystem all'interno di un [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | Impostazioni utilizzate per comporre le voci all'interno di [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | Opzioni con cui [`AppleArchive`](../aspose.zip.apple/applearchive/) viene caricato da un file compresso. |
| [AppleCompressionSettings](./applecompressionsettings/) | Impostazioni necessarie per la compressione delle voci di Apple Archive. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Impostazioni per la compressione LZ4 all'interno di un file Apple Archive (.aar). |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Impostazioni per la compressione LZFSE all'interno di un file Apple Archive (.aar). |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Impostazioni per la compressione LZMA all'interno di un file Apple Archive (.aar). |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Impostazioni per la modalità store (senza compressione) all'interno di un file Apple Archive (.aar). |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Impostazioni per la compressione Zlib all'interno di un file Apple Archive (.aar). |
