## SevenZipLZMACompressionSettings.NumberOfFastBytes property

Ottiene il numero di byte usati per la ricerca di corrispondenze rapide nell'algoritmo LZMA.

```csharp
public int NumberOfFastBytes { get; }
```

## Osservazioni

Un valore più alto consente al compressore di cercare corrispondenze più lunghe, il che può migliorare leggermente il rapporto di compressione ma rallenta la compressione.
