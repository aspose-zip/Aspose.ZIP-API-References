## LzmaCompressionSettings.DictionarySize property

La dimensione del dizionario (buffer della cronologia) indica quanti byte dei dati non compressi elaborati di recente sono conservati in memoria.

```csharp
public int DictionarySize { get; }
```

## Osservazioni

Più grande è il dizionario, di solito migliore è il rapporto di compressione - ma i dizionari più grandi dei dati non compressi sono uno spreco di RAM.
