
### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Always | `0` | Il Data Descriptor è sempre presente per tutte le voci zip. |
| ForAllFileEntries | `1` | Il Data Descriptor è presente solo per le voci con dati file; omesso per le directory. L'uso di questa opzione è sconsigliato. |
