Lo spazio dei nomi Alz contiene classi che rappresentano entità correlate ad ALZ.

## Classi

| Classe | Descrizione |
| --- | --- |
| [AlzArchive](./alzarchive/) | Questa classe rappresenta un file di archivio ALZ. Usala per estrarre archivi alz. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Opzioni con cui l'archivio ALZ viene caricato da un file compresso. |
| [AlzEntry](./alzentry/) | Rappresenta una voce di file in un archivio ALZ con tutti i suoi metadati. |
| [AlzEntryEncrypted](./alzentryencrypted/) | Voce ALZ che deve essere decrittata prima della decompressione. |
| [AlzEntryPlain](./alzentryplain/) | Voce ALZ che deve essere decompressa senza decrittazione. |
