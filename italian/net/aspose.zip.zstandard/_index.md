Lo spazio dei nomi Zstandard contiene classi per la manipolazione di dati compressi Zstandard.

## Classi

| Classe | Descrizione |
| --- | --- |
| [ZstandardArchive](./zstandardarchive/) | Questa classe rappresenta un file di archivio Zstandard. Usala per creare archivi Zstandard. |
| [ZstandardLoadOptions](./zstandardloadoptions/) | Opzioni con cui [`ZstandardArchive`](../aspose.zip.zstandard/zstandardarchive/) è caricato da un file compresso. Contiene l'evento sollevato durante l'estrazione. |
| [ZstandardSaveOptions](./zstandardsaveoptions/) | Impostazioni per l'archivio ZStandard. |
