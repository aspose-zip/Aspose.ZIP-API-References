Lo spazio dei nomi Egg contiene classi che rappresentano entità correlate a EGG.

## Classi

| Classe | Descrizione |
| --- | --- |
| [EggArchive](./eggarchive/) | Questa classe rappresenta un file di archivio EGG. Usala per estrarre archivi EGG. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Opzioni con cui un archivio EGG viene caricato da un file compresso. |
| [EggEntry](./eggentry/) | Rappresenta una voce di file in un archivio EGG con tutti i suoi metadati. |
| [EggEntryPlain](./eggentryplain/) | Voce EGG che può essere decompressa senza decrittazione. |
