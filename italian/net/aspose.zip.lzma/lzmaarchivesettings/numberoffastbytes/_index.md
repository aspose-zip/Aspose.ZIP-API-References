## LzmaArchiveSettings.NumberOfFastBytes property

Ottiene o imposta il numero di byte utilizzati per la ricerca rapida di corrispondenze nell'algoritmo LZMA.

```csharp
public int NumberOfFastBytes { get; set; }
```

## Osservazioni

Un valore più alto consente al compressore di cercare corrispondenze più lunghe, il che può migliorare leggermente il rapporto di compressione ma rallenta la compressione.
