## LzmaArchiveSettings.LiteralContextBits property

Ottiene o imposta il numero di bit di contesto letterale.

```csharp
public int LiteralContextBits { get; set; }
```

## Osservazioni

I bit di contesto letterale definiscono quanti dei bit più significativi del byte non compresso precedente vengono utilizzati per prevedere i bit del byte letterale successivo. Deve essere compreso tra 0 e 8.
