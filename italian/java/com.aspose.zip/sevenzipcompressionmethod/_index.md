Metodi di compressione supportati dal formato 7z.
## Campi

| Campo | Descrizione |
| --- | --- |
| [AES](#AES) | Il file è crittografato. |
| [Arm](#Arm) | Tecnica che migliora la compressione del codice macchina ARM a 32 bit. |
| [Arm64](#Arm64) | Tecnica che migliora la compressione del codice macchina ARM64. |
| [BCJ](#BCJ) | Tecnica che migliora la compressione del codice macchina. |
| [BCJ2](#BCJ2) | Tecnica che migliora la compressione del codice macchina x86 usando flussi ausiliari. |
| [BZip2](#BZip2) | Il file è compresso usando Bzip2. |
| [Deflate](#Deflate) | Il file è compresso usando Deflate. |
| [Deflate64](#Deflate64) | Il file è compresso usando Deflate64(tm). |
| [Delta](#Delta) | Il file è codificato usando il convertitore Delta. |
| [LZMA](#LZMA) | Il file è compresso usando LZMA. |
| [LZMA2](#LZMA2) | Il file è compresso usando LZMA2. |
| [PPMd](#PPMd) | Il file è compresso usando PPMd. |
| [Store](#Store) | Il file è archiviato (nessuna compressione). |
| [Swap2](#Swap2) | Tecnica che migliora la compressione scambiando coppie di byte. |
| [Swap4](#Swap4) | Tecnica che migliora la compressione invertendo gruppi di quattro byte. |
