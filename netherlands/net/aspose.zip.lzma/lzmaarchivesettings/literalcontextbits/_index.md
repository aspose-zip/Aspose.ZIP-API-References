## LzmaArchiveSettings.LiteralContextBits property

Haalt op of stelt het aantal letterlijke contextbits in.

```csharp
public int LiteralContextBits { get; set; }
```

## Opmerkingen

Letterlijke contextbits bepalen hoeveel van de meest significante bits van de vorige ongecomprimeerde byte worden gebruikt om de bits van de volgende letterlijke byte te voorspellen. Moet tussen 0 en 8 liggen.
