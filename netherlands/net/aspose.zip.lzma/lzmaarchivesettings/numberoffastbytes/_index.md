## LzmaArchiveSettings.NumberOfFastBytes property

Haalt op of stelt het aantal bytes in dat wordt gebruikt voor snelle overeenkomst‑zoekopdrachten in het LZMA‑algoritme.

```csharp
public int NumberOfFastBytes { get; set; }
```

## Opmerkingen

Naar een hogere waarde stelt de compressor in staat om langere overeenkomsten te zoeken, wat de compressieverhouding enigszins kan verbeteren maar de compressie vertraagt.
