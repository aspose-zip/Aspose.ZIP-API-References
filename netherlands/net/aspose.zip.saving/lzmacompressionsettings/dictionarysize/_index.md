## LzmaCompressionSettings.DictionarySize property

De grootte van het woordenboek (geschiedenisbuffer) geeft aan hoeveel bytes van de recent verwerkte ongecomprimeerde gegevens in het geheugen worden bewaard.

```csharp
public int DictionarySize { get; }
```

## Opmerkingen

Hoe groter het woordenboek, hoe beter de compressieverhouding meestal is - maar woordenboeken die groter zijn dan de ongecomprimeerde gegevens zijn een verspilling van RAM.
