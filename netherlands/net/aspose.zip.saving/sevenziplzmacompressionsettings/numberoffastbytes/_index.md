## SevenZipLZMACompressionSettings.NumberOfFastBytes property

Haalt het aantal bytes op dat wordt gebruikt voor snel overeenkomst zoeken in het LZMA-algoritme.

```csharp
public int NumberOfFastBytes { get; }
```

## Opmerkingen

Naar een hogere waarde stelt de compressor in staat om langere overeenkomsten te zoeken, wat de compressieverhouding enigszins kan verbeteren maar de compressie vertraagt.
