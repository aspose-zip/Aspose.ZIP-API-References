De Alz-namespace bevat klassen die ALZ-gerelateerde entiteiten vertegenwoordigen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [AlzArchive](./alzarchive/) | Deze klasse vertegenwoordigt een ALZ-archiefbestand. Gebruik deze om alz-archieven te extraheren. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Opties waarmee een ALZ-archief wordt geladen vanuit een gecomprimeerd bestand. |
| [AlzEntry](./alzentry/) | Vertegenwoordigt een bestandsitem in een ALZ-archief met al zijn metadata. |
| [AlzEntryEncrypted](./alzentryencrypted/) | ALZ-item dat moet worden ontsleuteld vóór decompressie. |
| [AlzEntryPlain](./alzentryplain/) | ALZ-item dat moet worden gedecomprimeerd zonder ontsleuteling. |
