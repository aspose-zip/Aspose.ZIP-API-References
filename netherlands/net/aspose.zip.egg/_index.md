De Egg-namespace bevat klassen die EGG-gerelateerde entiteiten vertegenwoordigen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [EggArchive](./eggarchive/) | Deze klasse vertegenwoordigt een EGG-archiefbestand. Gebruik deze om EGG-archieven te extraheren. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Opties waarmee een EGG-archief wordt geladen vanuit een gecomprimeerd bestand. |
| [EggEntry](./eggentry/) | Vertegenwoordigt een bestandsitem in een EGG-archief met al zijn metadata. |
| [EggEntryPlain](./eggentryplain/) | EGG-item dat kan worden gedecomprimeerd zonder ontsleuteling. |
