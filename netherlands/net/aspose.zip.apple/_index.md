De Apple-namespace bevat klassen die Apple Archive-gerelateerde entiteiten vertegenwoordigen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [AppleArchive](./applearchive/) | Deze klasse vertegenwoordigt een Apple Archive (.aar)-bestand. Gebruik het om Apple Archive-bestanden samen te stellen. |
| [AppleArchiveEntry](./applearchiveentry/) | Vertegenwoordigt een bestandssysteemitem binnen een [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | Instellingen die worden gebruikt om items samen te stellen binnen [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | Opties waarmee [`AppleArchive`](../aspose.zip.apple/applearchive/) wordt geladen vanuit een gecomprimeerd bestand. |
| [AppleCompressionSettings](./applecompressionsettings/) | Instellingen die nodig zijn voor compressie van Apple Archive-items. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Instellingen voor LZ4-compressie binnen een Apple Archive (.aar)-bestand. |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Instellingen voor LZFSE-compressie binnen een Apple Archive (.aar)-bestand. |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Instellingen voor LZMA-compressie binnen een Apple Archive (.aar)-bestand. |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Instellingen voor opslag (geen compressie) binnen een Apple Archive (.aar)-bestand. |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Instellingen voor Zlib-compressie binnen een Apple Archive (.aar)-bestand. |
