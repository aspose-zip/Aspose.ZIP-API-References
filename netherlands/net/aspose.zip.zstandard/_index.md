De Zstandard-namespace bevat klassen voor het manipuleren van Zstandard-gecomprimeerde gegevens.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ZstandardArchive](./zstandardarchive/) | Deze klasse vertegenwoordigt een Zstandard-archiefbestand. Gebruik het om Zstandard-archieven samen te stellen. |
| [ZstandardLoadOptions](./zstandardloadoptions/) | Opties waarmee [`ZstandardArchive`](../aspose.zip.zstandard/zstandardarchive/) wordt geladen vanuit een gecomprimeerd bestand. Bevat een gebeurtenis die wordt opgehaald bij extractie. |
| [ZstandardSaveOptions](./zstandardsaveoptions/) | Instellingen voor ZStandard-archief. |
