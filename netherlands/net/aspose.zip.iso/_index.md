De Iso-namespace bevat klassen die ISO-gerelateerde entiteiten vertegenwoordigen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Evenementargumenten voor entry-gerelateerde gebeurtenissen. |
| [EventsBag](./eventsbag/) | Evenementencontainer gebruikt bij het opslaan van [`IsoArchive`](../aspose.zip.iso/isoarchive/). |
| [IsoArchive](./isoarchive/) | Stelt een ISO-archief (ISO 9660) voor. |
| [IsoEntry](./isoentry/) | Stelt een entry (bestand of map) binnen een ISO-archief voor. |
| [IsoLoadOptions](./isoloadoptions/) | Opties waarmee [`IsoArchive`](../aspose.zip.iso/isoarchive/) wordt geladen vanuit een gecomprimeerd bestand. Bevat een gebeurtenis die wordt geactiveerd bij extractie. |
| [IsoSaveOptions](./isosaveoptions/) | Opties voor het opslaan van een ISO-archief. |
