Το χώρο ονομάτων Settings περιέχει κλάσεις που αντιπροσωπεύουν τις ρυθμίσεις του αρχείου xz.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [XzArchiveSettings](./xzarchivesettings/) | Η κλάση περιέχει ένα σύνολο ρυθμίσεων για συγκεκριμένο αρχείο xz. |
| [XzBcjX86FilterSettings](./xzbcjx86filtersettings/) | Ρυθμίσεις για το φίλτρο xz Bcj X86. |
| [XzFilterSettings](./xzfiltersettings/) | Βασική κλάση για ένα σύνολο ρυθμίσεων του συγκεκριμένου φίλτρου μορφής xz. |
| [XzLoadOptions](./xzloadoptions/) | Επιλογές για τη φόρτωση του [`XzArchive`](../aspose.zip.xz/xzarchive/). |
| [XzLZMA2FilterSettings](./xzlzma2filtersettings/) | Σύνολο ρυθμίσεων για το φίλτρο xz LZMA2. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [XzCheckType](./xzchecktype/) | Η απαρίθμηση ορίζει την προσέγγιση υπολογισμού αθροίσματος ελέγχου για αρχεία xz. |
