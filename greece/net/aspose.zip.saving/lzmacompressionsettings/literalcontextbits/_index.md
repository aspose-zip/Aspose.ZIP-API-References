## LzmaCompressionSettings.LiteralContextBits property

Επιστρέφει τον αριθμό των κυριολεκτικών bits περιβάλλοντος.

```csharp
public int LiteralContextBits { get; }
```

## Παρατηρήσεις

Τα Literal Context Bits ορίζουν πόσα από τα πιο σημαντικά bits του προηγούμενου ασυμπίεστου byte χρησιμοποιούνται για την πρόβλεψη των bits του επόμενου κυριολεκτικού byte. Πρέπει να είναι από 0 έως 8.
