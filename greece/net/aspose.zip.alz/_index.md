Ο χώρος ονομάτων Alz περιέχει κλάσεις που αντιπροσωπεύουν οντότητες σχετικές με ALZ.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [AlzArchive](./alzarchive/) | Αυτή η κλάση αντιπροσωπεύει ένα αρχείο αρχειοθήκης ALZ. Χρησιμοποιήστε την για την εξαγωγή αρχείων alz. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Επιλογές με τις οποίες η αρχειοθήκη ALZ φορτώνεται από ένα συμπιεσμένο αρχείο. |
| [AlzEntry](./alzentry/) | Αντιπροσωπεύει μια καταχώρηση αρχείου σε μια αρχειοθήκη ALZ με όλα τα μεταδεδομένα της. |
| [AlzEntryEncrypted](./alzentryencrypted/) | Καταχώρηση ALZ που πρέπει να αποκρυπτογραφηθεί πριν από την αποσυμπίεση. |
| [AlzEntryPlain](./alzentryplain/) | Καταχώρηση ALZ που πρέπει να αποσυμπιεστεί χωρίς αποκρυπτογράφηση. |
