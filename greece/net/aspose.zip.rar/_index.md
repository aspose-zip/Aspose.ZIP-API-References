Ο χώρος ονομάτων Rar περιέχει κλάσεις που αντιπροσωπεύουν οντότητες σχετικές με αρχείο RAR.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [RarArchive](./rararchive/) | Αυτή η κλάση αντιπροσωπεύει ένα αρχείο RAR. Χρησιμοποιήστε την για την εξαγωγή αρχείων RAR. |
| [RarArchiveEntry](./rararchiveentry/) | Αναπαριστά ένα μοναδικό αρχείο μέσα σε ένα αρχείο. |
| [RarArchiveEntryEncrypted](./rararchiveentryencrypted/) | Καταχώρηση Zip που χρειάζεται να αποσυμπιεστεί με αποκρυπτογράφηση. |
| [RarArchiveEntryPlain](./rararchiveentryplain/) | Καταχώρηση Rar που χρειάζεται να αποσυμπιεστεί χωρίς αποκρυπτογράφηση. |
| [RarArchiveLoadOptions](./rararchiveloadoptions/) | Επιλογές με τις οποίες το [`RarArchive`](../aspose.zip.rar/rararchive/) φορτώνεται από ένα συμπιεσμένο αρχείο. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [RarDictionaryStorageMode](./rardictionarystoragemode/) | Καθορίζει πώς αποθηκεύεται το λεξικό αποσυμπίεσης RAR. |
