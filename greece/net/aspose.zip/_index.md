Ο χώρος ονομάτων Zip περιέχει κλάσεις που αντιπροσωπεύουν το αρχείο ZIP και κοινές οντότητες σχετικές με αρχεία.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Archive](./archive/) | Αυτή η κλάση αναπαριστά ένα αρχείο zip. Χρησιμοποιήστε την για σύνθεση, εξαγωγή ή ενημέρωση αρχείων zip. |
| [ArchiveEntry](./archiveentry/) | Αναπαριστά ένα μοναδικό αρχείο μέσα σε ένα αρχείο. |
| [ArchiveEntryEncrypted](./archiveentryencrypted/) | Καταχώρηση Zip που πρέπει να συμπιεστεί με κρυπτογράφηση ή να αποσυμπιεστεί με αποκρυπτογράφηση. |
| [ArchiveEntryPlain](./archiveentryplain/) | Καταχώρηση Zip που πρέπει να συμπιεστεί χωρίς κρυπτογράφηση ή να αποσυμπιεστεί χωρίς αποκρυπτογράφηση. |
| [ArchiveFactory](./archivefactory/) | Ανιχνεύει τη μορφή του αρχείου και δημιουργεί το κατάλληλο αντικείμενο [`IArchive`](../aspose.zip/iarchive/) σύμφωνα με τον τύπο του αρχείου. |
| [ArchiveLoadOptions](./archiveloadoptions/) | Επιλογές με τις οποίες το αρχείο ZIP φορτώνεται από συμπιεσμένο αρχείο. |
| [CancelEntryEventArgs](./cancelentryeventargs/) | Παράμετροι συμβάντος για ακυρώσιμα συμβάντα σχετιζόμενα με καταχωρήσεις. |
| [ComHelper](./comhelper/) | Παρέχει μεθόδους για πελάτες COM ώστε να φορτώνουν αρχεία στο Aspose.Zip. |
| [EntryEventArgs](./entryeventargs/) | Παράμετροι συμβάντος για συμβάντα σχετιζόμενα με καταχωρήσεις. |
| [License](./license/) | Παρέχει μεθόδους για την άδεια του στοιχείου. |
| [MeteredLicense](./meteredlicense/) | Παρέχει μεθόδους για τον ορισμό κλειδιού μέτρησης. |
| [ProgressCancelEventArgs](./progresscanceleventargs/) | Κλάση για ακυρώσιμα δεδομένα συμβάντος που περιέχει τον αριθμό των επεξεργασμένων byte. |
| [ProgressEventArgs](./progresseventargs/) | Κλάση για δεδομένα συμβάντος που περιέχει τον αριθμό των επεξεργασμένων byte. |
## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IArchive](./iarchive/) | Αυτή η διεπαφή αναπαριστά ένα αρχείο. |
| [IArchiveFileEntry](./iarchivefileentry/) | Αυτή η διεπαφή αναπαριστά μια καταχώρηση αρχείου. |
