Το χώρο ονομάτων Wim περιέχει κλάσεις που αντιπροσωπεύουν οντότητες σχετικές με το αρχείο WIM.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [WimArchive](./wimarchive/) | Αυτή η κλάση αντιπροσωπεύει ένα αρχείο αρχειοθήκης wim. |
| [WimDirectoryEntry](./wimdirectoryentry/) | Αντιπροσωπεύει έναν μοναδικό φάκελο μέσα στην αρχειοθήκη wim. |
| [WimEntry](./wimentry/) | Αντιπροσωπεύει ένα μοναδικό αρχείο ή φάκελο μέσα στην εικόνα wim. |
| [WimFileEntry](./wimfileentry/) | Αντιπροσωπεύει ένα μοναδικό αρχείο μέσα στην αρχειοθήκη wim. |
| [WimImage](./wimimage/) | Αντιπροσωπεύει μια μοναδική εικόνα μέσα στην αρχειοθήκη wim. |
| [WimLoadOptions](./wimloadoptions/) | Επιλογές με τις οποίες το αρχείο φορτώνεται από ένα συμπιεσμένο αρχείο. |
