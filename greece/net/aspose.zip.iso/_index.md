Ο χώρος ονομάτων Iso περιέχει κλάσεις που αντιπροσωπεύουν οντότητες σχετικές με ISO.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Παράμετροι συμβάντος για συμβάντα σχετιζόμενα με καταχωρήσεις. |
| [EventsBag](./eventsbag/) | Κοντέινερ συμβάντων που χρησιμοποιείται κατά την αποθήκευση του [`IsoArchive`](../aspose.zip.iso/isoarchive/). |
| [IsoArchive](./isoarchive/) | Αναπαριστά ένα αρχείο ISO (ISO 9660). |
| [IsoEntry](./isoentry/) | Αναπαριστά μια καταχώρηση (αρχείο ή φάκελο) μέσα σε ένα αρχείο ISO. |
| [IsoLoadOptions](./isoloadoptions/) | Επιλογές με τις οποίες το [`IsoArchive`](../aspose.zip.iso/isoarchive/) φορτώνεται από συμπιεσμένο αρχείο. Περιέχει το συμβάν που ενεργοποιείται κατά την εξαγωγή. |
| [IsoSaveOptions](./isosaveoptions/) | Επιλογές για την αποθήκευση ενός αρχείου ISO. |
