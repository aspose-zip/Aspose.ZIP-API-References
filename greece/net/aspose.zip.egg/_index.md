Ο χώρος ονομάτων Egg περιέχει κλάσεις που αντιπροσωπεύουν οντότητες σχετικές με EGG.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [EggArchive](./eggarchive/) | Αυτή η κλάση αντιπροσωπεύει ένα αρχείο EGG. Χρησιμοποιήστε την για να εξάγετε αρχεία EGG. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Επιλογές με τις οποίες ένα αρχείο EGG φορτώνεται από συμπιεσμένο αρχείο. |
| [EggEntry](./eggentry/) | Αντιπροσωπεύει μια καταχώρηση αρχείου σε ένα αρχείο EGG με όλα τα μεταδεδομένα του. |
| [EggEntryPlain](./eggentryplain/) | Καταχώρηση EGG που μπορεί να αποσυμπιεστεί χωρίς αποκρυπτογράφηση. |
