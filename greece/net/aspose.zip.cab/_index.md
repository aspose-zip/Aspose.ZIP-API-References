Ο χώρος ονομάτων Cab περιέχει κλάσεις που αντιπροσωπεύουν οντότητες σχετικές με αρχείο Cab.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [CabArchive](./cabarchive/) | Αυτή η κλάση αντιπροσωπεύει ένα αρχείο CAB. |
| [CabCompressionSettings](./cabcompressionsettings/) | Ρυθμίσεις που απαιτούνται για τη λειτουργία του συμπιεστή CAB. |
| [CabEntry](./cabentry/) | Αντιπροσωπεύει ένα μεμονωμένο αρχείο μέσα σε αρχείο CAB. |
| [CabEntrySettings](./cabentrysettings/) | Ρυθμίσεις που ελέγχουν πώς γράφεται μια καταχώρηση CAB. |
| [CabLoadOptions](./cabloadoptions/) | Επιλογές με τις οποίες το αρχείο φορτώνεται από ένα συμπιεσμένο αρχείο. |
| [CabMsZipCompressionSettings](./cabmszipcompressionsettings/) | Ρυθμίσεις συμπίεσης που κωδικοποιούν τα μπλοκ δεδομένων CAB χρησιμοποιώντας τη συμπίεση MSZip (deflate). |
| [CabSaveOptions](./cabsaveoptions/) | Επιλογές για την αποθήκευση ενός αρχείου CAB. |
| [CabStoreCompressionSettings](./cabstorecompressionsettings/) | Ρυθμίσεις συμπίεσης που διατηρούν τα μπλοκ δεδομένων CAB ασυμπίεστα. |
