Ο χώρος ονομάτων Apple περιέχει κλάσεις που αντιπροσωπεύουν οντότητες σχετικές με Apple Archive.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [AppleArchive](./applearchive/) | Αυτή η κλάση αντιπροσωπεύει ένα αρχείο Apple Archive (.aar). Χρησιμοποιήστε την για τη δημιουργία αρχείων Apple Archive. |
| [AppleArchiveEntry](./applearchiveentry/) | Αντιπροσωπεύει μια καταχώρηση συστήματος αρχείων μέσα σε ένα [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | Ρυθμίσεις που χρησιμοποιούνται για τη δημιουργία καταχωρήσεων μέσα στο [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | Επιλογές με τις οποίες το [`AppleArchive`](../aspose.zip.apple/applearchive/) φορτώνεται από ένα συμπιεσμένο αρχείο. |
| [AppleCompressionSettings](./applecompressionsettings/) | Ρυθμίσεις που απαιτούνται για τη συμπίεση καταχώρησης Apple Archive. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Ρυθμίσεις για τη συμπίεση LZ4 μέσα σε ένα αρχείο Apple Archive (.aar). |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Ρυθμίσεις για τη συμπίεση LZFSE μέσα σε ένα αρχείο Apple Archive (.aar). |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Ρυθμίσεις για τη συμπίεση LZMA μέσα σε ένα αρχείο Apple Archive (.aar). |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Ρυθμίσεις για αποθήκευση (χωρίς συμπίεση) μέσα σε ένα αρχείο Apple Archive (.aar). |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Ρυθμίσεις για τη συμπίεση Zlib μέσα σε ένα αρχείο Apple Archive (.aar). |
