## AppleArchive.IsSolid property

Επιστρέφει μια τιμή που υποδεικνύει εάν το αρχείο χρησιμοποιεί συμπαγή συμπίεση. Σε συμπαγή λειτουργία, όλα τα δεδομένα των καταχωρίσεων συμπιέζονται ως μια ενιαία ροή και η εξαγωγή μεμονωμένων καταχωρίσεων δεν είναι διαθέσιμη. Χρησιμοποιήστε το [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/) αντί αυτού.

```csharp
public bool IsSolid { get; }
```
