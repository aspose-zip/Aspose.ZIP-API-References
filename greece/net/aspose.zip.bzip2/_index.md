Ο χώρος ονομάτων Bzip2 περιέχει κλάσεις που αντιπροσωπεύουν οντότητες σχετικές με αρχείο bzip2.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Bzip2Archive](./bzip2archive/) | Αυτή η κλάση αντιπροσωπεύει ένα αρχείο bzip2. Χρησιμοποιήστε την για τη δημιουργία ή την εξαγωγή αρχείων bzip2. |
| [Bzip2LoadOptions](./bzip2loadoptions/) | Επιλογές για τη φόρτωση του [`Bzip2Archive`](../aspose.zip.bzip2/bzip2archive/). Περιέχει γεγονός που ενεργοποιείται κατά την εξαγωγή. |
| [Bzip2SaveOptions](./bzip2saveoptions/) | Επιλογές για την αποθήκευση ενός αρχείου bzip2. |
