Iso 네임스페이스는 ISO와 관련된 엔터티를 나타내는 클래스를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | 엔트리 관련 이벤트에 대한 이벤트 인수입니다. |
| [EventsBag](./eventsbag/) | [`IsoArchive`](../aspose.zip.iso/isoarchive/) 저장에 사용되는 이벤트 컨테이너입니다. |
| [IsoArchive](./isoarchive/) | ISO 아카이브 (ISO 9660)를 나타냅니다. |
| [IsoEntry](./isoentry/) | ISO 아카이브 내의 엔트리(파일 또는 디렉터리)를 나타냅니다. |
| [IsoLoadOptions](./isoloadoptions/) | 압축 파일에서 [`IsoArchive`](../aspose.zip.iso/isoarchive/)를 로드할 때 사용하는 옵션입니다. 추출 시 발생하는 이벤트를 포함합니다. |
| [IsoSaveOptions](./isosaveoptions/) | ISO 아카이브를 저장하기 위한 옵션입니다. |
