Apple 네임스페이스에는 Apple Archive 관련 엔터티를 나타내는 클래스가 포함되어 있습니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [AppleArchive](./applearchive/) | 이 클래스는 Apple Archive (.aar) 파일을 나타냅니다. 이를 사용하여 Apple Archive 파일을 구성할 수 있습니다. |
| [AppleArchiveEntry](./applearchiveentry/) | [`AppleArchive`](../aspose.zip.apple/applearchive/) 내의 파일 시스템 항목을 나타냅니다. |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | [`AppleArchive`](../aspose.zip.apple/applearchive/) 내부에 항목을 구성하는 데 사용되는 설정입니다. |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | 압축 파일에서 [`AppleArchive`](../aspose.zip.apple/applearchive/)를 로드할 때 사용되는 옵션입니다. |
| [AppleCompressionSettings](./applecompressionsettings/) | Apple Archive 항목 압축에 필요한 설정입니다. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Apple Archive (.aar) 파일 내 LZ4 압축을 위한 설정입니다. |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Apple Archive (.aar) 파일 내 LZFSE 압축을 위한 설정입니다. |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Apple Archive (.aar) 파일 내 LZMA 압축을 위한 설정입니다. |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Apple Archive (.aar) 파일 내 저장(압축 없음) 설정입니다. |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Apple Archive (.aar) 파일 내 Zlib 압축을 위한 설정입니다. |
