Alz 네임스페이스에는 ALZ 관련 엔터티를 나타내는 클래스가 포함되어 있습니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [AlzArchive](./alzarchive/) | 이 클래스는 ALZ 아카이브 파일을 나타냅니다. 이를 사용하여 alz 아카이브를 추출하십시오. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | 압축 파일에서 ALZ 아카이브를 로드할 때 사용되는 옵션입니다. |
| [AlzEntry](./alzentry/) | ALZ 아카이브 내 파일 항목을 모든 메타데이터와 함께 나타냅니다. |
| [AlzEntryEncrypted](./alzentryencrypted/) | 압축 해제 전에 복호화가 필요한 ALZ 항목입니다. |
| [AlzEntryPlain](./alzentryplain/) | 복호화 없이 압축 해제해야 하는 ALZ 항목입니다. |
