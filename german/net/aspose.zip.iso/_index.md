Der Iso-Namespace enthält Klassen, die ISO-bezogene Entitäten repräsentieren.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Ereignisargumente für eintragsbezogene Ereignisse. |
| [EventsBag](./eventsbag/) | Ereigniscontainer, der beim Speichern von [`IsoArchive`](../aspose.zip.iso/isoarchive/) verwendet wird. |
| [IsoArchive](./isoarchive/) | Stellt ein ISO-Archiv (ISO 9660) dar. |
| [IsoEntry](./isoentry/) | Stellt einen Eintrag (Datei oder Verzeichnis) innerhalb eines ISO-Archivs dar. |
| [IsoLoadOptions](./isoloadoptions/) | Optionen, mit denen [`IsoArchive`](../aspose.zip.iso/isoarchive/) aus einer komprimierten Datei geladen wird. Enthält das beim Extrahieren ausgelöste Ereignis. |
| [IsoSaveOptions](./isosaveoptions/) | Optionen zum Speichern eines ISO-Archivs. |
