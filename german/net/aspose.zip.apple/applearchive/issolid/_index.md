## AppleArchive.IsSolid property

Gibt einen Wert zurück, der angibt, ob das Archiv solide Kompression verwendet. Im Solid-Modus werden alle Eintragsdaten als ein einziger Stream komprimiert und die einzelne Eintrags-Extraktion ist nicht verfügbar. Verwenden Sie stattdessen [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/).

public bool IsSolid { get; }
