Der Apple-Namespace enthält Klassen, die Apple-Archive-bezogene Entitäten darstellen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [AppleArchive](./applearchive/) | Diese Klasse repräsentiert eine Apple Archive (.aar)-Datei. Verwenden Sie sie zum Erstellen von Apple Archive-Dateien. |
| [AppleArchiveEntry](./applearchiveentry/) | Stellt einen Dateisystemeintrag innerhalb eines [`AppleArchive`](../aspose.zip.apple/applearchive/) dar. |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | Einstellungen, die zum Erstellen von Einträgen innerhalb von [`AppleArchive`](../aspose.zip.apple/applearchive/) verwendet werden. |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | Optionen, mit denen [`AppleArchive`](../aspose.zip.apple/applearchive/) aus einer komprimierten Datei geladen wird. |
| [AppleCompressionSettings](./applecompressionsettings/) | Einstellungen, die für die Komprimierung von Apple-Archive-Einträgen benötigt werden. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Einstellungen für die LZ4-Kompression innerhalb einer Apple-Archive-(.aar)-Datei. |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Einstellungen für die LZFSE-Kompression innerhalb einer Apple-Archive-(.aar)-Datei. |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Einstellungen für die LZMA-Kompression innerhalb einer Apple-Archive-(.aar)-Datei. |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Einstellungen für die Speicherung (keine Kompression) innerhalb einer Apple-Archive-(.aar)-Datei. |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Einstellungen für die Zlib-Kompression innerhalb einer Apple-Archive-(.aar)-Datei. |
