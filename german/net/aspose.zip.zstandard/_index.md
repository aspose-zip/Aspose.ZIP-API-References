Der Zstandard-Namespace enthält Klassen zur Manipulation von Zstandard-komprimierten Daten.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ZstandardArchive](./zstandardarchive/) | Diese Klasse repräsentiert eine Zstandard-Archivdatei. Verwenden Sie sie zum Erstellen von Zstandard-Archiven. |
| [ZstandardLoadOptions](./zstandardloadoptions/) | Optionen, mit denen [`ZstandardArchive`](../aspose.zip.zstandard/zstandardarchive/) aus einer komprimierten Datei geladen wird. Enthält Ereignis, das bei der Extraktion ausgelöst wird. |
| [ZstandardSaveOptions](./zstandardsaveoptions/) | Einstellungen für das ZStandard-Archiv. |
