Der Alz-Namespace enthält Klassen, die ALZ-bezogene Entitäten repräsentieren.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [AlzArchive](./alzarchive/) | Diese Klasse repräsentiert eine ALZ-Archivdatei. Verwenden Sie sie, um ALZ-Archive zu extrahieren. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Optionen, mit denen das ALZ-Archiv aus einer komprimierten Datei geladen wird. |
| [AlzEntry](./alzentry/) | Stellt einen Dateieintrag in einem ALZ-Archiv mit allen Metadaten dar. |
| [AlzEntryEncrypted](./alzentryencrypted/) | ALZ-Eintrag, der vor der Dekompression entschlüsselt werden muss. |
| [AlzEntryPlain](./alzentryplain/) | ALZ-Eintrag, der ohne Entschlüsselung dekomprimiert werden muss. |
