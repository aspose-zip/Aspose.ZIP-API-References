Der Egg-Namespace enthält Klassen, die EGG-bezogene Entitäten repräsentieren.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [EggArchive](./eggarchive/) | Diese Klasse repräsentiert eine EGG-Archivdatei. Verwenden Sie sie, um EGG-Archive zu extrahieren. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Optionen, mit denen ein EGG-Archiv aus einer komprimierten Datei geladen wird. |
| [EggEntry](./eggentry/) | Stellt einen Dateieintrag in einem EGG-Archiv mit allen Metadaten dar. |
| [EggEntryPlain](./eggentryplain/) | EGG-Eintrag, der ohne Entschlüsselung dekomprimiert werden kann. |
