## ZipDataDescriptorPolicy enumeration

Optionen für das Vorhandensein des Data Descriptor.

```csharp
public enum ZipDataDescriptorPolicy : byte
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Always | `0` | Data Descriptor ist für alle Zip-Einträge immer vorhanden. |
| ForAllFileEntries | `1` | Data Descriptor ist nur für Einträge mit Dateidaten vorhanden; für Verzeichnisse wird er weggelassen. Die Verwendung dieser Option wird nicht empfohlen. |
