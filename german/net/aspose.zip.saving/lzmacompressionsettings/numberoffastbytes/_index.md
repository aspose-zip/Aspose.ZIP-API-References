## LzmaCompressionSettings.NumberOfFastBytes property

Gibt die Anzahl der Bytes zurück, die für die schnelle Übereinstimmungssuche im LZMA-Algorithmus verwendet werden.

```csharp
public int NumberOfFastBytes { get; }
```

## Hinweise

Ein höherer Wert ermöglicht es dem Kompressor, längere Übereinstimmungen zu suchen, was das Kompressionsverhältnis leicht verbessern kann, aber die Kompression verlangsamt.
