## LzmaCompressionSettings.DictionarySize property

Die Größe des Wörterbuchs (Verlaufs‑Puffer) gibt an, wie viele Bytes der zuletzt verarbeiteten unkomprimierten Daten im Speicher gehalten werden.

```csharp
public int DictionarySize { get; }
```

## Hinweise

Je größer das Wörterbuch, desto besser ist in der Regel das Kompressionsverhältnis – aber Wörterbücher, die größer als die unkomprimierten Daten sind, verschwenden RAM.
