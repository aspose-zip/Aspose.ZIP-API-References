## LzmaCompressionSettings.LiteralContextBits property

Gibt die Anzahl der Literal-Kontextbits zurück.

```csharp
public int LiteralContextBits { get; }
```

## Hinweise

Literal-Kontextbits definieren, wie viele der höchstwertigen Bits des vorherigen unkomprimierten Bytes verwendet werden, um die Bits des nächsten Literal-Bytes vorherzusagen. Der Wert muss zwischen 0 und 8 liegen.
