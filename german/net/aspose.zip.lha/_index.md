Der Lha-Namespace enthält Klassen, die Lha-bezogene Entitäten darstellen.

## Klassen

| --- | --- |
| [LhaArchive](./lhaarchive/) | Diese Klasse repräsentiert eine LHA (.lzh)-Archivdatei. |
| [LhaArchiveEntry](./lhaarchiveentry/) | Stellt eine einzelne Datei innerhalb eines Lha-Archivs dar. |
| [LhaLoadOptions](./lhaloadoptions/) | Optionen, mit denen das Archiv aus einer komprimierten Datei geladen wird. |
