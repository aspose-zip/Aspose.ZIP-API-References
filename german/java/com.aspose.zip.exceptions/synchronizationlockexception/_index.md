Die Ausnahme, die ausgelöst wird, wenn eine Methode verlangt, dass der Aufrufer die Sperre auf einem gegebenen Monitor besitzt, und die Methode von einem Aufrufer aufgerufen wird, der diese Sperre nicht besitzt.
