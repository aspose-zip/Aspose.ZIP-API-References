Alz 命名空间包含表示 ALZ 相关实体的类。

## 类

| 类 | 描述 |
| --- | --- |
| [AlzArchive](./alzarchive/) | 此类表示 ALZ 存档文件。使用它来提取 alz 存档。 |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | 用于从压缩文件加载 ALZ 存档的选项。 |
| [AlzEntry](./alzentry/) | 表示 ALZ 存档中包含所有元数据的文件条目。 |
| [AlzEntryEncrypted](./alzentryencrypted/) | 在解压缩之前需要解密的 ALZ 条目。 |
| [AlzEntryPlain](./alzentryplain/) | 需要在不解密的情况下解压缩的 ALZ 条目。 |
