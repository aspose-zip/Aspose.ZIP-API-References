Iso 命名空间包含表示 ISO 相关实体的类。

## 类

| 类 | 描述 |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | 用于条目相关事件的事件参数。 |
| [EventsBag](./eventsbag/) | 用于保存 [`IsoArchive`](../aspose.zip.iso/isoarchive/) 时的事件容器。 |
| [IsoArchive](./isoarchive/) | 表示 ISO 存档 (ISO 9660)。 |
| [IsoEntry](./isoentry/) | 表示 ISO 存档中的条目（文件或目录）。 |
| [IsoLoadOptions](./isoloadoptions/) | 用于从压缩文件加载 [`IsoArchive`](../aspose.zip.iso/isoarchive/) 的选项。包含提取时触发的事件。 |
| [IsoSaveOptions](./isosaveoptions/) | 保存 ISO 存档的选项。 |
