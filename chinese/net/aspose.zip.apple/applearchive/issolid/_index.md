## AppleArchive.IsSolid property

获取一个值，指示存档是否使用固实压缩。在固实模式下，所有条目数据被压缩为单一流，无法单独提取条目。请改用 [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/)。

public bool IsSolid { get; }
