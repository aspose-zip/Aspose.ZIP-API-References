Apple 命名空间包含表示 Apple Archive 相关实体的类。

## 类

| 类 | 描述 |
| --- | --- |
| [AppleArchive](./applearchive/) | 此类表示 Apple Archive（.aar）文件。可用于创建 Apple Archive 文件。 |
| [AppleArchiveEntry](./applearchiveentry/) | 表示 [`AppleArchive`](../aspose.zip.apple/applearchive/) 中的文件系统条目。 |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | 用于在 [`AppleArchive`](../aspose.zip.apple/applearchive/) 中组成条目的设置。 |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | 用于从压缩文件加载 [`AppleArchive`](../aspose.zip.apple/applearchive/) 的选项。 |
| [AppleCompressionSettings](./applecompressionsettings/) | Apple Archive 条目压缩所需的设置。 |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Apple Archive (.aar) 文件中 LZ4 压缩的设置。 |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Apple Archive (.aar) 文件中 LZFSE 压缩的设置。 |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Apple Archive (.aar) 文件中 LZMA 压缩的设置。 |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Apple Archive (.aar) 文件中存储（无压缩）的设置。 |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Apple Archive (.aar) 文件中 Zlib 压缩的设置。 |
