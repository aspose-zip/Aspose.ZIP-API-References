## LzmaCompressionSettings.DictionarySize property

字典（历史缓冲区）大小表示最近处理的未压缩数据在内存中保留的字节数。

```csharp
public int DictionarySize { get; }
```

## 备注

字典越大，通常压缩率越好——但字典大于未压缩数据会浪费 RAM。
