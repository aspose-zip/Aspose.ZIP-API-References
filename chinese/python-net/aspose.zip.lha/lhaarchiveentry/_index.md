## LhaArchiveEntry class

表示 Lha 存档中的单个文件。

LhaArchiveEntry 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取条目的名称。 |
| length | 获取条目的字节长度。 |
| is_directory | 获取一个值，指示此条目是否为目录。 |
| last_modified | 获取条目的最后修改时间。 |
| modification_time | 获取条目的最后修改时间。 |
| path | 获取条目的完整路径。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| extract(path) | 按路径将 Lha 存档条目提取到文件系统。 |
| extract(destination) | 将条目提取到提供的流中。 |
| extract(file_info) | 将 Lha 存档条目提取到文件。 |
