## ArjEntryPlain class

表示 ARJ 存档中的单个文件。

ArjEntryPlain 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取存档中条目的名称。 |
| compressed_size | 获取压缩文件的大小。 |
| uncompressed_size | 获取原始文件的大小。 |
| length | 获取条目的字节长度。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| extract(path) | 将条目提取到提供的路径对应的文件系统中。 |
| extract(file_info) | 将 ARJ 存档条目提取到文件。 |
| extract(destination) | 将条目提取到提供的流中。 |
