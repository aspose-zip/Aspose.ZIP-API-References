包含表示 Cab 存档相关实体的类。

## 类
| 类 | 描述 |
| :- | :- |
| [CabArchive](/zip/python-net/aspose.zip.cab/cabarchive/) | 此类表示 CAB 存档文件。 |
| [CabCompressionSettings](/zip/python-net/aspose.zip.cab/cabcompressionsettings/) | CAB 压缩器工作所需的设置。 |
| [CabEntry](/zip/python-net/aspose.zip.cab/cabentry/) | 表示 CAB 存档中的单个文件。 |
| [CabEntrySettings](/zip/python-net/aspose.zip.cab/cabentrysettings/) | 控制 CAB 条目写入方式的设置。 |
| [CabLoadOptions](/zip/python-net/aspose.zip.cab/cabloadoptions/) | 从压缩文件加载存档的选项。 |
| [CabMsZipCompressionSettings](/zip/python-net/aspose.zip.cab/cabmszipcompressionsettings/) | 使用 MSZip（deflate）压缩对 CAB 数据块进行编码的压缩设置。 |
| [CabSaveOptions](/zip/python-net/aspose.zip.cab/cabsaveoptions/) | 保存 CAB 存档的选项。 |
| [CabStoreCompressionSettings](/zip/python-net/aspose.zip.cab/cabstorecompressionsettings/) | 保持 CAB 数据块未压缩的压缩设置。 |
