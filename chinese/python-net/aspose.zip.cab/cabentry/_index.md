## CabEntry class

表示 CAB 存档中的单个文件。

CabEntry 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取存档中条目的名称。 |
| length | 获取条目的字节长度。 |
| modification_time | 获取最后修改的日期和时间。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| extract(path) | 将条目提取到提供的路径对应的文件系统中。 |
| extract(destination) | 将条目提取到提供的流中。 |
| open() | 打开条目以进行提取，并提供包含条目内容的流。 |
