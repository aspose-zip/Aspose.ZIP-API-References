## TarEntry class

表示 tar 存档中的单个文件。

TarEntry 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取或设置存档中条目的名称。 |
| length | 获取条目的字节长度。 |
| uncompressed_size | 获取原始文件的大小。 |
| is_directory | 获取一个值，指示该条目是否表示目录。 |
| modification_time | 获取文件或目录的修改时间。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| extract(path) | 将条目提取到提供的路径对应的文件系统中。 |
| extract(destination) | 将条目提取到提供的流中。 |
| open() | 打开条目以进行提取，并提供包含条目内容的流。 |
