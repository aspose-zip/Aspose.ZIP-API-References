## WimImage class

表示 wim 存档中的单个镜像。

WimImage 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| root_directory | 获取映像的根目录条目。 |
| all_entries | 递归获取构成映像的 [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) 类型的条目。 |
| parent | 获取映像所属的存档。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| get_entry(path) | 获取给定路径的 [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) 类型的条目。 |
| extract_to_directory(destination_directory) | 将映像中的所有文件提取到提供的目录。 |
