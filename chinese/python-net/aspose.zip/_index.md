包含表示 zip 存档和常见存档相关实体的类。

## 类
| 类 | 描述 |
| :- | :- |
| [Archive](/zip/python-net/aspose.zip/archive/) | 此类表示 zip 存档文件。可用于创建、提取或更新 zip 存档。 |
| [ArchiveEntry](/zip/python-net/aspose.zip/archiveentry/) | 表示存档中的单个文件。 |
| [ArchiveEntryEncrypted](/zip/python-net/aspose.zip/archiveentryencrypted/) | 需要使用加密进行压缩或使用解密进行解压的 Zip 条目。 |
| [ArchiveEntryPlain](/zip/python-net/aspose.zip/archiveentryplain/) | 需要在不使用加密的情况下压缩或在不使用解密的情况下解压的 Zip 条目。 |
| [ArchiveFactory](/zip/python-net/aspose.zip/archivefactory/) | 检测存档格式并根据存档类型创建相应的 [IArchive](/zip/python-net/aspose.zip/iarchive/) 对象。 |
| [ArchiveLoadOptions](/zip/python-net/aspose.zip/archiveloadoptions/) | 用于从压缩文件加载 ZIP 存档的选项。 |
| [CancelEntryEventArgs](/zip/python-net/aspose.zip/cancelentryeventargs/) | 可取消的条目相关事件的事件参数。 |
| [ComHelper](/zip/python-net/aspose.zip/comhelper/) | 为 COM 客户端提供将存档加载到 Aspose.Zip 的方法。 |
| [EntryEventArgs](/zip/python-net/aspose.zip/entryeventargs/) | 与条目相关事件的事件参数。 |
| [IArchive](/zip/python-net/aspose.zip/iarchive/) | 此接口表示一个存档。 |
| [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) | 此接口表示存档文件条目。 |
| [License](/zip/python-net/aspose.zip/license/) | 提供对组件进行授权的方法。 |
| [MeteredLicense](/zip/python-net/aspose.zip/meteredlicense/) | 提供设置计量密钥的方法。 |
| [ProgressCancelEventArgs](/zip/python-net/aspose.zip/progresscanceleventargs/) | 用于包含已处理字节数的可取消事件数据的类。 |
| [ProgressEventArgs](/zip/python-net/aspose.zip/progresseventargs/) | 用于包含已处理字节数的事件数据的类。 |
