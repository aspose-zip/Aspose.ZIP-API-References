## LzxArchiveEntry class

表示 LZX 存档中的单个文件。

LzxArchiveEntry 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取条目的名称。 |
| 注释 | 获取注释。 |
| length | 获取条目的字节长度。 |
| uncompressed_size | 获取原始文件的大小。 |
| compressed_size | 获取压缩文件的大小。 |
| is_directory | 获取一个值，指示此条目是否为目录。 |
| modification_time | 获取条目的最后修改时间。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| extract(path) | 将 Lzx 存档条目提取到指定路径的文件系统中。 |
| extract(destination) | 将条目提取到提供的流中。 |
