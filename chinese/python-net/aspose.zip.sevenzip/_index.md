包含表示 7z 存档相关实体的类。

## 类
| 类 | 描述 |
| :- | :- |
| [SevenZipArchive](/zip/python-net/aspose.zip.sevenzip/sevenziparchive/) | 此类表示 7z 存档文件。可用于创建和提取 7z 存档。 |
| [SevenZipArchiveEntry](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentry/) | 表示 7z 存档中的单个文件。 |
| [SevenZipArchiveEntryEncrypted](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentryencrypted/) | 需要使用加密进行压缩或使用解密进行解压的 SevenZip 存档条目。 |
| [SevenZipArchiveEntryPlain](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentryplain/) | 需要在不使用加密的情况下压缩或在不使用解密的情况下解压的 SevenZip 条目。 |
| [SevenZipLoadOptions](/zip/python-net/aspose.zip.sevenzip/sevenziploadoptions/) | 用于从压缩文件加载 [SevenZipArchive](/zip/python-net/aspose.zip.sevenzip/sevenziparchive/) 的选项。 |
