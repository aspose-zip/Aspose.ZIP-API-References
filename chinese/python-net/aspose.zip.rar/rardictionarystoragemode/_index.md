## RarDictionaryStorageMode enumeration

指定 RAR 解压缩字典的存储方式。

## Members
| 成员名称 | 描述 |
| :- | :- |
| IN_MEMORY | 将字典存储在惰性分配的托管内存段中。 |
| TEMPORARY_FILE | 将被驱逐的字典页存储在临时文件中，并在内存中保留受限的页面缓存。 |
