包含表示 RAR 存档相关实体的类。

## 类
| 类 | 描述 |
| :- | :- |
| [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) | 此类表示 RAR 存档文件。可用于提取 RAR 存档。 |
| [RarArchiveEntry](/zip/python-net/aspose.zip.rar/rararchiveentry/) | 表示存档中的单个文件。 |
| [RarArchiveEntryEncrypted](/zip/python-net/aspose.zip.rar/rararchiveentryencrypted/) | 需要解密后解压的 Zip 条目。 |
| [RarArchiveEntryPlain](/zip/python-net/aspose.zip.rar/rararchiveentryplain/) | 需要在不解密的情况下解压的 Rar 条目。 |
| [RarArchiveLoadOptions](/zip/python-net/aspose.zip.rar/rararchiveloadoptions/) | 从压缩文件加载 [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) 时的选项。 |
