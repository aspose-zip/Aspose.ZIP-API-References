包含表示 ALZ 存档相关实体的类。

## 类
| 类 | 描述 |
| :- | :- |
| [AlzArchive](/zip/python-net/aspose.zip.alz/alzarchive/) | 此类表示 ALZ 存档文件。可用于提取 alz 存档。 |
| [AlzArchiveLoadOptions](/zip/python-net/aspose.zip.alz/alzarchiveloadoptions/) | 从压缩文件加载 ALZ 存档的选项。 |
| [AlzEntry](/zip/python-net/aspose.zip.alz/alzentry/) | 表示 ALZ 存档中包含全部元数据的文件条目。 |
| [AlzEntryEncrypted](/zip/python-net/aspose.zip.alz/alzentryencrypted/) | 在解压缩前需要解密的 ALZ 条目。 |
| [AlzEntryPlain](/zip/python-net/aspose.zip.alz/alzentryplain/) | 需要在不解密的情况下解压缩的 ALZ 条目。 |
