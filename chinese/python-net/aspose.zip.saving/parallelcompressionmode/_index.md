## ParallelCompressionMode enumeration

## Members
| 成员名称 | 描述 |
| :- | :- |
| NEVER | 不要并行压缩。 |
| ALWAYS | 进行并行压缩。请注意可能导致内存消耗。 |
| AUTO | 根据条目决定是否使用并行压缩。<br/>            此选项可能仅对某些条目进行并行压缩。 |
