## LzipArchiveSettings class

该类包含特定 lzip 存档的设置。

LzipArchiveSettings 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| LzipArchiveSettings(dictionary_size, max_member_size) | 使用特定字典大小初始化 [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) 的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| fastest_speed | 获取 [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) 类的实例<br/>            在 LZMA 过滤器中，字典大小等于 65536 字节。 |
| fast_speed | 获取 [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) 类的实例<br/>            在 LZMA 过滤器中，字典大小等于 1 兆字节。 |
| normal | 获取 [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) 类的实例<br/>            在 LZMA 过滤器中，字典大小等于 16 兆字节。 |
| high_compression | 获取 [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) 类的实例<br/>            在 LZMA 过滤器中，字典大小等于 32 兆字节。 |
| maximum_compression | 获取 [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) 类的实例<br/>            在 LZMA 过滤器中，字典大小等于 64 兆字节。 |
| dictionary_size | 获取 LZMA 压缩使用的字典大小。 |
| max_member_size | 获取 lzip 存档中单个成员的最大大小（字节）。 |
| compression_threads | 获取或设置压缩线程数。如果该值大于 1，将使用多线程压缩。 |
