## SevenZipCipher class

用于 7-zip 加密的 AES 密码的基类。

| 名称 | 描述 |
| :- | :- |
| can_reuse_transform | 获取一个值，指示当前转换是否可以重用。 |
| can_transform_multiple_blocks | 获取一个值，指示是否可以转换多个块。 |
| input_block_size | 获取输入块大小。 |
| output_block_size | 获取输出块大小。 |
