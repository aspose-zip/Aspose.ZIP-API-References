## LzmaArchiveSettings class

LZMA 存档的设置。

LzmaArchiveSettings 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| LzmaArchiveSettings() | 使用默认字典大小（16 兆字节）、快速字节数为 32、文字上下文位为 3，初始化 [LzmaArchiveSettings](/zip/python-net/aspose.zip.lzma/lzmaarchivesettings/) 类的新实例。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| dictionary_size | 字典（历史缓冲区）大小指示最近处理的未压缩数据在内存中保留的字节数。<br/>            如果未设置，将根据条目大小自动选择。 |
| number_of_fast_bytes | 获取或设置在 LZMA 算法中用于快速匹配搜索的字节数。 |
