## XarFileEntry class

表示 xar 存档中的文件条目。

XarFileEntry 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取存档中条目的名称。 |
| full_path | 获取归档中条目的完整路径。 |
| is_directory | 获取一个值，指示该条目是否表示目录。 |
| parent | 获取条目所属的父目录。 |
| creation_time | 获取文件或目录的创建时间。 |
| last_access_time | 获取文件或目录的最近访问时间。 |
| last_write_time | 获取文件或目录的修改时间。 |
| modification_time | 获取文件或目录的修改时间。 |
| length | 获取条目的字节长度。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| extract(path) | 将条目提取到提供的路径对应的文件系统中。 |
| extract(destination) | 将条目提取到提供的流中。 |
| open() | 打开条目以进行提取，并提供包含条目内容的流。 |
