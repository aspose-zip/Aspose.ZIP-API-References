## IsoEntry class

表示 ISO 存档中的一个条目（文件或目录）。

IsoEntry 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取条目的名称。 |
| is_directory | 获取一个值，指示该条目是否为目录。 |
| length | 获取或设置创建日期和时间。 |
| modification_time | 获取或设置最后修改日期和时间。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| extract(path) | 将条目提取到提供的路径对应的文件系统中。 |
| extract(destination) | 将条目提取到提供的流中。 |
