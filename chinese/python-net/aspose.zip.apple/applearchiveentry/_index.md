## AppleArchiveEntry class

表示位于 [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/) 中的文件或目录条目。

AppleArchiveEntry 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| name | 获取归档内条目的路径。 |
| length | 获取条目未压缩的字节长度。 |
| is_directory | 获取一个值，指示该条目是否表示目录。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| extract(path) | 将条目提取到提供的路径对应的文件系统中。 |
| extract(destination) | 将条目提取到提供的流中。 |
| open() | 打开条目以进行提取，并提供包含条目内容的流。 |
