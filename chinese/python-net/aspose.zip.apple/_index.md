包含表示 Apple 存档相关实体的类。

## 类
| 类 | 描述 |
| :- | :- |
| [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/) | 此类表示 Apple Archive (.aar) 文件。可用于创建 Apple Archive 文件。 |
| [AppleArchiveEntry](/zip/python-net/aspose.zip.apple/applearchiveentry/) | 表示位于 [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/) 中的文件或目录条目。 |
| [AppleArchiveEntrySettings](/zip/python-net/aspose.zip.apple/applearchiveentrysettings/) | 用于在 [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/) 中创建条目的设置。 |
| [AppleArchiveLoadOptions](/zip/python-net/aspose.zip.apple/applearchiveloadoptions/) | 从压缩文件加载 [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/) 的选项。 |
| [AppleCompressionSettings](/zip/python-net/aspose.zip.apple/applecompressionsettings/) | Apple Archive 条目压缩所需的设置。 |
| [AppleLz4CompressionSettings](/zip/python-net/aspose.zip.apple/applelz4compressionsettings/) | Apple Archive (.aar) 文件中 LZ4 压缩的设置。 |
| [AppleLzfseCompressionSettings](/zip/python-net/aspose.zip.apple/applelzfsecompressionsettings/) | Apple Archive (.aar) 文件中 LZFSE 压缩的设置。 |
| [AppleLzmaCompressionSettings](/zip/python-net/aspose.zip.apple/applelzmacompressionsettings/) | Apple Archive (.aar) 文件中 LZMA 压缩的设置。 |
| [AppleStoreCompressionSettings](/zip/python-net/aspose.zip.apple/applestorecompressionsettings/) | Apple Archive (.aar) 文件中存储（无压缩）的设置。 |
| [AppleZlibCompressionSettings](/zip/python-net/aspose.zip.apple/applezlibcompressionsettings/) | Apple Archive (.aar) 文件中 Zlib 压缩的设置。 |
