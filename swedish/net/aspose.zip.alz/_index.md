Alz-namnområdet innehåller klasser som representerar ALZ-relaterade enheter.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [AlzArchive](./alzarchive/) | Denna klass representerar en ALZ-arkivfil. Använd den för att extrahera alz-arkiv. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Alternativ med vilka ALZ-arkivet laddas från en komprimerad fil. |
| [AlzEntry](./alzentry/) | Representerar en filpost i ett ALZ-arkiv med all dess metadata. |
| [AlzEntryEncrypted](./alzentryencrypted/) | ALZ-post som måste dekrypteras innan dekomprimering. |
| [AlzEntryPlain](./alzentryplain/) | ALZ-post som måste dekomprimeras utan dekryptering. |
