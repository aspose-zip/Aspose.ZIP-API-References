Iso-namnutrymmet innehåller klasser som representerar ISO-relaterade enheter.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Händelseargument för händelser relaterade till poster. |
| [EventsBag](./eventsbag/) | Evenemangsbehållare som används vid sparande av [`IsoArchive`](../aspose.zip.iso/isoarchive/). |
| [IsoArchive](./isoarchive/) | Representerar ett ISO-arkiv (ISO 9660). |
| [IsoEntry](./isoentry/) | Representerar en post (fil eller katalog) i ett ISO-arkiv. |
| [IsoLoadOptions](./isoloadoptions/) | Alternativ med vilka [`IsoArchive`](../aspose.zip.iso/isoarchive/) laddas från en komprimerad fil. Innehåller händelse som utlöses vid extrahering. |
| [IsoSaveOptions](./isosaveoptions/) | Alternativ för att spara ett ISO-arkiv. |
