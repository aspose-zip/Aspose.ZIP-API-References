## AppleArchive.IsSolid property

Hämtar ett värde som indikerar om arkivet använder solid komprimering. I solidläge komprimeras all postdata som en enda ström och individuell postextrahering är inte tillgänglig. Använd [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/) istället.

public bool IsSolid { get; }
