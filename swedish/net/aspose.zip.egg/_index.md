Egg-namnområdet innehåller klasser som representerar EGG-relaterade enheter.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [EggArchive](./eggarchive/) | Denna klass representerar en EGG-arkivfil. Använd den för att extrahera EGG-arkiv. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Alternativ med vilka ett EGG-arkiv laddas från en komprimerad fil. |
| [EggEntry](./eggentry/) | Representerar en filpost i ett EGG-arkiv med all dess metadata. |
| [EggEntryPlain](./eggentryplain/) | EGG-post som kan dekomprimeras utan dekryptering. |
