## CabEntry class

Representerar en enskild fil i ett CAB-arkiv.

Typen CabEntry exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar namn på posten i arkivet. |
| length | Hämtar längden på posten i byte. |
| modification_time | Hämtar datum och tid för senaste ändring. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(path) | Extraherar posten till filsystemet med den angivna sökvägen. |
| extract(destination) | Extraherar posten till den angivna strömmen. |
| open() | Öppnar posten för extrahering och tillhandahåller en ström med postens innehåll. |
