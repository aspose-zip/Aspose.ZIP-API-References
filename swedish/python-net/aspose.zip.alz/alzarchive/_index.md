## AlzArchive class

Denna klass representerar en ALZ-arkivfil. Använd den för att extrahera alz-arkiv.

Typen AlzArchive exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| AlzArchive(stream, load_options) | Initierar en ny instans av klassen [AlzArchive](/zip/python-net/aspose.zip.alz/alzarchive/) från en ström. |
| AlzArchive(file_path, load_options) | Initierar en ny instans av klassen [AlzArchive](/zip/python-net/aspose.zip.alz/alzarchive/) från en filsökväg. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| poster | Hämtar listan över filer i arkivet. |
| file_entries | Hämtar poster av typen [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) som utgör arkivet. |
| format | Hämtar arkivformatet. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract_to_directory(destination_directory) | Extraherar alla filer och kataloger i arkivet till den angivna katalogen. |
