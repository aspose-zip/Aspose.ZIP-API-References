Innehåller klasser som representerar ALZ-arkivrelevanta enheter.

## Klasser
| Klass | Beskrivning |
| :- | :- |
| [AlzArchive](/zip/python-net/aspose.zip.alz/alzarchive/) | Denna klass representerar en ALZ-arkivfil. Använd den för att extrahera alz-arkiv. |
| [AlzArchiveLoadOptions](/zip/python-net/aspose.zip.alz/alzarchiveloadoptions/) | Alternativ med vilka ALZ-arkivet laddas från en komprimerad fil. |
| [AlzEntry](/zip/python-net/aspose.zip.alz/alzentry/) | Representerar en filpost i ett ALZ-arkiv med all dess metadata. |
| [AlzEntryEncrypted](/zip/python-net/aspose.zip.alz/alzentryencrypted/) | ALZ-post som måste dekrypteras innan dekomprimering. |
| [AlzEntryPlain](/zip/python-net/aspose.zip.alz/alzentryplain/) | ALZ-post som måste dekomprimeras utan dekryptering. |
