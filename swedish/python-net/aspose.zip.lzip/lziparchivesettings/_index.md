## LzipArchiveSettings class

Klassen innehåller inställningar för ett specifikt lzip-arkiv.

Typen LzipArchiveSettings exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LzipArchiveSettings(dictionary_size, max_member_size) | Initierar en ny instans av [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) med en viss ordboksstorlek. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| fastest_speed | Hämtar instansen av klassen [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            med ordboksstorlek lika med 65536 byte i LZMA-filter. |
| fast_speed | Hämtar instansen av klassen [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            med ordboksstorlek lika med 1 megabyte i LZMA-filter. |
| normal | Hämtar instansen av klassen [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            med ordboksstorlek lika med 16 megabyte i LZMA-filter. |
| high_compression | Hämtar instansen av klassen [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            med ordboksstorlek lika med 32 megabyte i LZMA-filter. |
| maximum_compression | Hämtar instansen av klassen [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            med ordboksstorlek lika med 64 megabyte i LZMA-filter. |
| dictionary_size | Hämtar storleken på ordboken som används av LZMA-komprimering. |
| max_member_size | Hämtar den maximala storleken för en medlem i lzip-arkivet, angivet i byte. |
| compression_threads | Hämtar eller anger antalet komprimeringstrådar. Om värdet är större än 1 kommer komprimering med flera trådar att användas. |
