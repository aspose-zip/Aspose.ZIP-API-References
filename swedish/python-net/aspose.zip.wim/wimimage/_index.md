## WimImage class

Representerar en enskild avbild i wim-arkivet.

Typen WimImage exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| root_directory | Hämtar rotkatalogsposten för avbilden. |
| all_entries | Hämtar poster av typen [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) som rekursivt utgör avbilden. |
| parent | Hämtar arkivet som avbilden tillhör. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| get_entry(path) | Hämtar posten av typen [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) för en given sökväg. |
| extract_to_directory(destination_directory) | Extraherar alla filer i avbilden till den angivna katalogen. |
