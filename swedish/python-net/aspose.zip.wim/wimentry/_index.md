## WimEntry class

Representerar en enskild fil eller katalog i wim-avbilden.

Typen WimEntry exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| archive | Hämtar archive som posten tillhör. |
| image | Hämtar image som posten tillhör. |
| parent | Hämtar parent-katalogen som posten tillhör. |
| name | Hämtar namn på posten i image. |
| short_name | Hämtar short name på posten i image. |
| full_path | Hämtar en full path för posten i image. |
| change_time | Hämtar den senaste tiden filen eller katalogen ändrades. |
| creation_time | Hämtar skapandetiden för filen eller katalogen. |
| last_access_time | Hämtar den senaste åtkomsttiden för filen eller katalogen. |
| last_write_time | Hämtar ändringstiden för filen eller katalogen. |
| modification_time | Hämtar ändringstiden för filen eller katalogen. |
| alternate_data_streams | Hämtar namnen på de alternativa datastreamarna för en fil eller katalog. |
| hard_link | Hämtar hårdlänk‑id för filen eller katalogen. |
| has_hard_links | Hämtar om filen eller katalogen är känd under andra namn. |
| is_directory | Hämtar ett värde som indikerar om posten representerar en katalog. |
