## WimArchive class

Denna klass representerar en wim-arkivfil.

Typen WimArchive exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| WimArchive(source_stream, load_options) | Initierar en ny instans av klassen [WimArchive](/zip/python-net/aspose.zip.wim/wimarchive/) och skapar en postlista som kan extraheras från arkivet. |
| WimArchive(path, load_options) | Initierar en ny instans av klassen [WimArchive](/zip/python-net/aspose.zip.wim/wimarchive/) och skapar en postlista som kan extraheras från arkivet. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| images | Hämtar poster av typen [WimImage](/zip/python-net/aspose.zip.wim/wimimage/) som utgör arkivet. |
| entries | Hämtar poster av typen [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) som utgör arkivet. |
| guid | Hämtar den identifierande GUID‑en för arkivet. |
| boot_image_index | Hämtar (nollbaserat) index för den startbara avbilden. |
| file_format_version | Hämtar versionen av filformatet. |
| manifest | Hämtar det inbäddade manifestet som beskriver filen och de innehållna avbilderna. |
| file_entries | Hämtar poster av typen [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) som utgör arkivet. |
| format | Hämtar arkivformatet. |
