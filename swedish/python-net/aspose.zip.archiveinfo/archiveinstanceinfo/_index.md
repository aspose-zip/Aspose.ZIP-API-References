## ArchiveInstanceInfo class

Representerar information om arkivinstansen.

Typen ArchiveInstanceInfo exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| format_info | Hämtar arkivformatinformationen. |
| is_content_encrypted | Hämtar ett värde som indikerar om arkivets innehåll är krypterat. |
| are_file_names_encrypted | Hämtar ett värde som indikerar om namnen på poster (filer) i arkivet är krypterade. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| get_archive_format_info(file_name) | Hämtar information om arkivformat. |
| get_archive_format_info(stream) | Hämtar information om arkivformat. |
| get_archive_instance_info(file_name) | Hämtar information om arkivinstans. |
| get_archive_instance_info(stream) | Hämtar information om arkivinstans. |
