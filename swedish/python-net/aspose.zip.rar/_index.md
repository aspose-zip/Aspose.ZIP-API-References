Innehåller klasser som representerar RAR-arkivrelevanta enheter.

## Klasser
| Klass | Beskrivning |
| :- | :- |
| [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) | Denna klass representerar en RAR-arkivfil. Använd den för att extrahera RAR-arkiv. |
| [RarArchiveEntry](/zip/python-net/aspose.zip.rar/rararchiveentry/) | Representerar en enskild fil i arkivet. |
| [RarArchiveEntryEncrypted](/zip/python-net/aspose.zip.rar/rararchiveentryencrypted/) | Zip-post som måste dekomprimeras med dekryptering. |
| [RarArchiveEntryPlain](/zip/python-net/aspose.zip.rar/rararchiveentryplain/) | Rar-post som måste dekomprimeras utan dekryptering. |
| [RarArchiveLoadOptions](/zip/python-net/aspose.zip.rar/rararchiveloadoptions/) | Alternativ med vilka [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) laddas från en komprimerad fil. |
