## XarDirectoryEntry class

Representerar katalogpost inom xar-arkivet.

Typen XarDirectoryEntry exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar namn på posten i arkivet. |
| full_path | Hämtar hela sökvägen för posten i arkivet. |
| is_directory | Hämtar ett värde som indikerar om posten representerar en katalog. |
| parent | Hämtar parent-katalogen som posten tillhör. |
| creation_time | Hämtar skapandetiden för filen eller katalogen. |
| last_access_time | Hämtar den senaste åtkomsttiden för filen eller katalogen. |
| last_write_time | Hämtar ändringstiden för filen eller katalogen. |
| modification_time | Hämtar ändringstiden för filen eller katalogen. |
| files_and_directories | Hämtar poster av typen [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/) som utgör katalogen. |
| directories | Hämtar poster av typen [XarDirectoryEntry](/zip/python-net/aspose.zip.xar/xardirectoryentry/) som utgör katalogen. |
| files | Hämtar poster av typen [XarFileEntry](/zip/python-net/aspose.zip.xar/xarfileentry/) som utgör katalogen. |
| all_entries | Hämtar alla poster av typen [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/) som utgör katalogen rekursivt. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract_to_directory(destination_directory) | Extraherar alla filer i den aktuella katalogen till den angivna katalogen. |
