## SevenZipCipher class

Bas-klass för AES-chiffer som används för 7-zip-kryptering.

SevenZipCipher-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| can_reuse_transform | Hämtar ett värde som indikerar om den aktuella transformationen kan återanvändas. |
| can_transform_multiple_blocks | Hämtar ett värde som indikerar om flera block kan transformeras. |
| input_block_size | Hämtar ingångsblockens storlek. |
| output_block_size | Hämtar storleken på utdata-blocket. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| transform_block(input_buffer, input_offset, input_count, output_buffer, output_offset) | Transformerar det angivna området i inmatningsbytearrayen och kopierar den resulterande transformationen till det angivna området i utdata-bytearrayen. |
| transform_final_block(input_buffer, input_offset, input_count) | Transformerar det angivna området i den angivna bytearrayen. |
