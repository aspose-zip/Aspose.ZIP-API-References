## LzmaArchiveSettings class

Inställningar för lzma-arkiv.

Typen LzmaArchiveSettings visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LzmaArchiveSettings() | Initierar en ny instans av klassen [LzmaArchiveSettings](/zip/python-net/aspose.zip.lzma/lzmaarchivesettings/) med standardordlistestorlek, lika med 16 megabyte, antal snabba byte lika med 32 och bokstavskontextbitar lika med 3. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| dictionary_size | Storleken på ordboken (historikbufferten) anger hur många byte av den nyligen bearbetade okomprimerade datan som hålls i minnet.<br/>            Om den inte är angiven väljs den enligt postens storlek. |
| number_of_fast_bytes | Hämtar eller anger antalet byte som används för snabb matchningssökning i LZMA-algoritmen. |
| literal_context_bits | Hämtar eller anger antalet bokstavskontextbitar. |
