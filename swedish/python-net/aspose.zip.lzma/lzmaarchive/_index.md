## LzmaArchive class

Denna klass representerar en LZMA-arkivfil. Använd den för att skapa eller extrahera LZMA-arkiv.

Typen LzmaArchive visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LzmaArchive(settings) | Initierar en ny instans av klassen [LzmaArchive](/zip/python-net/aspose.zip.lzma/lzmaarchive/) och skapar arkivet i lzma-format. |
| LzmaArchive(source) | Initierar en ny instans av klassen [LzmaArchive](/zip/python-net/aspose.zip.lzma/lzmaarchive/) för dekomprimering. |
| LzmaArchive(path) | Initierar en ny instans av klassen [LzmaArchive](/zip/python-net/aspose.zip.lzma/lzmaarchive/) för dekomprimering. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| file_entries | Hämtar poster av typen [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) som utgör arkivet. |
| format | Hämtar arkivformatet. |
| name | Hämtar namn på posten. |
| length | Hämtar längden på posten i byte. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(destination) | Extraherar lzma-arkivet till en ström. |
| extract(file_info) | Extraherar lzma-arkivet till en fil. |
| extract(path) | Extraherar lzma-arkivet till en fil via sökväg. |
| set_source(source) | Ställer in innehållet som ska komprimeras i arkivet. |
| set_source(file_info) | Ställer in innehållet som ska komprimeras i arkivet. |
| set_source(source_path) | Ställer in innehållet som ska komprimeras i arkivet. |
| save(output) | Sparar lzma-arkivet till den angivna strömmen. |
| save(destination) | Sparar lzma-arkivet till den angivna destinationsfilen. |
| save(destination_file_name) | Sparar lzma-arkivet till den angivna destinationsfilen. |
| extract_to_directory(destination_directory) | Extraherar arkivets innehåll till den angivna katalogen. |
