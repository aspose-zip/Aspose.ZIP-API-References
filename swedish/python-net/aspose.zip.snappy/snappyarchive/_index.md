## SnappyArchive class

Denna klass representerar en snappy-arkivfil. Använd den för att skapa eller extrahera snappy-arkiv.

SnappyArchive-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| SnappyArchive() | Initierar en ny instans av klassen [SnappyArchive](/zip/python-net/aspose.zip.snappy/snappyarchive/) för komprimering. |
| SnappyArchive(source) | Initierar en ny instans av klassen [SnappyArchive](/zip/python-net/aspose.zip.snappy/snappyarchive/) för dekomprimering. |
| SnappyArchive(path) | Initierar en ny instans av klassen [SnappyArchive](/zip/python-net/aspose.zip.snappy/snappyarchive/) för dekomprimering. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| file_entries | Hämtar poster av typen [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) som utgör arkivet. |
| format | Hämtar arkivformatet. |
| name | Hämtar namn på posten. |
| length | Hämtar längden på posten i byte. |
