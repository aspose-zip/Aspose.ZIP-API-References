## LhaArchiveEntry class

Representerar en enskild fil i ett Lha-arkiv.

Typen LhaArchiveEntry exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar namn på posten. |
| length | Hämtar längden på posten i byte. |
| is_directory | Hämtar ett värde som indikerar om detta objekt är en katalog. |
| last_modified | Hämtar den senast ändrade tiden för objektet. |
| modification_time | Hämtar den senast ändrade tiden för objektet. |
| path | Hämtar den fullständiga sökvägen till objektet. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(path) | Extraherar Lha-arkivpost till ett filsystem enligt sökväg. |
| extract(destination) | Extraherar posten till den angivna strömmen. |
| extract(file_info) | Extraherar Lha-arkivpost till en fil. |
