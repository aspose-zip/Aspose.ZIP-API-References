## LhaArchive class

Denna klass representerar en LHA (.lzh)-arkivfil.

Typen LhaArchive exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LhaArchive(source_stream, load_options) | Initierar en ny instans av klassen [LhaArchive](/zip/python-net/aspose.zip.lha/lhaarchive/) och skapar en postlista som kan extraheras från arkivet. |
| LhaArchive(path, load_options) | Initierar en ny instans av klassen [LhaArchive](/zip/python-net/aspose.zip.lha/lhaarchive/) och skapar en postlista som kan extraheras från arkivet. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| entries | Hämtar filposter av typen [LhaArchiveEntry](/zip/python-net/aspose.zip.lha/lhaarchiveentry/) som utgör arkivet. |
| file_entries | Hämtar poster av typen [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) som utgör arkivet. |
| format | Hämtar arkivformatet. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract_to_directory(destination_directory) | Extraherar alla filer och kataloger i arkivet till den angivna katalogen. |
