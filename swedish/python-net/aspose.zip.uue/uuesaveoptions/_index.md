Alternativ för att spara en uu-kodad fil.

## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| UueSaveOptions(file_name, new_line) | Initierar alternativen med användarens angivna filnamn och ny rad. |

| Namn | Beskrivning |
