## XzArchiveSettings class

Klassen innehåller en uppsättning inställningar för ett specifikt xz-arkiv.

Typen XzArchiveSettings visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| XzArchiveSettings() | Initierar en ny instans av klassen [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) med enkel LZMA2-komprimering. |
| XzArchiveSettings(filters, block_size, check_type) | Initierar en ny instans av klassen [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) med anpassade parametrar. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| compression_threads | Hämtar eller anger antalet komprimeringstrådar. Om värdet är större än 1 kommer komprimering med flera trådar att användas. |
| fastest_speed | Hämtar instansen av klassen [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            med en ordboksstorlek på 65536 byte i LZMA2-filter, blockstorlek på 1 megabyte och CRC32-kontrollsumma. |
| fast_speed | Hämtar instansen av klassen [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            med en ordboksstorlek på 1 megabyte i LZMA2-filter, blockstorlek på 4 megabyte och CRC32-kontrollsumma. |
| normal | Hämtar instansen av klassen [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            med en ordboksstorlek på 16 megabyte i LZMA2-filter, blockstorlek på 64 megabyte och CRC32-kontrollsumma. |
| high_compression | Hämtar instansen av klassen [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            med en ordboksstorlek på 32 megabyte i LZMA2-filter, blockstorlek på 128 megabyte och CRC32-kontrollsumma. |
| maximum_compression | Hämtar instansen av klassen [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            med en ordboksstorlek på 64 megabyte i LZMA2-filter, blockstorlek på 256 megabyte och CRC32-kontrollsumma. |
