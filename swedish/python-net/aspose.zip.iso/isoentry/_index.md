## IsoEntry class

Representerar en post (fil eller katalog) i ett ISO-arkiv.

Typen IsoEntry exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar namnet på posten. |
| is_directory | Hämtar ett värde som indikerar om posten är en katalog. |
| length | Hämtar eller anger skapelsedatum och -tid. |
| modification_time | Hämtar eller anger senast ändrad datum och tid. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(path) | Extraherar posten till filsystemet med den angivna sökvägen. |
| extract(destination) | Extraherar posten till den angivna strömmen. |
