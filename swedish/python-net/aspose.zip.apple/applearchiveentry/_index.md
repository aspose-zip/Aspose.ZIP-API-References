## AppleArchiveEntry class

Representerar en fil- eller katalogpost inom en [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/).

Typen AppleArchiveEntry visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar sökvägen för posten i arkivet. |
| length | Hämtar den okomprimerade längden för posten i byte. |
| is_directory | Hämtar ett värde som indikerar om posten representerar en katalog. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(path) | Extraherar posten till filsystemet med den angivna sökvägen. |
| extract(destination) | Extraherar posten till den angivna strömmen. |
| open() | Öppnar posten för extraktion och tillhandahåller en ström med postens innehåll. |
