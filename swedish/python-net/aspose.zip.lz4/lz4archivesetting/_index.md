## Lz4ArchiveSetting class

Inställningar för LZ4-arkivskapande.

Lz4ArchiveSetting-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Lz4ArchiveSetting() | Initierar en ny instans av [Lz4ArchiveSetting](/zip/python-net/aspose.zip.lz4/lz4archivesetting/) med standardparametrar. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| include_content_checksum | Hämtar eller anger ett värde som indikerar om innehålls‑xxh32‑hash ska inkluderas i slutet av LZ4‑arkivet. |
| include_block_checksum | Hämtar eller anger ett värde som indikerar om komprimerad xxh32‑hash ska inkluderas i slutet av det komprimerade blocket. |
| include_content_size | Hämtar eller anger ett värde som indikerar om innehållsstorleken ska inkluderas i ramen. |
