## SevenZipEntrySettings class

Inställningar som används för att komprimera eller dekomprimera 7Z-poster.

Typen SevenZipEntrySettings visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| SevenZipEntrySettings(compression_settings, encryption_settings) | Initierar en ny instans av klassen [SevenZipEntrySettings](/zip/python-net/aspose.zip.saving/sevenzipentrysettings/). |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| compression_settings | Hämtar inställningar för komprimerings- eller dekomprimeringsrutinen. |
| encryption_settings | Hämtar inställningar för kryptering eller dekryptering. Inställningarna för en viss post kan variera. |
| `compress_header` | Hämtar eller anger värde som indikerar om arkivhuvudet ska komprimeras. |
| `solid` | Hämtar eller anger värde som indikerar om poster ska sammanfogas och behandlas som ett enda datablok. |
