## SevenZipLZMA2CompressionSettings class

Inställningar för LZMA2-komprimeringsmetod i ett 7z-arkiv.

Typen SevenZipLZMA2CompressionSettings visar följande medlemmar:

| Namn | Beskrivning |
| :- | :- |
| SevenZipLZMA2CompressionSettings(dictionary_size) | Initierar en ny instans av klassen SevenZipLZMA2CompressionSettings |

## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| metod | Hämtar komprimerings- eller dekomprimeringsmetod. |
| compression_threads | Hämtar eller anger antalet komprimeringstrådar. Om värdet är större än 1 kommer komprimering med flera trådar att användas. |
| dictionary_size | Storleken på ordboken (historikbuffert) indikerar hur många byte av den nyligen bearbetade okomprimerade datan som hålls i minnet. |
| fast_bytes | Hämtar kontrollnumret för snabba byte som används av LZMA2-komprimeraren. |
