## ParallelCompressionMode enumeration

Alternativ för användning av parallell komprimeringsfunktion.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NEVER | Komprimera inte parallellt. |
| ALWAYS | Komprimera parallellt. Var uppmärksam på minnesutflöde. |
| AUTO | Bestäm om parallell komprimering ska användas baserat på posterna.<br/>            Detta alternativ kan endast komprimera vissa poster parallellt. |
