## ArchiveEntryEncrypted class

Zip-post som måste komprimeras med kryptering eller dekomprimeras med dekryptering.

Typen ArchiveEntryEncrypted exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| compressed_size | Hämtar storleken på den komprimerade filen. |
| name | Hämtar namn på posten i arkivet. |
| comment | Hämtar kommentaren för posten i arkivet. |
| uncompressed_size | Hämtar storleken på originalfilen. |
| modification_time | Hämtar eller anger senast ändrad datum och tid. |
| is_directory | Hämtar ett värde som indikerar om posten representerar en katalog. |
| data_source | Källa för posten om den lades till i arkivet, inte extraherad. |
| compression_settings | Hämtar inställningar för komprimering eller dekomprimering. |
| encryption_settings | Hämtar inställningar för kryptering eller dekryptering. |
| length | Hämtar längden på posten i byte. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(path, password) | Extraherar posten till filsystemet med den angivna sökvägen. |
| extract(destination, password) | Extraherar posten till den angivna strömmen. |
| extract(path) | Extraherar posten till filsystemet med den angivna sökvägen. |
| extract(destination) | Extraherar posten till den angivna strömmen. |
| open(password) | Öppnar posten för extrahering och tillhandahåller en ström med dekomprimerat postinnehåll. |
