## IArchiveFileEntry class

Detta gränssnitt representerar en arkivfilspost.

Typen IArchiveFileEntry visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar namn på posten. |
| length | Hämtar längden på posten i byte. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(path) | Extraherar posten till filsystemet med den angivna sökvägen. |
| extract(destination) | Extraherar posten till den angivna strömmen. |
