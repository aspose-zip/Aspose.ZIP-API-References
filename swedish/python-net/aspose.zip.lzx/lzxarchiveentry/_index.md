## LzxArchiveEntry class

Representerar en enskild fil i ett LZX-arkiv.

Typen LzxArchiveEntry exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar namn på posten. |
| kommentar | Hämtar kommentaren. |
| length | Hämtar längden på posten i byte. |
| uncompressed_size | Hämtar storleken på originalfilen. |
| compressed_size | Hämtar storleken på den komprimerade filen. |
| is_directory | Hämtar ett värde som indikerar om detta objekt är en katalog. |
| modification_time | Hämtar den senast ändrade tiden för objektet. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(path) | Extraherar Lzx-arkivpost till ett filsystem via sökväg. |
| extract(destination) | Extraherar posten till den angivna strömmen. |
