## LzxArchive class

Denna klass representerar en LZX (.lzx)-arkivfil.

Typen LzxArchive exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LzxArchive(extraction_source, load_options) | Initierar en ny instans av klassen [LzxArchive](/zip/python-net/aspose.zip.lzx/lzxarchive/) och skapar en postlista som kan extraheras från arkivet. |
| LzxArchive(path, load_options) | Initierar en ny instans av klassen [LzxArchive](/zip/python-net/aspose.zip.lzx/lzxarchive/) och skapar en postlista som kan extraheras från arkivet. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| entries | Hämtar filposter av typen [LzxArchiveEntry](/zip/python-net/aspose.zip.lzx/lzxarchiveentry/) som utgör arkivet. |
| file_entries | Hämtar poster av typen [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) som utgör arkivet. |
| format | Hämtar arkivformatet. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
