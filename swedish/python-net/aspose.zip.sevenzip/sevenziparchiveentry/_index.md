## SevenZipArchiveEntry class

Representerar en enskild fil i 7z-arkivet.

Typen SevenZipArchiveEntry visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| name | Hämtar namn på posten i arkivet. |
| modification_time | Hämtar datum och tid för senaste ändring. |
| uncompressed_size | Hämtar storleken på en originalfil. |
| compressed_size | Hämtar storleken på en komprimerad fil. |
| is_directory | Hämtar ett värde som indikerar om posten representerar en katalog. |
| compression_settings | Hämtar inställningar för komprimering eller dekomprimering. |
| length | Hämtar längden på posten i byte. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| extract(path, password) | Extraherar posten till filsystemet med den angivna sökvägen. |
| extract(destination, password) | Extraherar posten till den angivna strömmen. |
| extract(path) | Extraherar posten till filsystemet med den angivna sökvägen. |
| extract(destination) | Extraherar posten till den angivna strömmen. |
| open(password) | Öppnar posten för extrahering och tillhandahåller en ström med postens innehåll. |
