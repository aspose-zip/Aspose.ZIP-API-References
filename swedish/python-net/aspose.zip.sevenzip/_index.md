Innehåller klasser som representerar 7z-arkivrelevanta enheter.

## Klasser
| Klass | Beskrivning |
| :- | :- |
| [SevenZipArchive](/zip/python-net/aspose.zip.sevenzip/sevenziparchive/) | Denna klass representerar en 7z-arkivfil. Använd den för att skapa och extrahera 7z-arkiv. |
| [SevenZipArchiveEntry](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentry/) | Representerar en enskild fil i 7z-arkivet. |
| [SevenZipArchiveEntryEncrypted](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentryencrypted/) | SevenZip-arkivpost som måste komprimeras med kryptering eller dekomprimeras med dekryptering. |
| [SevenZipArchiveEntryPlain](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentryplain/) | SevenZip-post som måste komprimeras utan kryptering eller dekomprimeras utan dekryptering. |
| [SevenZipLoadOptions](/zip/python-net/aspose.zip.sevenzip/sevenziploadoptions/) | Alternativ med vilka [SevenZipArchive](/zip/python-net/aspose.zip.sevenzip/sevenziparchive/) laddas från en komprimerad fil. |
