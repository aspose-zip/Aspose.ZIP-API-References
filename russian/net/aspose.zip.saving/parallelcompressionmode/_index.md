## ParallelCompressionMode enumeration

Параметры использования параллельного сжатия.

```csharp
public enum ParallelCompressionMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Never | `0` | Не выполнять параллельное сжатие. |
| Always | `1` | Выполнять параллельное сжатие. Учтите повышенное потребление памяти. |
| Auto | `2` | Определяет, будет ли использоваться параллельное сжатие на основе записей. Эта опция может выполнять параллельное сжатие только для некоторых записей. |
