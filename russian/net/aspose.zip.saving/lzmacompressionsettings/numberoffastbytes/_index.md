## LzmaCompressionSettings.NumberOfFastBytes property

Возвращает количество байтов, используемых для быстрого поиска совпадений в алгоритме LZMA.

```csharp
public int NumberOfFastBytes { get; }
```

## Примечания

Большее значение позволяет компрессору искать более длинные совпадения, что может немного улучшить коэффициент сжатия, но замедляет процесс сжатия.
