## ZipDataDescriptorPolicy enumeration

Параметры наличия дескриптора данных.

```csharp
public enum ZipDataDescriptorPolicy : byte
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Always | `0` | Data Descriptor всегда присутствует для всех записей zip. |
| ForAllFileEntries | `1` | Data Descriptor присутствует только для записей с файловыми данными; опускается для каталогов. Использование этой опции не рекомендуется. |
