## LzipArchiveSettings.CompressionThreads property

Получает или задает количество потоков сжатия. Если значение больше 1, будет использоваться многопоточное сжатие.

```csharp
public int CompressionThreads { get; set; }
```

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentOutOfRangeException | Количество потоков больше 100. |

## Примечания

Не задавайте это число больше количества ядер процессора.
