## FastLZStream.Read method

Читает последовательность байтов из потока и перемещает позицию в потоке на количество прочитанных байтов. Не поддерживается.

```csharp
public override int Read(byte[] buffer, int offset, int count)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| buffer | Byte[] | Массив байтов. После возврата этого метода буфер содержит указанный массив байтов, где значения между offset и (offset + count - 1) заменены байтами, считанными из текущего источника. |
| offset | Int32 | Байтовое смещение в buffer, начиная с которого следует сохранять данные, считанные из текущего потока. |
| count | Int32 | Максимальное количество байтов, которое будет считано из текущего потока. |

### Возвращаемое значение

Общее количество байтов, считанных в буфер. Оно может быть меньше запрошенного количества байтов, если столько байтов в данный момент недоступно, либо равно нулю (0), если достигнут конец потока.

### Исключения

| исключение | условие |
| --- | --- |
| NotSupportedException | Операция не поддерживается. |
