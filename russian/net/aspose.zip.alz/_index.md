Пространство имён Alz содержит классы, представляющие сущности, связанные с ALZ.

## Классы

| Класс | Описание |
| --- | --- |
| [AlzArchive](./alzarchive/) | Этот класс представляет файл архива ALZ. Используйте его для извлечения архивов ALZ. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Параметры, с помощью которых архив ALZ загружается из сжатого файла. |
| [AlzEntry](./alzentry/) | Представляет файловую запись в архиве ALZ со всей её метаданными. |
| [AlzEntryEncrypted](./alzentryencrypted/) | Запись ALZ, которую необходимо расшифровать перед распаковкой. |
| [AlzEntryPlain](./alzentryplain/) | Запись ALZ, которую необходимо распаковать без расшифровки. |
