Пространство имен Z содержит классы, представляющие сущности, связанные с архивом Z.

| Класс | Описание |
| --- | --- |
| [ZArchive](./zarchive/) | Этот класс представляет файл архива Z (compress). Используйте его для создания или извлечения архивов Z. |
| [ZArchiveLoadOptions](./zarchiveloadoptions/) | Параметры, с которыми [`ZArchive`](../aspose.zip.z/zarchive/) загружается из сжатого файла. Содержит событие, вызываемое при извлечении. |
| [ZArchiveSaveOptions](./zarchivesaveoptions/) | Настройки Zarchive. |
