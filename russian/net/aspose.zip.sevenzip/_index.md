Пространство имен SevenZip содержит классы, представляющие сущности, связанные с архивом 7z.

## Классы

| Класс | Описание |
| --- | --- |
| [SevenZipArchive](./sevenziparchive/) | Этот класс представляет файл архива 7z. Используйте его для создания и извлечения архивов 7z. |
| [SevenZipArchiveEntry](./sevenziparchiveentry/) | Представляет отдельный файл внутри архива 7z. |
| [SevenZipArchiveEntryEncrypted](./sevenziparchiveentryencrypted/) | Элемент архива SevenZip, который необходимо сжать с шифрованием или распаковать с дешифрованием. |
| [SevenZipArchiveEntryPlain](./sevenziparchiveentryplain/) | Элемент SevenZip, который необходимо сжать без шифрования или распаковать без дешифрования. |
| [SevenZipLoadOptions](./sevenziploadoptions/) | Параметры, с помощью которых [`SevenZipArchive`](../aspose.zip.sevenzip/sevenziparchive/) загружается из сжатого файла. |
