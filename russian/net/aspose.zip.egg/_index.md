Пространство имён Egg содержит классы, представляющие сущности, связанные с EGG.

## Классы

| Класс | Описание |
| --- | --- |
| [EggArchive](./eggarchive/) | Этот класс представляет файл архива EGG. Используйте его для извлечения архивов EGG. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Параметры, с помощью которых архив EGG загружается из сжатого файла. |
| [EggEntry](./eggentry/) | Представляет запись файла в архиве EGG со всей его метаданными. |
| [EggEntryPlain](./eggentryplain/) | Запись EGG, которую можно распаковать без расшифровки. |
