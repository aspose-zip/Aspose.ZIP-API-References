## FromXz(Stream) {#fromxz}

Извлекает предоставленный архив в формате xz и создает [`TarArchive`](../) из извлечённых данных.

Важно: xz‑архив полностью извлекается в этом методе, его содержимое хранится во внутренней памяти. Будьте внимательны к потреблению памяти.

```csharp
public static TarArchive FromXz(Stream source)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| source | Stream | Источник архива. |

### Возвращаемое значение

Экземпляр [`TarArchive`](../)

### Исключения

| исключение | условие |
| --- | --- |
| EndOfStreamException | Выбрасывается, когда конец потока достигается до чтения ожидаемого количества байтов. |
| ObjectDisposedException | Выбрасывается, если исходный поток был освобождён. |
| ArgumentNullException | *source* равен null. |
| IOException | Произошла ошибка ввода/вывода. |
| InvalidDataException | Выбрасывается, когда данные недействительны или повреждены. |
| InvalidOperationException | Заголовки архива и служебная информация не были прочитаны. |

## Примечания

Tar‑архив предоставляет возможность извлекать произвольные записи, поэтому он должен работать с перемещаемым потоком в основе.

## FromXz(string) {#fromxz_1}

Извлекает предоставленный архив в формате xz и создает [`TarArchive`](../) из извлечённых данных.

Важно: xz‑архив полностью извлекается в этом методе, его содержимое хранится во внутренней памяти. Будьте внимательны к потреблению памяти.

```csharp
public static TarArchive FromXz(string path)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| path | String | Путь к файлу архива. |

### Возвращаемое значение

Экземпляр [`TarArchive`](../)

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentNullException | *path* имеет значение null. |
| ArgumentException | *path* пустой, содержит только пробелы или содержит недопустимые символы. |
| UnauthorizedAccessException | Доступ к файлу *path* запрещён. |
| PathTooLongException | Указанный *path*, имя файла или оба превышают системно определённую максимальную длину. Например, на платформах Windows пути должны быть короче 248 символов, а имена файлов — короче 260 символов. |
| NotSupportedException | Файл по пути *path* имеет недопустимый формат. |
| DirectoryNotFoundException | Указанный путь недействителен, например, находится на не смонтированном диске. |
| FileNotFoundException | Файл не найден. |
| EndOfStreamException | Выбрасывается, когда конец потока достигается до чтения ожидаемого количества байтов. |
| IOException | Во время открытия файла произошла ошибка ввода/вывода. |

## Примечания

Tar‑архив предоставляет возможность извлекать произвольные записи, поэтому он должен работать с перемещаемым потоком в основе.
