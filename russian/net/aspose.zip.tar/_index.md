Пространство имен Tar содержит классы, представляющие сущности, связанные с архивом tar.

## Классы

| Класс | Описание |
| --- | --- |
| [TarArchive](./tararchive/) | Этот класс представляет файл архива tar. Используйте его для создания, извлечения или обновления архивов tar. |
| [TarEntry](./tarentry/) | Представляет отдельный файл в архиве tar. |
| [TarLoadOptions](./tarloadoptions/) | Параметры, с помощью которых [`TarArchive`](../aspose.zip.tar/tararchive/) загружается из сжатого файла. |
