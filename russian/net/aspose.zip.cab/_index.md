Пространство имён Cab содержит классы, представляющие сущности, связанные с архивом Cab.

## Классы

| Класс | Описание |
| --- | --- |
| [CabArchive](./cabarchive/) | Этот класс представляет файл архива CAB. |
| [CabCompressionSettings](./cabcompressionsettings/) | Настройки, необходимые для работы компрессора CAB. |
| [CabEntry](./cabentry/) | Представляет отдельный файл внутри архива CAB. |
| [CabEntrySettings](./cabentrysettings/) | Настройки, определяющие, как записывается запись CAB. |
| [CabLoadOptions](./cabloadoptions/) | Параметры, с помощью которых архив загружается из сжатого файла. |
| [CabMsZipCompressionSettings](./cabmszipcompressionsettings/) | Настройки сжатия, которые кодируют блоки данных CAB с использованием сжатия MSZip (deflate). |
| [CabSaveOptions](./cabsaveoptions/) | Параметры сохранения архива CAB. |
| [CabStoreCompressionSettings](./cabstorecompressionsettings/) | Настройки сжатия, которые оставляют блоки данных CAB несжатыми. |
