## LzmaArchiveSettings.LiteralContextBits property

Получает или задает количество битов контекста литералов.

```csharp
public int LiteralContextBits { get; set; }
```

## Примечания

Биты контекста литералов определяют, сколько старших битов предыдущего несжатого байта используется для предсказания битов следующего литерального байта. Должно быть от 0 до 8.
