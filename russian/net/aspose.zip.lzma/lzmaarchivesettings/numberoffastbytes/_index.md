## LzmaArchiveSettings.NumberOfFastBytes property

Получает или задает количество байтов, используемых для быстрого поиска совпадений в алгоритме LZMA.

```csharp
public int NumberOfFastBytes { get; set; }
```

## Примечания

Большее значение позволяет компрессору искать более длинные совпадения, что может немного улучшить коэффициент сжатия, но замедляет процесс сжатия.
