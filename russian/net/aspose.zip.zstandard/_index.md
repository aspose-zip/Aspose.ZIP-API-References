Пространство имен Zstandard содержит классы для работы с данными, сжатым алгоритмом Zstandard.

## Классы

| Класс | Описание |
| --- | --- |
| [ZstandardArchive](./zstandardarchive/) | Этот класс представляет файл архива Zstandard. Используйте его для создания архивов Zstandard. |
| [ZstandardLoadOptions](./zstandardloadoptions/) | Параметры, с помощью которых [`ZstandardArchive`](../aspose.zip.zstandard/zstandardarchive/) загружается из сжатого файла. Содержит событие, вызываемое при извлечении. |
| [ZstandardSaveOptions](./zstandardsaveoptions/) | Настройки для архива ZStandard. |
