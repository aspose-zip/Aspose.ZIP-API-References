Пространство имён Iso содержит классы, представляющие сущности, связанные с ISO.

## Классы

| Класс | Описание |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Аргументы события для связанных с записью событий. |
| [EventsBag](./eventsbag/) | Контейнер событий, используемый при сохранении [`IsoArchive`](../aspose.zip.iso/isoarchive/). |
| [IsoArchive](./isoarchive/) | Представляет ISO‑архив (ISO 9660). |
| [IsoEntry](./isoentry/) | Представляет запись (файл или каталог) в ISO‑архиве. |
| [IsoLoadOptions](./isoloadoptions/) | Параметры, с помощью которых [`IsoArchive`](../aspose.zip.iso/isoarchive/) загружается из сжатого файла. Содержит событие, вызываемое при извлечении. |
| [IsoSaveOptions](./isosaveoptions/) | Параметры сохранения ISO‑архива. |
