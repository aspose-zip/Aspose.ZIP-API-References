## AppleArchive.IsSolid property

Возвращает значение, указывающее, использует ли архив сплошное сжатие. В сплошном режиме все данные записей сжаты в один поток, и отдельное извлечение записей недоступно. Используйте [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/) вместо этого.

public bool IsSolid { get; }
