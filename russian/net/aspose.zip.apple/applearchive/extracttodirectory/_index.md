## AppleArchive.ExtractToDirectory method

Извлекает все файлы из архива в указанный каталог.

```csharp
public void ExtractToDirectory(string destinationDirectory)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| destinationDirectory | String | Путь к директории, в которую следует поместить извлечённые файлы. |

### Исключения

| исключение | условие |
| --- | --- |
| EndOfStreamException | Поток неожиданно заканчивается во время извлечения сплошного архива. |
| InvalidDataException | Данные архива повреждены, либо символическая ссылка небезопасна. |
| PlatformNotSupportedException | Создание символических ссылок не поддерживается текущей средой выполнения. |
