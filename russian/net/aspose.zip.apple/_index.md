Пространство имён Apple содержит классы, представляющие сущности, связанные с Apple Archive.

## Классы

| Класс | Описание |
| --- | --- |
| [AppleArchive](./applearchive/) | Этот класс представляет файл Apple Archive (.aar). Используйте его для создания файлов Apple Archive. |
| [AppleArchiveEntry](./applearchiveentry/) | Представляет запись файловой системы внутри [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | Настройки, используемые для создания записей внутри [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | Параметры, с помощью которых [`AppleArchive`](../aspose.zip.apple/applearchive/) загружается из сжатого файла. |
| [AppleCompressionSettings](./applecompressionsettings/) | Настройки, необходимые для сжатия записей Apple Archive. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Настройки сжатия LZ4 внутри файла Apple Archive (.aar). |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Настройки сжатия LZFSE внутри файла Apple Archive (.aar). |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Настройки сжатия LZMA внутри файла Apple Archive (.aar). |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Настройки хранения (без сжатия) внутри файла Apple Archive (.aar). |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Настройки сжатия Zlib внутри файла Apple Archive (.aar). |
