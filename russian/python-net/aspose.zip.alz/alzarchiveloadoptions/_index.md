## AlzArchiveLoadOptions class

Параметры, с помощью которых архив ALZ загружается из сжатого файла.

Тип AlzArchiveLoadOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| AlzArchiveLoadOptions() | Инициализирует новый экземпляр класса AlzArchiveLoadOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| decryption_password | Получает или задает пароль для расшифровки записей. |
| encoding | Получает или задает кодировку имен записей. По умолчанию используется корейская кодовая страница Windows 949 (CP949). |
| skip_checksum_verification | Получает или задает значение, указывающее, следует ли пропускать проверку контрольной суммы записей ALZ и игнорировать несоответствия. По умолчанию — false. |
