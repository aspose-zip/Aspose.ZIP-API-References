## AlzEntryEncrypted class

Запись ALZ, которую необходимо расшифровать перед декомпрессией.

Тип AlzEntryEncrypted раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| compressed_size | Сжатый размер данных файла в байтах. |
| uncompressed_size | Несжатый размер данных файла в байтах. |
| length | Получает длину записи в байтах. |
| is_directory | Возвращает true, если эта запись представляет каталог. |
| name | Имя файла (без пути). |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path, password) | Извлекает запись в файловую систему по указанному пути. |
| extract(destination, password) | Извлекает запись в предоставленный поток. |
| extract(path) | Извлекает запись в файловую систему по указанному пути. |
| extract(destination) | Извлекает запись в предоставленный поток. |
