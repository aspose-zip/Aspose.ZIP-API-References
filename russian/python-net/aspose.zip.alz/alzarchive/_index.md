## AlzArchive class

Этот класс представляет файл архива ALZ. Используйте его для извлечения архивов ALZ.

Тип AlzArchive раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| AlzArchive(stream, load_options) | Инициализирует новый экземпляр класса [AlzArchive](/zip/python-net/aspose.zip.alz/alzarchive/) из потока. |
| AlzArchive(file_path, load_options) | Инициализирует новый экземпляр класса [AlzArchive](/zip/python-net/aspose.zip.alz/alzarchive/) из пути к файлу. |
## Свойства
| Имя | Описание |
| :- | :- |
| entries | Получает список файлов в архиве. |
| file_entries | Получает записи типа [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/), составляющие архив. |
| format | Возвращает формат архива. |
## Методы
| Имя | Описание |
| :- | :- |
| extract_to_directory(destination_directory) | Извлекает все файлы и каталоги из архива в указанную директорию. |
