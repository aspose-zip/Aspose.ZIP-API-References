## LzmaArchive class

Этот класс представляет файл архива LZMA. Используйте его для создания или извлечения архивов LZMA.

Тип LzmaArchive раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LzmaArchive(settings) | Создаёт новый экземпляр класса [LzmaArchive](/zip/python-net/aspose.zip.lzma/lzmaarchive/) и формирует архив в формате lzma. |
| LzmaArchive(source) | Создаёт новый экземпляр класса [LzmaArchive](/zip/python-net/aspose.zip.lzma/lzmaarchive/) для распаковки. |
| LzmaArchive(path) | Создаёт новый экземпляр класса [LzmaArchive](/zip/python-net/aspose.zip.lzma/lzmaarchive/) для распаковки. |
## Свойства
| Имя | Описание |
| :- | :- |
| file_entries | Получает записи типа [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/), составляющие архив. |
| format | Возвращает формат архива. |
| name | Получает имя записи. |
| length | Получает длину записи в байтах. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(destination) | Извлекает архив lzma в поток. |
| extract(file_info) | Извлекает архив lzma в файл. |
| extract(path) | Извлекает архив lzma в файл по пути. |
| set_source(source) | Устанавливает содержимое, которое будет сжато в архиве. |
| set_source(file_info) | Устанавливает содержимое, которое будет сжато в архиве. |
| set_source(source_path) | Устанавливает содержимое, которое будет сжато в архиве. |
| save(output) | Сохраняет архив lzma в указанный поток. |
| save(destination) | Сохраняет архив lzma в указанный файл назначения. |
| save(destination_file_name) | Сохраняет архив lzma в указанный файл назначения. |
| extract_to_directory(destination_directory) | Извлекает содержимое архива в предоставленный каталог. |
