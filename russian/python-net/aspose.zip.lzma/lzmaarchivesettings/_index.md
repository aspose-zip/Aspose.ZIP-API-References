## LzmaArchiveSettings class

Настройки архива lzma.

Тип LzmaArchiveSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LzmaArchiveSettings() | Создаёт новый экземпляр класса [LzmaArchiveSettings](/zip/python-net/aspose.zip.lzma/lzmaarchivesettings/) с размером словаря по умолчанию, равным 16 мегабайт, количеством быстрых байтов, равным 32, и битами контекста литералов, равными 3. |
## Свойства
| Имя | Описание |
| :- | :- |
| dictionary_size | Размер словаря (буфера истории) указывает, сколько байт недавно обработанных несжатых данных хранится в памяти.<br/>            Если не задан, будет выбран в соответствии с размером записи. |
| number_of_fast_bytes | Получает или задаёт количество байт, используемых для быстрого поиска совпадений в алгоритме LZMA. |
| literal_context_bits | Получает или задаёт количество битов контекста литералов. |
