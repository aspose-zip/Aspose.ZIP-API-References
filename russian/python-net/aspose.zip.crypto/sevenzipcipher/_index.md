## SevenZipCipher class

Базовый класс для шифра AES, используемого в шифровании 7-zip.

Тип SevenZipCipher раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| can_reuse_transform | Получает значение, указывающее, может ли текущая трансформация быть переиспользована. |
| can_transform_multiple_blocks | Получает значение, указывающее, могут ли быть преобразованы несколько блоков. |
| input_block_size | Получает размер входного блока. |
| output_block_size | Получает размер выходного блока. |
## Методы
| Имя | Описание |
| :- | :- |
| transform_block(input_buffer, input_offset, input_count, output_buffer, output_offset) | Преобразует указанную область входного массива байтов и копирует полученное преобразование в указанную область выходного массива байтов. |
| transform_final_block(input_buffer, input_offset, input_count) | Преобразует указанную область указанного массива байтов. |
