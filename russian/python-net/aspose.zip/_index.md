Содержит классы, представляющие zip‑архив и общие связанные с архивом сущности.

## Классы
| Класс | Описание |
| :- | :- |
| [Archive](/zip/python-net/aspose.zip/archive/) | Этот класс представляет файл zip‑архива. Используйте его для создания, извлечения или обновления zip‑архивов. |
| [ArchiveEntry](/zip/python-net/aspose.zip/archiveentry/) | Представляет отдельный файл внутри архива. |
| [ArchiveEntryEncrypted](/zip/python-net/aspose.zip/archiveentryencrypted/) | Элемент Zip, который необходимо сжать с шифрованием или распаковать с дешифрованием. |
| [ArchiveEntryPlain](/zip/python-net/aspose.zip/archiveentryplain/) | Элемент Zip, который необходимо сжать без шифрования или распаковать без дешифрования. |
| [ArchiveFactory](/zip/python-net/aspose.zip/archivefactory/) | Определяет формат архива и создает соответствующий объект [IArchive](/zip/python-net/aspose.zip/iarchive/) в зависимости от типа архива. |
| [ArchiveLoadOptions](/zip/python-net/aspose.zip/archiveloadoptions/) | Параметры, с помощью которых ZIP‑архив загружается из сжатого файла. |
| [CancelEntryEventArgs](/zip/python-net/aspose.zip/cancelentryeventargs/) | Аргументы события для отменяемых событий, связанных с элементом. |
| [ComHelper](/zip/python-net/aspose.zip/comhelper/) | Предоставляет методы для COM‑клиентов для загрузки архивов в Aspose.Zip. |
| [EntryEventArgs](/zip/python-net/aspose.zip/entryeventargs/) | Аргументы события для событий, связанных с элементами. |
| [IArchive](/zip/python-net/aspose.zip/iarchive/) | Этот интерфейс представляет архив. |
| [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) | Этот интерфейс представляет элемент файла архива. |
| [License](/zip/python-net/aspose.zip/license/) | Предоставляет методы для лицензирования компонента. |
| [MeteredLicense](/zip/python-net/aspose.zip/meteredlicense/) | Предоставляет методы для установки измеряемого ключа. |
| [ProgressCancelEventArgs](/zip/python-net/aspose.zip/progresscanceleventargs/) | Класс для отменяемых данных события, содержащих количество обработанных байтов. |
| [ProgressEventArgs](/zip/python-net/aspose.zip/progresseventargs/) | Класс для данных события, содержащих количество обработанных байтов. |
