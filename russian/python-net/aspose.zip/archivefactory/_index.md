## ArchiveFactory class

Определяет формат архива и создает соответствующий объект [IArchive](/zip/python-net/aspose.zip/iarchive/) в зависимости от типа архива.

Тип ArchiveFactory раскрывает следующие члены:
## Методы
| Имя | Описание |
| :- | :- |
| get_archive(path) | Определяет формат архива и создает соответствующий объект [IArchive](/zip/python-net/aspose.zip/iarchive/) в соответствии с типом архива, указанного в заданном пути. |
| get_archive(stream) | Определяет формат архива и создает соответствующий объект [IArchive](/zip/python-net/aspose.zip/iarchive/) в соответствии с типом архива, указанным в данном потоке. |
| get_archive(stream, password) | Определяет формат архива и создает соответствующий объект [IArchive](/zip/python-net/aspose.zip/iarchive/) в соответствии с типом зашифрованного архива, указанным в данном потоке. |
| compress_directory(path, output_file_name, archive_format) | Сжимает указанный каталог в архивный файл, используя предоставленный формат архива. |
