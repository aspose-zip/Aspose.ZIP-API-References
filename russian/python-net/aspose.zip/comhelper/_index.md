## ComHelper class

Предоставляет методы для COM‑клиентов для загрузки архивов в Aspose.Zip.

Тип ComHelper раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ComHelper() | Инициализирует новый экземпляр этого класса. |
## Методы
| Имя | Описание |
| :- | :- |
| open_gzip(stream) | Позволяет COM‑приложению загрузить gzip‑архив из потока. |
| open_gzip(file_name) | Позволяет COM‑приложению загрузить gzip‑архив из файла. |
| open_zip(stream) | Позволяет COM‑приложению загрузить ZIP‑архив из потока. |
| open_zip(file_name) | Позволяет COM‑приложению загрузить ZIP‑архив из файла. |
| open_rar(stream) | Позволяет COM‑приложению загрузить rar‑архив из потока. |
| open_rar(file_name) | Позволяет COM‑приложению загрузить rar‑архив из файла. |
| open_bzip2(stream) | Позволяет COM‑приложению загрузить bzip2‑архив из потока. |
| open_bzip2(file_name) | Позволяет COM‑приложению загрузить bzip2‑архив из файла. |
