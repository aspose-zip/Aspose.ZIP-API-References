## ArchiveLoadOptions class

Параметры, с помощью которых ZIP‑архив загружается из сжатого файла.

Тип ArchiveLoadOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ArchiveLoadOptions() | Инициализирует новый экземпляр класса ArchiveLoadOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| decryption_password | Получает или задает пароль для расшифровки записей. |
| encoding | Получает или задает кодировку для имён записей. |
| skip_checksum_verification | Получает или задает значение, указывающее, следует ли пропускать проверку контрольной суммы записей ZIP и игнорировать несоответствия. По умолчанию false. |
| forward_only | Архив извлекается из потока только для чтения. |
