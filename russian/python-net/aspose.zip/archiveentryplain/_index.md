## ArchiveEntryPlain class

Элемент Zip, который необходимо сжать без шифрования или распаковать без дешифрования.

Тип ArchiveEntryPlain раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| compressed_size | Возвращает размер сжатого файла. |
| name | Возвращает имя элемента в архиве. |
| comment | Возвращает комментарий к элементу в архиве. |
| uncompressed_size | Возвращает размер оригинального файла. |
| modification_time | Получает или задает дату и время последнего изменения. |
| is_directory | Возвращает значение, указывающее, является ли элемент каталогом. |
| data_source | Источник для элемента, если элемент был добавлен в архив, а не извлечён. |
| compression_settings | Получает настройки для сжатия или распаковки. |
| length | Получает длину записи в байтах. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path, password) | Извлекает запись в файловую систему по указанному пути. |
| extract(destination, password) | Извлекает запись в предоставленный поток. |
| extract(path) | Извлекает запись в файловую систему по указанному пути. |
| extract(destination) | Извлекает запись в предоставленный поток. |
| open(password) | Открывает запись для извлечения и предоставляет поток с распакованным содержимым записи. |
