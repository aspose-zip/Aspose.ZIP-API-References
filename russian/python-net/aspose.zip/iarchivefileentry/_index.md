## IArchiveFileEntry class

Этот интерфейс представляет элемент файла архива.

Тип IArchiveFileEntry раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| name | Получает имя записи. |
| length | Получает длину записи в байтах. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path) | Извлекает запись в файловую систему по указанному пути. |
| extract(destination) | Извлекает запись в предоставленный поток. |
