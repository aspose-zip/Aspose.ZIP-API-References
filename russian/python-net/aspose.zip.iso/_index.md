Содержит классы, представляющие связанные с архивом Iso сущности.

## Классы
| Класс | Описание |
| :- | :- |
| [EntryEventArgs](/zip/python-net/aspose.zip.iso/entryeventargs/) | Аргументы события для событий, связанных с элементами. |
| [EventsBag](/zip/python-net/aspose.zip.iso/eventsbag/) | Контейнер событий, используемый при сохранении [IsoArchive](/zip/python-net/aspose.zip.iso/isoarchive/). |
| [IsoArchive](/zip/python-net/aspose.zip.iso/isoarchive/) | Представляет ISO‑архив (ISO 9660). |
| [IsoEntry](/zip/python-net/aspose.zip.iso/isoentry/) | Представляет элемент (файл или каталог) внутри ISO‑архива. |
| [IsoLoadOptions](/zip/python-net/aspose.zip.iso/isoloadoptions/) | Параметры, с помощью которых [IsoArchive](/zip/python-net/aspose.zip.iso/isoarchive/) загружается из сжатого файла. Содержит событие, вызываемое при извлечении. |
| [IsoSaveOptions](/zip/python-net/aspose.zip.iso/isosaveoptions/) | Параметры для сохранения ISO‑архива. |
