## IsoEntry class

Представляет элемент (файл или каталог) внутри ISO‑архива.

Тип IsoEntry раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| name | Получает имя записи. |
| is_directory | Получает значение, указывающее, является ли запись каталогом. |
| length | Получает или задает дату и время создания. |
| modification_time | Получает или задает дату и время последнего изменения. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path) | Извлекает запись в файловую систему по указанному пути. |
| extract(destination) | Извлекает запись в предоставленный поток. |
