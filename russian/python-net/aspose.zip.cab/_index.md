Содержит классы, представляющие связанные с архивом Cab сущности.

## Классы
| Класс | Описание |
| :- | :- |
| [CabArchive](/zip/python-net/aspose.zip.cab/cabarchive/) | Этот класс представляет файл архива CAB. |
| [CabCompressionSettings](/zip/python-net/aspose.zip.cab/cabcompressionsettings/) | Настройки, необходимые для работы компрессора CAB. |
| [CabEntry](/zip/python-net/aspose.zip.cab/cabentry/) | Представляет отдельный файл внутри архива CAB. |
| [CabEntrySettings](/zip/python-net/aspose.zip.cab/cabentrysettings/) | Настройки, определяющие, как записывается запись CAB. |
| [CabLoadOptions](/zip/python-net/aspose.zip.cab/cabloadoptions/) | Параметры, с помощью которых архив загружается из сжатого файла. |
| [CabMsZipCompressionSettings](/zip/python-net/aspose.zip.cab/cabmszipcompressionsettings/) | Настройки сжатия, которые кодируют блоки данных CAB с использованием сжатия MSZip (deflate). |
| [CabSaveOptions](/zip/python-net/aspose.zip.cab/cabsaveoptions/) | Параметры сохранения архива CAB. |
| [CabStoreCompressionSettings](/zip/python-net/aspose.zip.cab/cabstorecompressionsettings/) | Настройки сжатия, сохраняющие блоки данных CAB без сжатия. |
