| [ZstandardLoadOptions](/zip/python-net/aspose.zip.zstandard/zstandardloadoptions/) | Параметры, с помощью которых [ZstandardArchive](/zip/python-net/aspose.zip.zstandard/zstandardarchive/) загружается из сжатого файла. Содержит событие, вызываемое при извлечении. |
| [ZstandardSaveOptions](/zip/python-net/aspose.zip.zstandard/zstandardsaveoptions/) | Настройки для архива ZStandard. |
