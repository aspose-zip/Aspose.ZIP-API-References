## Lz4ArchiveSetting class

Настройки создания архива LZ4.

Тип Lz4ArchiveSetting раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Lz4ArchiveSetting() | Инициализирует новый экземпляр [Lz4ArchiveSetting](/zip/python-net/aspose.zip.lz4/lz4archivesetting/) с параметрами по умолчанию. |
## Свойства
| Имя | Описание |
| :- | :- |
| include_content_checksum | Получает или задает значение, указывающее, включать ли xxh32‑хеш содержимого в конец архива LZ4. |
| include_block_checksum | Получает или задает значение, указывающее, включать ли xxh32‑хеш сжатого блока в конец сжатого блока. |
| include_content_size | Получает или задает значение, указывающее, включать ли размер содержимого в кадр. |
