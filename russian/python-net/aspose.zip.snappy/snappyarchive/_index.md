## SnappyArchive class

Этот класс представляет файл архива snappy. Используйте его для создания или извлечения архивов snappy.

Тип SnappyArchive раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SnappyArchive() | Инициализирует новый экземпляр класса [SnappyArchive](/zip/python-net/aspose.zip.snappy/snappyarchive/) для сжатия. |
| SnappyArchive(source) | Инициализирует новый экземпляр класса [SnappyArchive](/zip/python-net/aspose.zip.snappy/snappyarchive/) для распаковки. |
| SnappyArchive(path) | Инициализирует новый экземпляр класса [SnappyArchive](/zip/python-net/aspose.zip.snappy/snappyarchive/) для распаковки. |
## Свойства
| Имя | Описание |
| :- | :- |
| file_entries | Получает записи типа [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/), составляющие архив. |
| format | Возвращает формат архива. |
| name | Получает имя записи. |
| length | Получает длину записи в байтах. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(destination) | Извлекает snappy‑архив в поток. |
| extract(file_info) | Извлекает snappy‑архив в файл. |
| extract(path) | Извлекает snappy‑архив в файл по пути. |
| set_source(source) | Устанавливает содержимое, которое будет сжато в архиве. |
| set_source(file_info) | Устанавливает содержимое, которое будет сжато в архиве. |
| set_source(source_path) | Устанавливает содержимое, которое будет сжато в архиве. |
| save(output) | Сохраняет snappy‑архив в указанный поток. |
| save(destination) | Сохраняет snappy‑архив в указанный файл назначения. |
| save(destination_file_name) | Сохраняет snappy‑архив в указанный файл назначения. |
| extract_to_directory(destination_directory) | Извлекает содержимое архива в предоставленный каталог. |
