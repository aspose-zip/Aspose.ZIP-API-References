## ArchiveEntrySettings class

Настройки, используемые для сжатия или распаковки элементов.

Тип ArchiveEntrySettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ArchiveEntrySettings(compression_settings, encryption_settings) | Инициализирует новый экземпляр класса [ArchiveEntrySettings](/zip/python-net/aspose.zip.saving/archiveentrysettings/). |
## Свойства
| Имя | Описание |
| :- | :- |
| compression_settings | Получает настройки для процедуры сжатия или распаковки. |
| encryption_settings | Получает настройки для шифрования или дешифрования. Настройки конкретной записи могут различаться. |
| comment | Комментарий к записи в ZIP-архиве. |
