## SplitArchiveSaveOptions class

Параметры сохранения многотомного ZIP-архива.

Тип SplitArchiveSaveOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SplitArchiveSaveOptions(file_name, segment_size) | Создаёт настройки для сохранения многотомного ZIP‑архива. |
## Свойства
| Имя | Описание |
| :- | :- |
| segment_size | Получает размер сегмента. |
| file_name | Получает имя сегментов без расширения. |
| archive_comment | Получает или задает необязательный комментарий для Zip‑файла. |
| encoding | Получает или задает кодировку для преобразования имен файлов и других строк в байты. |
| close_entry_source | Получает или задает значение, указывающее, следует ли закрывать источники записей сразу после сжатия записи. |
| events_bag | Получает или задает контейнер событий, возникающих при сохранении архива. |
