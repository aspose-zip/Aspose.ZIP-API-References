## ParallelOptions class

Параметры параллельного сжатия.

Тип ParallelOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ParallelOptions() | Инициализирует новый экземпляр класса ParallelOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| parallel_compress_in_memory | Получает или задает значение, указывающее, как будет использоваться параллельный подход. |
| available_memory_size | Получает или задает оценку памяти в мегабайтах, доступную для размещения сжатых записей без выгрузки на диск.<br/>            Это значение имеет смысл только если параметр [parallel_compress_in_memory](/zip/python-net/aspose.zip.saving/paralleloptions/) установлен в режим [AUTO](/zip/python-net/aspose.zip.saving/parallelcompressionmode/). |
