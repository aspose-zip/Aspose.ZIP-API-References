## ParallelCompressionMode enumeration

Параметры использования возможности параллельного сжатия.

## Members
| Имя члена | Описание |
| :- | :- |
| NEVER | Не выполнять сжатие параллельно. |
| ALWAYS | Выполнять сжатие параллельно. Будьте осторожны, это может привести к повышенному потреблению памяти. |
| AUTO | Решить, будет ли использоваться параллельное сжатие, исходя из записей.<br/>            Эта опция может сжимать параллельно только некоторые записи. |
