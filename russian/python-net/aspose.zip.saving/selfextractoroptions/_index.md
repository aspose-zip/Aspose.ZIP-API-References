## SelfExtractorOptions class

Параметры создания самораспаковывающегося исполняемого архива.

Тип SelfExtractorOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SelfExtractorOptions() | Инициализирует новый экземпляр класса SelfExtractorOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| extractor_title | Получает или задает заголовок окна извлекателя. |
| title_icon | Получает или задает путь к значку заголовка для основных окон приложения‑извлекателя. |
| close_window_on_extraction | Получает или задает значение, указывающее, должно ли окно извлекателя закрываться после извлечения или нет. |
| run_after_extraction | Получает или задает программу, которая будет выполнена после завершения извлечения архива. |
