## SevenZipAESEncryptionSettings class

Настройки алгоритма шифрования или дешифрования AES внутри 7z-архива.

Тип SevenZipAESEncryptionSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SevenZipAESEncryptionSettings(password) | Инициализирует новый экземпляр класса [SevenZipAESEncryptionSettings](/zip/python-net/aspose.zip.saving/sevenzipaesencryptionsettings/). |
| SevenZipAESEncryptionSettings(cipher) | Инициализирует новый экземпляр класса [SevenZipAESEncryptionSettings](/zip/python-net/aspose.zip.saving/sevenzipaesencryptionsettings/) с внешним шифром. |
## Свойства
| Имя | Описание |
| :- | :- |
| пароль | Получает или задает пароль для шифрования или дешифрования. |
| encrypt_header | Получает или задает значение, указывающее на шифрование заголовка. |
