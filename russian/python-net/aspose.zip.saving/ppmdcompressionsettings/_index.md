## PPMdCompressionSettings class

Настройки сжатия PPMd внутри ZIP-архива.

Тип PPMdCompressionSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PPMdCompressionSettings(model_order, suballocator_size) | Инициализирует новый экземпляр класса PPMdCompressionSettings |
| PPMdCompressionSettings() | Инициализирует новый экземпляр класса [PPMdCompressionSettings](/zip/python-net/aspose.zip.saving/ppmdcompressionsettings/). |
