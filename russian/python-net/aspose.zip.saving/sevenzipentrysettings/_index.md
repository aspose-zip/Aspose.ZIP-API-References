## SevenZipEntrySettings class

Настройки, используемые для сжатия или распаковки записей 7Z.

Тип SevenZipEntrySettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SevenZipEntrySettings(compression_settings, encryption_settings) | Инициализирует новый экземпляр класса [SevenZipEntrySettings](/zip/python-net/aspose.zip.saving/sevenzipentrysettings/). |
## Свойства
| Имя | Описание |
| :- | :- |
| compression_settings | Получает настройки для процедуры сжатия или распаковки. |
| encryption_settings | Получает настройки для шифрования или дешифрования. Настройки конкретной записи могут различаться. |
| compress_header | Получает или задает значение, указывающее, следует ли сжимать заголовок архива. |
| solid | Получает или задает значение, указывающее, следует ли объединять записи и рассматривать их как единый блок данных. |
