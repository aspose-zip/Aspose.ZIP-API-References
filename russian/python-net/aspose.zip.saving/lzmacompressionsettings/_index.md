## LzmaCompressionSettings class

Настройки сжатия LZMA внутри ZIP архива.

Тип LzmaCompressionSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LzmaCompressionSettings() | Инициализирует новый экземпляр класса [LzmaCompressionSettings](/zip/python-net/aspose.zip.saving/lzmacompressionsettings/) с параметрами по умолчанию. |
| LzmaCompressionSettings(dictionary_size, number_of_fast_bytes, literal_context_bits) | Инициализирует новый экземпляр класса LzmaCompressionSettings |
| LzmaCompressionSettings(dictionary_size) | Инициализирует новый экземпляр класса LzmaCompressionSettings |
## Свойства
| Имя | Описание |
| :- | :- |
| bzip2 | Экземпляр |
| deflate | Экземпляр |
| enhanced_deflate | Экземпляр |
| store | Экземпляр |
| lzma | Экземпляр |
| xz | Экземпляр |
| pp_md | Экземпляр |
| zstd | Экземпляр |
| dictionary_size | Размер словаря (буфера истории) указывает, сколько байтов недавно обработанных несжатых данных хранится в памяти. |
| number_of_fast_bytes | Получает количество байтов, используемых для быстрого поиска совпадений в алгоритме LZMA. |
| literal_context_bits | Получает количество битов контекста литералов. |
