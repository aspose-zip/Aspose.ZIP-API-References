## LzipArchiveSettings class

Класс содержит настройки конкретного lzip архива.

Тип LzipArchiveSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LzipArchiveSettings(dictionary_size, max_member_size) | Инициализирует новый экземпляр [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) с определённым размером словаря. |
## Свойства
| Имя | Описание |
| :- | :- |
| fastest_speed | Получает экземпляр класса [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            с размером словаря, равным 65536 байт, в фильтре LZMA. |
| fast_speed | Получает экземпляр класса [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            с размером словаря, равным 1 мегабайт, в фильтре LZMA. |
| normal | Получает экземпляр класса [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            с размером словаря, равным 16 мегабайт, в фильтре LZMA. |
| high_compression | Получает экземпляр класса [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            с размером словаря, равным 32 мегабайт, в фильтре LZMA. |
| maximum_compression | Получает экземпляр класса [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            с размером словаря, равным 64 мегабайт, в фильтре LZMA. |
| dictionary_size | Получает размер словаря, используемого в сжатии LZMA. |
| max_member_size | Получает максимальный размер одного элемента в lzip-архиве в байтах. |
| compression_threads | Получает или задает количество потоков сжатия. Если значение больше 1, будет использоваться многопоточное сжатие. |
