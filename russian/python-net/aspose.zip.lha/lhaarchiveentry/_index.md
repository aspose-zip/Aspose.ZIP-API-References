## LhaArchiveEntry class

Представляет отдельный файл внутри архива Lha.

Тип LhaArchiveEntry раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| name | Получает имя записи. |
| length | Получает длину записи в байтах. |
| is_directory | Получает значение, указывающее, является ли этот элемент каталогом. |
| last_modified | Получает время последнего изменения элемента. |
| modification_time | Получает время последнего изменения элемента. |
| path | Получает полный путь к элементу. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path) | Извлекает запись архива Lha в файловую систему по пути. |
| extract(destination) | Извлекает запись в предоставленный поток. |
| extract(file_info) | Извлекает запись архива Lha в файл. |
