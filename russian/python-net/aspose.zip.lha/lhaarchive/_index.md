## LhaArchive class

Этот класс представляет файл архива LHA (.lzh).

Тип LhaArchive раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LhaArchive(source_stream, load_options) | Инициализирует новый экземпляр класса [LhaArchive](/zip/python-net/aspose.zip.lha/lhaarchive/) и формирует список записей, которые можно извлечь из архива. |
| LhaArchive(path, load_options) | Инициализирует новый экземпляр класса [LhaArchive](/zip/python-net/aspose.zip.lha/lhaarchive/) и формирует список записей, которые можно извлечь из архива. |
## Свойства
| Имя | Описание |
| :- | :- |
| entries | Получает файловые записи типа [LhaArchiveEntry](/zip/python-net/aspose.zip.lha/lhaarchiveentry/), составляющие архив. |
| file_entries | Получает записи типа [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/), составляющие архив. |
| format | Возвращает формат архива. |
## Методы
| Имя | Описание |
| :- | :- |
| extract_to_directory(destination_directory) | Извлекает все файлы и каталоги из архива в указанную директорию. |
