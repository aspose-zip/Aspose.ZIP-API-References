## XarDirectoryEntry class

Представляет запись каталога внутри архива xar.

Тип XarDirectoryEntry содержит следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| name | Возвращает имя элемента в архиве. |
| full_path | Получает полный путь к записи внутри архива. |
| is_directory | Возвращает значение, указывающее, является ли элемент каталогом. |
| parent | Возвращает родительский каталог, к которому принадлежит запись. |
| creation_time | Возвращает время создания файла или каталога. |
| last_access_time | Возвращает время последнего доступа к файлу или каталогу. |
| last_write_time | Получает время изменения файла или каталога. |
| modification_time | Получает время изменения файла или каталога. |
| files_and_directories | Получает записи типа [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/), составляющие каталог. |
| directories | Получает записи типа [XarDirectoryEntry](/zip/python-net/aspose.zip.xar/xardirectoryentry/), составляющие каталог. |
| files | Получает записи типа [XarFileEntry](/zip/python-net/aspose.zip.xar/xarfileentry/), составляющие каталог. |
| all_entries | Получает все записи типа [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/), составляющие каталог рекурсивно. |
## Методы
| Имя | Описание |
| :- | :- |
| extract_to_directory(destination_directory) | Извлекает все файлы из текущего каталога в указанный каталог. |
