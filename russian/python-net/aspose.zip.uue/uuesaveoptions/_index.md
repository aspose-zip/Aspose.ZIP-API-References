## UueSaveOptions class

Параметры сохранения uuencoded файла.

Тип UueSaveOptions предоставляет следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| UueSaveOptions(file_name, new_line) | Инициализирует параметры с указанным пользователем именем файла и символом новой строки. |
| UueSaveOptions(file_name) | Инициализирует параметры с указанным пользователем именем файла и символом новой строки. |
## Свойства
| Имя | Описание |
| :- | :- |
| new_line | Получает символ, завершающий каждую строку, обычно "\n" или "\r\n". |
| file_name | Получает имя файла, которое будет использоваться при воссоздании декодированных данных. |
| unix_file_permissions | Получает Unix-разрешения файла. |
