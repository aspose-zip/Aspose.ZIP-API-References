## XzArchiveSettings class

Класс содержит набор настроек конкретного xz архива.

Тип XzArchiveSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| XzArchiveSettings() | Инициализирует новый экземпляр класса [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) с использованием одиночного сжатия LZMA2. |
| XzArchiveSettings(filters, block_size, check_type) | Инициализирует новый экземпляр класса [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) с пользовательскими параметрами. |
## Свойства
| Имя | Описание |
| :- | :- |
| compression_threads | Получает или задает количество потоков сжатия. Если значение больше 1, будет использоваться многопоточное сжатие. |
| fastest_speed | Получает экземпляр класса [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            с размером словаря, равным 65536 байт, в фильтре LZMA2, размером блока, равным 1 мегабайт, и контрольной суммой CRC32. |
| fast_speed | Получает экземпляр класса [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            с размером словаря, равным 1 мегабайт, в фильтре LZMA2, размером блока, равным 4 мегабайта, и контрольной суммой CRC32. |
| normal | Получает экземпляр класса [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            с размером словаря, равным 16 мегабайт, в фильтре LZMA2, размером блока, равным 64 мегабайта, и контрольной суммой CRC32. |
| high_compression | Получает экземпляр класса [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            с размером словаря, равным 32 мегабайт, в фильтре LZMA2, размером блока, равным 128 мегабайта, и контрольной суммой CRC32. |
| maximum_compression | Получает экземпляр класса [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            с размером словаря, равным 64 мегабайт, в фильтре LZMA2, размером блока, равным 256 мегабайта, и контрольной суммой CRC32. |
