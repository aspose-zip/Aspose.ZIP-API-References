## XzCheckType enumeration

Перечисление определяет подход к вычислению контрольной суммы для xz архива.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Контрольная сумма не будет вычислена. |
| CRC32 | Контрольная сумма будет вычислена с использованием алгоритма CRC32. |
| CRC64 | Контрольная сумма будет вычислена с использованием алгоритма CRC64. |
