## Bzip2SaveOptions class

Параметры сохранения архива bzip2.

Тип Bzip2SaveOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Bzip2SaveOptions(block_size) | Инициализирует новый экземпляр класса Bzip2SaveOptions |
| Bzip2SaveOptions() | Инициализирует новый экземпляр класса [Bzip2SaveOptions](/zip/python-net/aspose.zip.bzip2/bzip2saveoptions/). |
## Свойства
| Имя | Описание |
| :- | :- |
| block_size | Размер блока в сотнях килобайт. |
| compression_threads | Получает или задает количество потоков сжатия. Если значение больше 1, будет использоваться многопоточное сжатие. |
