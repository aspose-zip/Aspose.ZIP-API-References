## AppleZlibCompressionSettings class

Настройки сжатия Zlib внутри файла Apple Archive (.aar).

Тип AppleZlibCompressionSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| AppleZlibCompressionSettings(block_size) | Инициализирует новый экземпляр класса AppleZlibCompressionSettings |
| AppleZlibCompressionSettings() | Инициализирует новый экземпляр класса [AppleZlibCompressionSettings](/zip/python-net/aspose.zip.apple/applezlibcompressionsettings/). |

| Имя | Описание |
| :- | :- |
