## AppleLzmaCompressionSettings class

Настройки сжатия LZMA внутри файла Apple Archive (.aar).

Тип AppleLzmaCompressionSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| AppleLzmaCompressionSettings(block_size, dictionary_size) | Инициализирует новый экземпляр класса AppleLzmaCompressionSettings |
| AppleLzmaCompressionSettings(block_size, dictionary_size, fast_bytes) | Инициализирует новый экземпляр класса AppleLzmaCompressionSettings |
| AppleLzmaCompressionSettings() | Инициализирует новый экземпляр класса [AppleLzmaCompressionSettings](/zip/python-net/aspose.zip.apple/applelzmacompressionsettings/). |
## Свойства
| Имя | Описание |
| :- | :- |
| lz4 | Экземпляр [AppleLz4CompressionSettings](/zip/python-net/aspose.zip.apple/applelz4compressionsettings/) с параметрами по умолчанию. |
| lzfse | Экземпляр [AppleLzfseCompressionSettings](/zip/python-net/aspose.zip.apple/applelzfsecompressionsettings/) с параметрами по умолчанию. |
| lzma | Экземпляр [AppleLzmaCompressionSettings](/zip/python-net/aspose.zip.apple/applelzmacompressionsettings/) с параметрами по умолчанию. |

| dictionary_size | Получает размер словаря, используемого для сжатия. |
