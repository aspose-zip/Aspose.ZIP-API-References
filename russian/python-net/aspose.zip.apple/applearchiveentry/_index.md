## AppleArchiveEntry class

Представляет запись файла или каталога внутри [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/).

Тип AppleArchiveEntry раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| name | Получает путь к записи внутри архива. |
| length | Получает несжатую длину записи в байтах. |
| is_directory | Возвращает значение, указывающее, является ли элемент каталогом. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path) | Извлекает запись в файловую систему по указанному пути. |
| extract(destination) | Извлекает запись в предоставленный поток. |
| open() | Открывает запись для извлечения и предоставляет поток с содержимым записи. |
