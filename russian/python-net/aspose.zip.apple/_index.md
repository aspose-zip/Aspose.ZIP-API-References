Содержит классы, представляющие связанные с архивом Apple сущности.

## Классы
| Класс | Описание |
| :- | :- |
| [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/) | Этот класс представляет файл Apple Archive (.aar). Используйте его для создания файлов Apple Archive. |
| [AppleArchiveEntry](/zip/python-net/aspose.zip.apple/applearchiveentry/) | Представляет запись файла или каталога внутри [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/). |
| [AppleArchiveEntrySettings](/zip/python-net/aspose.zip.apple/applearchiveentrysettings/) | Настройки, используемые для создания записей внутри [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/). |
| [AppleArchiveLoadOptions](/zip/python-net/aspose.zip.apple/applearchiveloadoptions/) | Параметры, с помощью которых [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/) загружается из сжатого файла. |
| [AppleCompressionSettings](/zip/python-net/aspose.zip.apple/applecompressionsettings/) | Настройки, необходимые для сжатия записей Apple Archive. |
| [AppleLz4CompressionSettings](/zip/python-net/aspose.zip.apple/applelz4compressionsettings/) | Настройки сжатия LZ4 внутри файла Apple Archive (.aar). |
| [AppleLzfseCompressionSettings](/zip/python-net/aspose.zip.apple/applelzfsecompressionsettings/) | Настройки сжатия LZFSE внутри файла Apple Archive (.aar). |
| [AppleLzmaCompressionSettings](/zip/python-net/aspose.zip.apple/applelzmacompressionsettings/) | Настройки сжатия LZMA внутри файла Apple Archive (.aar). |
| [AppleStoreCompressionSettings](/zip/python-net/aspose.zip.apple/applestorecompressionsettings/) | Настройки хранения (без сжатия) внутри файла Apple Archive (.aar). |
| [AppleZlibCompressionSettings](/zip/python-net/aspose.zip.apple/applezlibcompressionsettings/) | Настройки сжатия Zlib внутри файла Apple Archive (.aar). |
