## ArjEntryPlain class

Представляет отдельный файл внутри архива ARJ.

Тип ArjEntryPlain раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| name | Возвращает имя элемента в архиве. |
| compressed_size | Получает размер сжатого файла. |
| uncompressed_size | Получает размер оригинального файла. |
| length | Получает длину записи в байтах. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path) | Извлекает запись в файловую систему по указанному пути. |
| extract(file_info) | Извлекает запись ARJ-архива в файл. |
| extract(destination) | Извлекает запись в предоставленный поток. |
