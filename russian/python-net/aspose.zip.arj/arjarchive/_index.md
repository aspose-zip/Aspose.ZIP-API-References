## ArjArchive class

Этот класс представляет файл архива ARJ.

Тип ArjArchive раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ArjArchive(extraction_source, load_options) | Инициализирует новый экземпляр класса [ArjArchive](/zip/python-net/aspose.zip.arj/arjarchive/) и формирует список записей, которые могут быть извлечены из архива. |
| ArjArchive(path, load_options) | Инициализирует новый экземпляр класса [ArjArchive](/zip/python-net/aspose.zip.arj/arjarchive/) и формирует список записей, которые могут быть извлечены из архива. |
## Свойства
| Имя | Описание |
| :- | :- |
| entries | Получает записи типа [ArjEntryPlain](/zip/python-net/aspose.zip.arj/arjentryplain/), составляющие ARJ-архив. |
| комментарий | Получает комментарий. |
| name | Получает оригинальное имя. |
| file_entries | Получает записи типа [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/), составляющие архив. |
| format | Возвращает формат архива. |
## Методы
| Имя | Описание |
| :- | :- |
| extract_to_directory(destination_directory) | Извлекает все записи в указанный каталог. |
