## RarArchiveEntryEncrypted class

## Свойства
| Имя | Описание |
| :- | :- |
| name | Возвращает имя элемента в архиве. |
| compressed_size | Получает размер сжатого файла. |
| uncompressed_size | Получает размер оригинального файла. |
| modification_time | Получает дату и время последнего изменения. |
| creation_time | Получает дату и время создания. |
| last_access_time | Получает дату и время последнего доступа. |
| is_directory | Возвращает значение, указывающее, является ли элемент каталогом. |
| length | Получает длину записи в байтах. |
