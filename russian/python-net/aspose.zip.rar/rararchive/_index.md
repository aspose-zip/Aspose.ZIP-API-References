## RarArchive class

Этот класс представляет файл архива RAR. Используйте его для извлечения архивов RAR.

Тип RarArchive раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| RarArchive(path, load_options) | Инициализирует новый экземпляр класса [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) и формирует список записей, которые можно извлечь из архива. |
| RarArchive(source_stream, load_options) | Инициализирует новый экземпляр класса [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) и формирует список записей, которые можно извлечь из архива. |
## Свойства
| Имя | Описание |
| :- | :- |
| entries | Получает записи типа [RarArchiveEntry](/zip/python-net/aspose.zip.rar/rararchiveentry/), составляющие rar‑архив. |
| file_entries | Получает записи типа [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/), составляющие архив. |
| format | Возвращает формат архива. |
## Методы
| Имя | Описание |
| :- | :- |
| extract_to_directory(destination_directory, password) | Извлекает все файлы из архива в указанный каталог. |
| extract_to_directory(destination_directory) | Извлекает все файлы из архива в указанный каталог. |
