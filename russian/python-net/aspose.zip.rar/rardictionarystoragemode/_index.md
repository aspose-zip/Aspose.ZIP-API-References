## RarDictionaryStorageMode enumeration

Указывает, как хранится словарь распаковки RAR.

## Members
| Имя члена | Описание |
| :- | :- |
| IN_MEMORY | Сохраняет словарь в лениво выделенных управляемых сегментах памяти. |
| TEMPORARY_FILE | Сохраняет вытесненные страницы словаря во временный файл и удерживает ограниченный кэш страниц в памяти. |
