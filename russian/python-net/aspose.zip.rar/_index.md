Содержит классы, представляющие связанные с архивом RAR сущности.

## Классы
| Класс | Описание |
| :- | :- |
| [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) | Этот класс представляет файл архива RAR. Используйте его для извлечения архивов RAR. |
| [RarArchiveEntry](/zip/python-net/aspose.zip.rar/rararchiveentry/) | Представляет отдельный файл внутри архива. |
| [RarArchiveEntryEncrypted](/zip/python-net/aspose.zip.rar/rararchiveentryencrypted/) | Элемент Zip, который необходимо распаковать с расшифровкой. |
| [RarArchiveEntryPlain](/zip/python-net/aspose.zip.rar/rararchiveentryplain/) | Элемент Rar, который необходимо распаковать без расшифровки. |
| [RarArchiveLoadOptions](/zip/python-net/aspose.zip.rar/rararchiveloadoptions/) | Параметры, с помощью которых [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) загружается из сжатого файла. |
