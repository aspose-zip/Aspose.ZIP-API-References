## WimFileEntry class

Представляет отдельный файл внутри архива wim.

Тип WimFileEntry раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| archive | Возвращает архив, к которому принадлежит запись. |
| image | Возвращает образ, к которому принадлежит запись. |
| parent | Возвращает родительский каталог, к которому принадлежит запись. |
| name | Возвращает имя записи внутри образа. |
| short_name | Возвращает короткое имя записи внутри образа. |
| full_path | Возвращает полный путь к записи внутри образа. |
| change_time | Возвращает время последнего изменения файла или каталога. |
| creation_time | Возвращает время создания файла или каталога. |
| last_access_time | Возвращает время последнего доступа к файлу или каталогу. |
| last_write_time | Получает время изменения файла или каталога. |
| modification_time | Получает время изменения файла или каталога. |
| alternate_data_streams | Получает имена альтернативных потоков данных для файла или каталога. |
| hard_link | Получает идентификатор жёсткой ссылки файла или каталога. |
| has_hard_links | Определяет, известен ли файл или каталог под другими именами. |
| is_directory | Возвращает значение, указывающее, является ли элемент каталогом. |
| length | Получает длину записи в байтах. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path) | Извлекает запись в файловую систему по указанному пути. |
| extract(destination) | Извлекает запись в предоставленный поток. |
| open() | Открывает запись для извлечения и предоставляет поток с содержимым записи. |
