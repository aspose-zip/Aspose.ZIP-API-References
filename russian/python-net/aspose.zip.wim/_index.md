Содержит классы, представляющие сущности, связанные с архивом WIM.

## Классы
| Класс | Описание |
| :- | :- |
| [WimArchive](/zip/python-net/aspose.zip.wim/wimarchive/) | Этот класс представляет файл архива wim. |
| [WimDirectoryEntry](/zip/python-net/aspose.zip.wim/wimdirectoryentry/) | Представляет отдельный каталог внутри архива wim. |
| [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) | Представляет отдельный файл или каталог внутри образа wim. |
| [WimFileEntry](/zip/python-net/aspose.zip.wim/wimfileentry/) | Представляет отдельный файл внутри архива wim. |
| [WimImage](/zip/python-net/aspose.zip.wim/wimimage/) | Представляет отдельный образ внутри архива wim. |
| [WimLoadOptions](/zip/python-net/aspose.zip.wim/wimloadoptions/) | Параметры, с помощью которых архив загружается из сжатого файла. |
