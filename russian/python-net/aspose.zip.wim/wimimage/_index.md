## WimImage class

Представляет отдельный образ внутри архива wim.

Тип WimImage раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| root_directory | Получает запись корневого каталога образа. |
| all_entries | Получает записи типа [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/), составляющие образ рекурсивно. |
| parent | Получает архив, к которому принадлежит образ. |
## Методы
| Имя | Описание |
| :- | :- |
| get_entry(path) | Получает запись типа [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) для заданного пути. |
| extract_to_directory(destination_directory) | Извлекает все файлы из образа в указанный каталог. |
