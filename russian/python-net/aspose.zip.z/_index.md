Содержит классы, представляющие сущности, связанные с архивом Z.

## Классы
| Класс | Описание |
| :- | :- |
| [ZArchive](/zip/python-net/aspose.zip.z/zarchive/) | Этот класс представляет файл архива Z (compress). Используйте его для создания или извлечения архивов Z. |
| [ZArchiveLoadOptions](/zip/python-net/aspose.zip.z/zarchiveloadoptions/) | Параметры, с помощью которых [ZArchive](/zip/python-net/aspose.zip.z/zarchive/) загружается из сжатого файла. Содержит событие, вызываемое при извлечении. |
| [ZArchiveSaveOptions](/zip/python-net/aspose.zip.z/zarchivesaveoptions/) | Настройки для Zarchive. |
