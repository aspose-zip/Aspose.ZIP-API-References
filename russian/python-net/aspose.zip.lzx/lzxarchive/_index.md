## LzxArchive class

Этот класс представляет файл архива LZX (.lzx).

Тип LzxArchive раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LzxArchive(extraction_source, load_options) | Инициализирует новый экземпляр класса [LzxArchive](/zip/python-net/aspose.zip.lzx/lzxarchive/) и формирует список записей, которые можно извлечь из архива. |
| LzxArchive(path, load_options) | Инициализирует новый экземпляр класса [LzxArchive](/zip/python-net/aspose.zip.lzx/lzxarchive/) и формирует список записей, которые можно извлечь из архива. |
## Свойства
| Имя | Описание |
| :- | :- |
| entries | Получает файловые записи типа [LzxArchiveEntry](/zip/python-net/aspose.zip.lzx/lzxarchiveentry/), составляющие архив. |
| file_entries | Получает записи типа [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/), составляющие архив. |
| format | Возвращает формат архива. |
## Методы
| Имя | Описание |
| :- | :- |
| extract_to_directory(destination_directory) | Извлекает все файлы и каталоги из архива в указанную директорию. |
