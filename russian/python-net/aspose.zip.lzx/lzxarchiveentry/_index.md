## LzxArchiveEntry class

Представляет отдельный файл внутри архива LZX.

Тип LzxArchiveEntry раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| name | Получает имя записи. |
| комментарий | Получает комментарий. |
| length | Получает длину записи в байтах. |
| uncompressed_size | Возвращает размер оригинального файла. |
| compressed_size | Возвращает размер сжатого файла. |
| is_directory | Получает значение, указывающее, является ли этот элемент каталогом. |
| modification_time | Получает время последнего изменения элемента. |
## Методы
| Имя | Описание |
| :- | :- |
| extract(path) | Извлекает запись архива Lzx в файловую систему по пути. |
| extract(destination) | Извлекает запись в предоставленный поток. |
