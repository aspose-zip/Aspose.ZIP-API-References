## AppleArchive.IsSolid property

Obtiene un valor que indica si el archivo usa compresión sólida. En modo sólido, todos los datos de las entradas se comprimen como una única secuencia y la extracción individual de entradas no está disponible. Use [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/) en su lugar.

```csharp
public bool IsSolid { get; }
```
