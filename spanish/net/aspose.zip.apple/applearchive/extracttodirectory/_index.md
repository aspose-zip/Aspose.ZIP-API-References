## AppleArchive.ExtractToDirectory method

Extrae todos los archivos del archivo al directorio proporcionado.

```csharp
public void ExtractToDirectory(string destinationDirectory)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| destinationDirectory | String | La ruta al directorio donde se colocarán los archivos extraídos. |

### Excepciones

| excepción | condición |
| --- | --- |
| EndOfStreamException | El flujo termina inesperadamente durante la extracción de un archivo sólido. |
| InvalidDataException | Los datos del archivo están malformados, o un enlace simbólico no es seguro. |
| PlatformNotSupportedException | La creación de enlaces simbólicos no es compatible con el tiempo de ejecución actual. |
