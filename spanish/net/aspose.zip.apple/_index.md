El espacio de nombres Apple contiene clases que representan entidades relacionadas con Apple Archive.

## Clases

| Clase | Descripción |
| --- | --- |
| [AppleArchive](./applearchive/) | Esta clase representa un archivo Apple Archive (.aar). Úsela para crear archivos Apple Archive. |
| [AppleArchiveEntry](./applearchiveentry/) | Representa una entrada del sistema de archivos dentro de un [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | Configuraciones usadas para componer entradas dentro de [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | Opciones con las que se carga [`AppleArchive`](../aspose.zip.apple/applearchive/) desde un archivo comprimido. |
| [AppleCompressionSettings](./applecompressionsettings/) | Configuraciones necesarias para la compresión de entradas de Apple Archive. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Configuraciones para la compresión LZ4 dentro de un archivo Apple Archive (.aar). |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Configuraciones para la compresión LZFSE dentro de un archivo Apple Archive (.aar). |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Configuraciones para la compresión LZMA dentro de un archivo Apple Archive (.aar). |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Configuraciones para almacenar (sin compresión) dentro de un archivo Apple Archive (.aar). |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Configuraciones para la compresión Zlib dentro de un archivo Apple Archive (.aar). |
