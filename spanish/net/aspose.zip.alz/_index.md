El espacio de nombres Alz contiene clases que representan entidades relacionadas con ALZ.

## Clases

| Clase | Descripción |
| --- | --- |
| [AlzArchive](./alzarchive/) | Esta clase representa un archivo de archivo ALZ. Úsela para extraer archivos alz. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Opciones con las que se carga el archivo ALZ desde un archivo comprimido. |
| [AlzEntry](./alzentry/) | Representa una entrada de archivo en un archivo ALZ con todos sus metadatos. |
| [AlzEntryEncrypted](./alzentryencrypted/) | Entrada ALZ que necesita ser descifrada antes de la descompresión. |
| [AlzEntryPlain](./alzentryplain/) | Entrada ALZ que necesita ser descomprimida sin descifrado. |
