El espacio de nombres Egg contiene clases que representan entidades relacionadas con EGG.

## Clases

| Clase | Descripción |
| --- | --- |
| [EggArchive](./eggarchive/) | Esta clase representa un archivo de archivo EGG. Úsela para extraer archivos EGG. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Opciones con las que se carga un archivo EGG desde un archivo comprimido. |
| [EggEntry](./eggentry/) | Representa una entrada de archivo en un archivo EGG con todos sus metadatos. |
| [EggEntryPlain](./eggentryplain/) | Entrada EGG que puede ser descomprimida sin descifrado. |
