## XzArchiveSettings.CompressionThreads property

Obtiene o establece el número de hilos de compresión. Si el valor es mayor que 1, se utilizará compresión multihilo.

```csharp
public int CompressionThreads { get; set; }
```

### Excepciones

| excepción | condición |
| --- | --- |
| ArgumentOutOfRangeException | El número de hilos es mayor que 100. |

## Observaciones

No establezca este número a más de los núcleos de CPU.
