El espacio de nombres Iso contiene clases que representan entidades relacionadas con ISO.

## Clases

| Clase | Descripción |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Argumentos del evento para eventos relacionados con entradas. |
| [EventsBag](./eventsbag/) | Contenedor de eventos utilizado al guardar [`IsoArchive`](../aspose.zip.iso/isoarchive/). |
| [IsoArchive](./isoarchive/) | Representa un archivo ISO (ISO 9660). |
| [IsoEntry](./isoentry/) | Representa una entrada (archivo o directorio) dentro de un archivo ISO. |
| [IsoLoadOptions](./isoloadoptions/) | Opciones con las que [`IsoArchive`](../aspose.zip.iso/isoarchive/) se carga desde un archivo comprimido. Contiene el evento generado al extraer. |
| [IsoSaveOptions](./isosaveoptions/) | Opciones para guardar un archivo ISO. |
