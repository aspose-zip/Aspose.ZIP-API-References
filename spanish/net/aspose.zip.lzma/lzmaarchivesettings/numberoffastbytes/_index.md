## LzmaArchiveSettings.NumberOfFastBytes property

Obtiene o establece el número de bytes usados para la búsqueda rápida de coincidencias en el algoritmo LZMA.

```csharp
public int NumberOfFastBytes { get; set; }
```

## Observaciones

Un valor más alto permite que el compresor busque coincidencias más largas, lo que puede mejorar ligeramente la relación de compresión pero ralentiza la compresión.
