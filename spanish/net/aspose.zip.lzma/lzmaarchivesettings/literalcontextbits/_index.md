## LzmaArchiveSettings.LiteralContextBits property

Obtiene o establece el número de bits de contexto literal.

```csharp
public int LiteralContextBits { get; set; }
```

## Observaciones

Los Bits de Contexto Literal definen cuántos de los bits más significativos del byte sin comprimir anterior se utilizan para predecir los bits del siguiente byte literal. Debe estar entre 0 y 8.
