## RarArchiveLoadOptions.TemporaryDirectory property

Obtiene o establece el directorio usado para archivos de diccionario temporales.

```csharp
public string TemporaryDirectory { get; set; }
```

## Observaciones

El valor predeterminado es GetTempPath. Un `null` o un valor vacío también usa el directorio temporal del sistema.
