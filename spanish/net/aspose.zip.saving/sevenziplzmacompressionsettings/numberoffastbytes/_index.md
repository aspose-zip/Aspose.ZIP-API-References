## SevenZipLZMACompressionSettings.NumberOfFastBytes property

Obtiene el número de bytes usados para la búsqueda de coincidencias rápidas en el algoritmo LZMA.

```csharp
public int NumberOfFastBytes { get; }
```

## Observaciones

Un valor más alto permite que el compresor busque coincidencias más largas, lo que puede mejorar ligeramente la relación de compresión pero ralentiza la compresión.
