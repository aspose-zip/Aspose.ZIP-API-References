## LzmaCompressionSettings.DictionarySize property

El tamaño del diccionario (búfer de historial) indica cuántos bytes de los datos descomprimidos procesados recientemente se mantienen en memoria.

```csharp
public int DictionarySize { get; }
```

## Observaciones

Cuanto más grande es el diccionario, generalmente mejor es la relación de compresión, pero los diccionarios más grandes que los datos descomprimidos son un desperdicio de RAM.
