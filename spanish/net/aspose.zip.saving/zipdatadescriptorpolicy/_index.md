### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |

| ForAllFileEntries | `1` | El Descriptor de Datos está presente solo para entradas con datos de archivo; se omite para directorios. Se desaconseja el uso de esta opción. |
