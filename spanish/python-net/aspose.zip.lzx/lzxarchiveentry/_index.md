## LzxArchiveEntry class

Representa un solo archivo dentro del archivo LZX.

El tipo LzxArchiveEntry expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene el nombre de la entrada. |
| comentario | Obtiene el comentario. |
| length | Obtiene la longitud de la entrada en bytes. |
| uncompressed_size | Obtiene el tamaño del archivo original. |
| compressed_size | Obtiene el tamaño del archivo comprimido. |
| is_directory | Obtiene un valor que indica si esta entrada es un directorio. |
| modification_time | Obtiene la hora de última modificación de la entrada. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract(path) | Extrae la entrada del archivo Lzx a un sistema de archivos por ruta. |
| extract(destination) | Extrae la entrada al flujo proporcionado. |
