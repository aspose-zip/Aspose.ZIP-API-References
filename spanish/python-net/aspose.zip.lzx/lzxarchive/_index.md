## LzxArchive class

Esta clase representa un archivo LZX (.lzx).

El tipo LzxArchive expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LzxArchive(extraction_source, load_options) | Inicializa una nueva instancia de la clase [LzxArchive](/zip/python-net/aspose.zip.lzx/lzxarchive/) y compone una lista de entradas que puede extraerse del archivo. |
| LzxArchive(path, load_options) | Inicializa una nueva instancia de la clase [LzxArchive](/zip/python-net/aspose.zip.lzx/lzxarchive/) y compone una lista de entradas que puede extraerse del archivo. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| entries | Obtiene las entradas de archivo del tipo [LzxArchiveEntry](/zip/python-net/aspose.zip.lzx/lzxarchiveentry/) que constituyen el archivo. |
| file_entries | Obtiene entradas del tipo [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) que constituyen el archivo. |
| format | Obtiene el formato del archivo. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract_to_directory(destination_directory) | Extrae todos los archivos y directorios del archivo al directorio proporcionado. |
