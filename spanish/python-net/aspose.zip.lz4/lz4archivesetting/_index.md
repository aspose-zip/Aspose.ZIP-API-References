## Lz4ArchiveSetting class

Configuración para la composición de archivos LZ4.

El tipo Lz4ArchiveSetting expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Lz4ArchiveSetting() | Inicializa una nueva instancia de [Lz4ArchiveSetting](/zip/python-net/aspose.zip.lz4/lz4archivesetting/) con parámetros predeterminados. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| include_content_checksum | Obtiene o establece un valor que indica si se debe incluir el hash xxh32 del contenido al final del archivo LZ4. |
| include_block_checksum | Obtiene o establece un valor que indica si se debe incluir el hash xxh32 comprimido al final del bloque comprimido. |
| include_content_size | Obtiene o establece un valor que indica si se debe incluir el tamaño del contenido en el marco. |
