## XarDirectoryEntry class

Representa una entrada de directorio dentro del archivo xar.

El tipo XarDirectoryEntry expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene el nombre de la entrada dentro del archivo. |
| full_path | Obtiene la ruta completa de la entrada dentro del archivo. |
| is_directory | Obtiene un valor que indica si la entrada representa un directorio. |
| parent | Obtiene el directorio padre al que pertenece la entrada. |
| creation_time | Obtiene la hora de creación del archivo o directorio. |
| last_access_time | Obtiene la última hora de acceso del archivo o directorio. |
| last_write_time | Obtiene la hora de modificación del archivo o directorio. |
| modification_time | Obtiene la hora de modificación del archivo o directorio. |
| files_and_directories | Obtiene entradas del tipo [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/) que constituyen el directorio. |
| directories | Obtiene entradas del tipo [XarDirectoryEntry](/zip/python-net/aspose.zip.xar/xardirectoryentry/) que constituyen el directorio. |
| files | Obtiene entradas del tipo [XarFileEntry](/zip/python-net/aspose.zip.xar/xarfileentry/) que constituyen el directorio. |
| all_entries | Obtiene todas las entradas del tipo [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/) que constituyen el directorio de forma recursiva. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract_to_directory(destination_directory) | Extrae todos los archivos en el directorio actual al directorio proporcionado. |
