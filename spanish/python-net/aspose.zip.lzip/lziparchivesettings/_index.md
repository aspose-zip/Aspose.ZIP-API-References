## LzipArchiveSettings class

La clase contiene la configuración de un archivo lzip particular.

El tipo LzipArchiveSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LzipArchiveSettings(dictionary_size, max_member_size) | Inicializa una nueva instancia de [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) con un tamaño de diccionario particular. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| fastest_speed | Obtiene la instancia de la clase [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            con un tamaño de diccionario igual a 65536 bytes en el filtro LZMA. |
| fast_speed | Obtiene la instancia de la clase [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            con un tamaño de diccionario igual a 1 megabyte en el filtro LZMA. |
| normal | Obtiene la instancia de la clase [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            con un tamaño de diccionario igual a 16 megabytes en el filtro LZMA. |
| high_compression | Obtiene la instancia de la clase [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            con un tamaño de diccionario igual a 32 megabytes en el filtro LZMA. |
| maximum_compression | Obtiene la instancia de la clase [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/)<br/>            con un tamaño de diccionario igual a 64 megabytes en el filtro LZMA. |
| dictionary_size | Obtiene el tamaño del diccionario que se usa en la compresión LZMA. |
| max_member_size | Obtiene el tamaño máximo de un miembro en el archivo lzip presentado en bytes. |
| compression_threads | Obtiene o establece el recuento de hilos de compresión. Si el valor es mayor que 1, se utilizará compresión multihilo. |
