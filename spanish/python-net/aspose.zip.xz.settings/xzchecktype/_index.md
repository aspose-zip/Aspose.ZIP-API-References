## XzCheckType enumeration

La enumeración define el enfoque de cálculo de suma de verificación para el archivo xz.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | No se calculará la suma de verificación. |
| CRC32 | El checksum se calculará usando el algoritmo CRC32. |
| CRC64 | El checksum se calculará usando el algoritmo CRC64. |
