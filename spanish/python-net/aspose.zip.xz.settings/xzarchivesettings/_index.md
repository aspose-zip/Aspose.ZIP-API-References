## XzArchiveSettings class

La clase contiene un conjunto de configuraciones de un archivo xz particular.

El tipo XzArchiveSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| XzArchiveSettings() | Inicializa una nueva instancia de la clase [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) usando compresión LZMA2 única. |
| XzArchiveSettings(filters, block_size, check_type) | Inicializa una nueva instancia de la clase [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) con parámetros personalizados. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| compression_threads | Obtiene o establece el recuento de hilos de compresión. Si el valor es mayor que 1, se utilizará compresión multihilo. |
| fastest_speed | Obtiene la instancia de la clase [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            con un tamaño de diccionario igual a 65536 bytes en el filtro LZMA2, tamaño de bloque igual a 1 megabyte y suma de verificación CRC32. |
| fast_speed | Obtiene la instancia de la clase [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            con un tamaño de diccionario igual a 1 megabyte en el filtro LZMA2, tamaño de bloque igual a 4 megabytes y suma de verificación CRC32. |
| normal | Obtiene la instancia de la clase [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            con un tamaño de diccionario igual a 16 megabytes en el filtro LZMA2, tamaño de bloque igual a 64 megabytes y suma de verificación CRC32. |
| high_compression | Obtiene la instancia de la clase [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            con un tamaño de diccionario igual a 32 megabytes en el filtro LZMA2, tamaño de bloque igual a 128 megabytes y suma de verificación CRC32. |
| maximum_compression | Obtiene la instancia de la clase [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/)<br/>            con un tamaño de diccionario igual a 64 megabytes en el filtro LZMA2, tamaño de bloque igual a 256 megabytes y suma de verificación CRC32. |
