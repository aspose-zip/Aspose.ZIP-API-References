## CabSaveOptions class

Opciones para guardar un archivo CAB.

El tipo CabSaveOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| CabSaveOptions() | Inicializa una nueva instancia de la clase CabSaveOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| skip_checksum_calculation | Obtiene o establece un valor que indica si se debe omitir el cálculo de la suma de verificación al guardar el archivo CAB. |
| close_entry_source | Obtiene o establece un valor que indica si las fuentes de las entradas deben cerrarse justo después de que una entrada haya sido comprimida. |
