## WimImage class

Representa una única imagen dentro del archivo wim.

El tipo WimImage expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| root_directory | Obtiene la entrada del directorio raíz de la imagen. |
| all_entries | Obtiene las entradas del tipo [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) que constituyen la imagen de forma recursiva. |
| parent | Obtiene el archivo al que pertenece la imagen. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_entry(path) | Obtiene la entrada del tipo [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) para una ruta dada. |
| extract_to_directory(destination_directory) | Extrae todos los archivos en la imagen al directorio proporcionado. |
