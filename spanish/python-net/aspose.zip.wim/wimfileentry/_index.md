## WimFileEntry class

Representa un único archivo dentro del archivo wim.

El tipo WimFileEntry expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| archive | Obtiene el archivo al que pertenece la entrada. |
| image | Obtiene la imagen a la que pertenece la entrada. |
| parent | Obtiene el directorio padre al que pertenece la entrada. |
| name | Obtiene el nombre de la entrada dentro de la imagen. |
| short_name | Obtiene el nombre corto de la entrada dentro de la imagen. |
| full_path | Obtiene una ruta completa de la entrada dentro de la imagen. |
| change_time | Obtiene la última vez que se cambió el archivo o directorio. |
| creation_time | Obtiene la hora de creación del archivo o directorio. |
| last_access_time | Obtiene la última hora de acceso del archivo o directorio. |
| last_write_time | Obtiene la hora de modificación del archivo o directorio. |
| modification_time | Obtiene la hora de modificación del archivo o directorio. |
| alternate_data_streams | Obtiene los nombres de los flujos de datos alternativos para un archivo o directorio. |
| hard_link | Obtiene el ID del enlace duro del archivo o directorio. |
| has_hard_links | Obtiene si el archivo o directorio es conocido por otros nombres. |
| is_directory | Obtiene un valor que indica si la entrada representa un directorio. |
| length | Obtiene la longitud de la entrada en bytes. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract(path) | Extrae la entrada al sistema de archivos usando la ruta proporcionada. |
| extract(destination) | Extrae la entrada al flujo proporcionado. |
| open() | Abre la entrada para extracción y proporciona un flujo con el contenido de la entrada. |
