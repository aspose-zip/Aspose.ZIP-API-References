## ArchiveInstanceInfo class

Representa información sobre la instancia del archivo.

El tipo ArchiveInstanceInfo expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| format_info | Obtiene la información del formato del archivo. |
| is_content_encrypted | Obtiene un valor que indica si el contenido del archivo está cifrado. |
| are_file_names_encrypted | Obtiene un valor que indica si los nombres de las entradas (archivos) del archivo están cifrados. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_archive_format_info(file_name) | Obtiene información del formato del archivo. |
| get_archive_format_info(stream) | Obtiene información del formato del archivo. |
| get_archive_instance_info(file_name) | Obtiene información de la instancia del archivo. |
| get_archive_instance_info(stream) | Obtiene información de la instancia del archivo. |
