## SevenZipCipher class

Clase base para el cifrado AES utilizado en la encriptación 7-zip.

El tipo SevenZipCipher expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| can_reuse_transform | Obtiene un valor que indica si la transformación actual puede reutilizarse. |
| can_transform_multiple_blocks | Obtiene un valor que indica si se pueden transformar varios bloques. |
| input_block_size | Obtiene el tamaño del bloque de entrada. |
| output_block_size | Obtiene el tamaño del bloque de salida. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| transform_block(input_buffer, input_offset, input_count, output_buffer, output_offset) | Transforma la región especificada del arreglo de bytes de entrada y copia la transformación resultante a la región especificada del arreglo de bytes de salida. |
| transform_final_block(input_buffer, input_offset, input_count) | Transforma la región especificada del arreglo de bytes especificado. |
