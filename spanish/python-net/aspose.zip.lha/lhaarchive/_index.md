## LhaArchive class

Esta clase representa un archivo LHA (.lzh).

El tipo LhaArchive expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LhaArchive(source_stream, load_options) | Inicializa una nueva instancia de la clase [LhaArchive](/zip/python-net/aspose.zip.lha/lhaarchive/) y compone una lista de entradas que puede ser extraída del archivo. |
| LhaArchive(path, load_options) | Inicializa una nueva instancia de la clase [LhaArchive](/zip/python-net/aspose.zip.lha/lhaarchive/) y compone una lista de entradas que puede ser extraída del archivo. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| entries | Obtiene las entradas de archivo del tipo [LhaArchiveEntry](/zip/python-net/aspose.zip.lha/lhaarchiveentry/) que constituyen el archivo. |
| file_entries | Obtiene entradas del tipo [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) que constituyen el archivo. |
| format | Obtiene el formato del archivo. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract_to_directory(destination_directory) | Extrae todos los archivos y directorios del archivo al directorio proporcionado. |
