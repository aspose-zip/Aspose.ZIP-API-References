## LhaArchiveEntry class

Representa un solo archivo dentro del archivo Lha.

El tipo LhaArchiveEntry expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene el nombre de la entrada. |
| length | Obtiene la longitud de la entrada en bytes. |
| is_directory | Obtiene un valor que indica si esta entrada es un directorio. |
| last_modified | Obtiene la hora de última modificación de la entrada. |
| modification_time | Obtiene la hora de última modificación de la entrada. |
| path | Obtiene la ruta completa de la entrada. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract(path) | Extrae la entrada del archivo Lha a un sistema de archivos mediante la ruta. |
| extract(destination) | Extrae la entrada al flujo proporcionado. |
| extract(file_info) | Extrae la entrada del archivo Lha a un archivo. |
