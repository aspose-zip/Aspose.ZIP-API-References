## UueSaveOptions class

Opciones para guardar un archivo uuencoded.

El tipo UueSaveOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| UueSaveOptions(file_name, new_line) | Inicializa las opciones con el nombre de archivo y la nueva línea proporcionados por el usuario. |
| UueSaveOptions(file_name) | Inicializa las opciones con el nombre de archivo y la nueva línea proporcionados por el usuario. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| new_line | Obtiene el carácter que termina cada línea, usualmente "\n" o "\r\n". |
| file_name | Obtiene el nombre de archivo que se usará al recrear los datos decodificados. |
| unix_file_permissions | Obtiene los permisos Unix del archivo. |
