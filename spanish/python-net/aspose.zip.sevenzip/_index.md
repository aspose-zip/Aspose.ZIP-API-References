Contiene clases que representan entidades relacionadas con archivos 7z.

## Clases
| Clase | Descripción |
| :- | :- |
| [SevenZipArchive](/zip/python-net/aspose.zip.sevenzip/sevenziparchive/) | Esta clase representa un archivo 7z. Úsela para crear y extraer archivos 7z. |
| [SevenZipArchiveEntry](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentry/) | Representa un archivo único dentro del archivo 7z. |
| [SevenZipArchiveEntryEncrypted](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentryencrypted/) | Entrada del archivo SevenZip que necesita ser comprimida con cifrado o descomprimida con descifrado. |
| [SevenZipArchiveEntryPlain](/zip/python-net/aspose.zip.sevenzip/sevenziparchiveentryplain/) | Entrada SevenZip que necesita ser comprimida sin cifrado o descomprimida sin descifrado. |
| [SevenZipLoadOptions](/zip/python-net/aspose.zip.sevenzip/sevenziploadoptions/) | Opciones con las que se carga [SevenZipArchive](/zip/python-net/aspose.zip.sevenzip/sevenziparchive/) desde un archivo comprimido. |
