Contiene clases que representan entidades relacionadas con archivos Apple.

| Clase | Descripción |
| :- | :- |

| [AppleLzfseCompressionSettings](/zip/python-net/aspose.zip.apple/applelzfsecompressionsettings/) | Configuración para la compresión LZFSE dentro de un archivo Apple Archive (.aar). |
