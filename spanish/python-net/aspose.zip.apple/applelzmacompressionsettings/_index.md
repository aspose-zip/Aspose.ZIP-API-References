## AppleLzmaCompressionSettings class

Configuración para la compresión LZMA dentro de un archivo Apple Archive (.aar).

El tipo AppleLzmaCompressionSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| AppleLzmaCompressionSettings(block_size, dictionary_size) | Inicializa una nueva instancia de la clase AppleLzmaCompressionSettings |
| AppleLzmaCompressionSettings(block_size, dictionary_size, fast_bytes) | Inicializa una nueva instancia de la clase AppleLzmaCompressionSettings |
| AppleLzmaCompressionSettings() | Inicializa una nueva instancia de la clase [AppleLzmaCompressionSettings](/zip/python-net/aspose.zip.apple/applelzmacompressionsettings/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| lz4 | Una instancia de [AppleLz4CompressionSettings](/zip/python-net/aspose.zip.apple/applelz4compressionsettings/) con parámetros predeterminados. |
| lzfse | Una instancia de [AppleLzfseCompressionSettings](/zip/python-net/aspose.zip.apple/applelzfsecompressionsettings/) con parámetros predeterminados. |
| lzma | Una instancia de [AppleLzmaCompressionSettings](/zip/python-net/aspose.zip.apple/applelzmacompressionsettings/) con parámetros predeterminados. |
| store | Una instancia de [AppleStoreCompressionSettings](/zip/python-net/aspose.zip.apple/applestorecompressionsettings/) con parámetros predeterminados. |
| zlib | Una instancia de [AppleZlibCompressionSettings](/zip/python-net/aspose.zip.apple/applezlibcompressionsettings/) con parámetros predeterminados. |
| block_size | Obtiene el tamaño de cada bloque de datos antes de la compresión. |
| dictionary_size | Obtiene el tamaño del diccionario usado para la compresión. |
| fast_bytes | Obtiene el número de bytes rápidos usados para la compresión. |
