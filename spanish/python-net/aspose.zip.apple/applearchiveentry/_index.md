## AppleArchiveEntry class

Representa una entrada de archivo o directorio dentro de [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/).

El tipo AppleArchiveEntry expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene la ruta de la entrada dentro del archivo. |
| length | Obtiene la longitud sin comprimir de la entrada en bytes. |
| is_directory | Obtiene un valor que indica si la entrada representa un directorio. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract(path) | Extrae la entrada al sistema de archivos usando la ruta proporcionada. |
| extract(destination) | Extrae la entrada al flujo proporcionado. |
| open() | Abre la entrada para extracción y proporciona un flujo con el contenido de la entrada. |
