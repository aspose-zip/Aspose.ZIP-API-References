## AlzArchiveLoadOptions class

Opciones con las que se carga el archivo ALZ desde un archivo comprimido.

El tipo AlzArchiveLoadOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| AlzArchiveLoadOptions() | Inicializa una nueva instancia de la clase AlzArchiveLoadOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| decryption_password | Obtiene o establece la contraseña para descifrar las entradas. |
| encoding | Obtiene o establece la codificación para los nombres de las entradas. El valor predeterminado es la página de códigos Windows coreana 949 (CP949). |
| skip_checksum_verification | Obtiene o establece un valor que indica si se omite la verificación de suma de comprobación de las entradas ALZ y se ignoran los desajustes. El valor predeterminado es false. |
