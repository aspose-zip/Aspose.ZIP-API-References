## RarArchive class

Esta clase representa un archivo RAR. Úsela para extraer archivos RAR.

El tipo RarArchive expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| RarArchive(path, load_options) | Inicializa una nueva instancia de la clase [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) y compone una lista de entradas que se puede extraer del archivo. |
| RarArchive(source_stream, load_options) | Inicializa una nueva instancia de la clase [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) y compone una lista de entradas que se puede extraer del archivo. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| entries | Obtiene entradas del tipo [RarArchiveEntry](/zip/python-net/aspose.zip.rar/rararchiveentry/) que constituyen el archivo rar. |
| file_entries | Obtiene entradas del tipo [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) que constituyen el archivo. |
| format | Obtiene el formato del archivo. |
