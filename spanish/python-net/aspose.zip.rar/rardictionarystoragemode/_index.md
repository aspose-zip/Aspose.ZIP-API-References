## RarDictionaryStorageMode enumeration

Especifica cómo se almacena el diccionario de descompresión RAR.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| IN_MEMORY | Almacena el diccionario en segmentos de memoria gestionada asignados perezosamente. |
| TEMPORARY_FILE | Almacena las páginas del diccionario expulsadas en un archivo temporal y mantiene una caché de páginas limitada en memoria. |
