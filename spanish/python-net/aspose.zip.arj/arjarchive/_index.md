## ArjArchive class

Esta clase representa un archivo ARJ.

El tipo ArjArchive expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ArjArchive(extraction_source, load_options) | Inicializa una nueva instancia de la clase [ArjArchive](/zip/python-net/aspose.zip.arj/arjarchive/) y compone una lista de entradas que pueden extraerse del archivo. |
| ArjArchive(path, load_options) | Inicializa una nueva instancia de la clase [ArjArchive](/zip/python-net/aspose.zip.arj/arjarchive/) y compone una lista de entradas que pueden extraerse del archivo. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| entries | Obtiene entradas del tipo [ArjEntryPlain](/zip/python-net/aspose.zip.arj/arjentryplain/) que constituyen el archivo ARJ. |
| comentario | Obtiene el comentario. |
| name | Obtiene el nombre original. |
| file_entries | Obtiene entradas del tipo [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) que constituyen el archivo. |
| format | Obtiene el formato del archivo. |
