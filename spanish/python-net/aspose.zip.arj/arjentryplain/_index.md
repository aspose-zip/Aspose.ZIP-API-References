## ArjEntryPlain class

Representa un solo archivo dentro del archivo ARJ.

El tipo ArjEntryPlain expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene el nombre de la entrada dentro del archivo. |
| compressed_size | Obtiene el tamaño de un archivo comprimido. |
| uncompressed_size | Obtiene el tamaño de un archivo original. |
| length | Obtiene la longitud de la entrada en bytes. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract(path) | Extrae la entrada al sistema de archivos usando la ruta proporcionada. |
| extract(file_info) | Extrae la entrada del archivo ARJ a un archivo. |
| extract(destination) | Extrae la entrada al flujo proporcionado. |
