| Nombre | Descripción |
| :- | :- |

| Nombre | Descripción |
| :- | :- |

| encryption_settings | Obtiene la configuración para el cifrado o descifrado. La configuración de una entrada particular puede variar. |
| comment | Comentario para la entrada dentro del archivo ZIP. |
