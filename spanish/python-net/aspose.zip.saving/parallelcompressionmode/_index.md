## ParallelCompressionMode enumeration

Opciones de uso de la funcionalidad de compresión paralela.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NEVER | No comprimir en paralelo. |
| ALWAYS | Comprima en paralelo. Tenga cuidado con el consumo de memoria. |
| AUTO | Decida si se utilizará compresión paralela según las entradas.<br/>            Esta opción puede comprimir en paralelo solo algunas entradas. |
