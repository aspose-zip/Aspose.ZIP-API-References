## SevenZipLZMACompressionSettings class

Configuración para el método de compresión LZMA dentro de un archivo 7z.

El tipo SevenZipLZMACompressionSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SevenZipLZMACompressionSettings() | Inicializa una nueva instancia de la clase [SevenZipLZMACompressionSettings](/zip/python-net/aspose.zip.saving/sevenziplzmacompressionsettings/) con parámetros predeterminados. |
| SevenZipLZMACompressionSettings(dictionary_size, number_of_fast_bytes, literal_context_bits) | Inicializa una nueva instancia de la clase SevenZipLZMACompressionSettings |
| SevenZipLZMACompressionSettings(dictionary_size) | Inicializa una nueva instancia de la clase SevenZipLZMACompressionSettings |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| método | Obtiene el método de compresión o descompresión. |
| dictionary_size | El tamaño del diccionario (búfer de historial) indica cuántos bytes de los datos descomprimidos recientemente procesados se mantienen en memoria.<br/>            Si no se establece, se elegirá de acuerdo al tamaño de la entrada. Debe estar entre 4096 y 1073741824, o ser igual a cero para detección automática basada en el tamaño de la entrada. |
| number_of_fast_bytes | Obtiene el número de bytes usados para la búsqueda rápida de coincidencias en el algoritmo LZMA. |
| literal_context_bits | Obtiene el número de bits de contexto literal. |
