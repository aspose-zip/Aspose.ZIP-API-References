## ParallelOptions class

Opciones para compresión paralela.

El tipo ParallelOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ParallelOptions() | Inicializa una nueva instancia de la clase ParallelOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| parallel_compress_in_memory | Obtiene o establece el valor que indica cómo se debe usar el enfoque paralelo. |
| available_memory_size | Obtiene o establece la estimación de memoria en megabytes disponible para acomodar entradas comprimidas sin intercambiar a disco.<br/>            Este valor solo tiene sentido si la configuración [parallel_compress_in_memory](/zip/python-net/aspose.zip.saving/paralleloptions/) está en modo [AUTO](/zip/python-net/aspose.zip.saving/parallelcompressionmode/). |
