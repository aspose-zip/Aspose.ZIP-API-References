## SelfExtractorOptions class

Opciones para la creación de un archivo ejecutable autoextraíble.

El tipo SelfExtractorOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SelfExtractorOptions() | Inicializa una nueva instancia de la clase SelfExtractorOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| extractor_title | Obtiene o establece el título de la ventana del extractor. |
| title_icon | Obtiene o establece la ruta al ícono del título para las ventanas principales de la aplicación extractor. |
| close_window_on_extraction | Obtiene o establece un valor que indica si la ventana del extractor debe cerrarse al finalizar la extracción o no. |
| run_after_extraction | Obtiene o establece un programa que se ejecutará después de que se complete la extracción del archivo. |
