## SplitArchiveSaveOptions class

Opciones para guardar un archivo ZIP multivolumen.

El tipo SplitArchiveSaveOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SplitArchiveSaveOptions(file_name, segment_size) | Instancia la configuración para guardar un archivo ZIP de varios volúmenes. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| segment_size | Obtiene el tamaño del segmento. |
| file_name | Obtiene el nombre de los segmentos sin extensión. |
| archive_comment | Obtiene o establece un comentario opcional para el archivo Zip. |
| encoding | Obtiene o establece la codificación para convertir nombres de archivo y otras cadenas a bytes. |
| close_entry_source | Obtiene o establece un valor que indica si las fuentes de las entradas deben cerrarse justo después de que una entrada haya sido comprimida. |
| events_bag | Obtiene o establece el contenedor de eventos que se generan al guardar el archivo. |
