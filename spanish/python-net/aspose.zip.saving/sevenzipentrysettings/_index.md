## SevenZipEntrySettings class

Configuración utilizada para comprimir o descomprimir entradas 7Z.

El tipo SevenZipEntrySettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SevenZipEntrySettings(compression_settings, encryption_settings) | Inicializa una nueva instancia de la clase [SevenZipEntrySettings](/zip/python-net/aspose.zip.saving/sevenzipentrysettings/). |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| compression_settings | Obtiene la configuración para la rutina de compresión o descompresión. |
| encryption_settings | Obtiene la configuración para el cifrado o descifrado. La configuración de una entrada particular puede variar. |
| compress_header | Obtiene o establece el valor que indica si se debe comprimir el encabezado del archivo. |
| solid | Obtiene o establece el valor que indica si se deben concatenar las entradas y tratarlas como un solo bloque de datos. |
