## ZipDataDescriptorPolicy enumeration

## Members

| :- | :- |
| ALWAYS | El descriptor de datos está siempre presente para todas las entradas zip. |
| FOR_ALL_FILE_ENTRIES | El descriptor de datos está presente solo para entradas con datos de archivo; <br/>            omitido para directorios. Se desaconseja el uso de esta opción. |
