## SevenZipLZMA2CompressionSettings class

Configuración para el método de compresión LZMA2 dentro de un archivo 7z.

El tipo SevenZipLZMA2CompressionSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SevenZipLZMA2CompressionSettings(dictionary_size) | Inicializa una nueva instancia de la clase SevenZipLZMA2CompressionSettings |
| SevenZipLZMA2CompressionSettings(dictionary_size, fast_bytes) | Inicializa una nueva instancia de la clase SevenZipLZMA2CompressionSettings |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| método | Obtiene el método de compresión o descompresión. |
| compression_threads | Obtiene o establece el recuento de hilos de compresión. Si el valor es mayor que 1, se utilizará compresión multihilo. |
| dictionary_size | El tamaño del diccionario (búfer de historial) indica cuántos bytes de los datos sin comprimir procesados recientemente se mantienen en memoria. |
| fast_bytes | Obtiene el número de control de fast bytes utilizado por el compresor LZMA2. |
