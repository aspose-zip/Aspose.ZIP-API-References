## LzmaArchiveSettings class

Configuración para el archivo lzma.

El tipo LzmaArchiveSettings expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LzmaArchiveSettings() | Inicializa una nueva instancia de la clase [LzmaArchiveSettings](/zip/python-net/aspose.zip.lzma/lzmaarchivesettings/) con el tamaño de diccionario predeterminado, igual a 16 megabytes, número de bytes rápidos igual a 32 y bits de contexto literal igual a 3. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| dictionary_size | El tamaño del diccionario (búfer de historial) indica cuántos bytes de los datos descomprimidos procesados recientemente se mantienen en memoria.<br/>            Si no se establece, se elegirá de acuerdo al tamaño de la entrada. |
| number_of_fast_bytes | Obtiene o establece el número de bytes utilizados para la búsqueda rápida de coincidencias en el algoritmo LZMA. |
| literal_context_bits | Obtiene o establece el número de bits de contexto literal. |
