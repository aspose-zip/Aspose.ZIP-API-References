## IsoEntry class

Representa una entrada (archivo o directorio) dentro de un archivo ISO.

El tipo IsoEntry expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene el nombre de la entrada. |
| is_directory | Obtiene un valor que indica si la entrada es un directorio. |
| length | Obtiene o establece la fecha y hora de creación. |
| modification_time | Obtiene o establece la fecha y hora de la última modificación. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract(path) | Extrae la entrada al sistema de archivos usando la ruta proporcionada. |
| extract(destination) | Extrae la entrada al flujo proporcionado. |
