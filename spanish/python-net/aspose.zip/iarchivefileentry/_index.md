## IArchiveFileEntry class

Esta interfaz representa una entrada de archivo.

El tipo IArchiveFileEntry expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Obtiene el nombre de la entrada. |
| length | Obtiene la longitud de la entrada en bytes. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract(path) | Extrae la entrada al sistema de archivos usando la ruta proporcionada. |
| extract(destination) | Extrae la entrada al flujo proporcionado. |
