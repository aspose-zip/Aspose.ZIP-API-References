## ArchiveFactory class

Detecta el formato del archivo y crea el objeto [IArchive](/zip/python-net/aspose.zip/iarchive/) apropiado según el tipo de archivo.

El tipo ArchiveFactory expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_archive(path) | Detecta el formato del archivo y crea el objeto [IArchive](/zip/python-net/aspose.zip/iarchive/) apropiado según el tipo de archivo especificado por la ruta proporcionada. |
| get_archive(stream) | Detecta el formato del archivo y crea el objeto [IArchive](/zip/python-net/aspose.zip/iarchive/) apropiado según el tipo de archivo especificado por el flujo dado. |
| get_archive(stream, password) | Detecta el formato del archivo y crea el objeto [IArchive](/zip/python-net/aspose.zip/iarchive/) apropiado según el tipo de archivo cifrado especificado por el flujo dado. |
| compress_directory(path, output_file_name, archive_format) | Comprime el directorio especificado en un archivo comprimido utilizando el formato de archivo proporcionado. |
