Contiene clases que representan archivos zip y entidades relacionadas con archivos comunes.

## Clases
| Clase | Descripción |
| :- | :- |
| [Archive](/zip/python-net/aspose.zip/archive/) | Esta clase representa un archivo zip. Úsela para crear, extraer o actualizar archivos zip. |
| [ArchiveEntry](/zip/python-net/aspose.zip/archiveentry/) | Representa un archivo individual dentro del archivo. |
| [ArchiveEntryEncrypted](/zip/python-net/aspose.zip/archiveentryencrypted/) | Entrada zip que necesita ser comprimida con cifrado o descomprimida con descifrado. |
| [ArchiveEntryPlain](/zip/python-net/aspose.zip/archiveentryplain/) | Entrada zip que necesita ser comprimida sin cifrado o descomprimida sin descifrado. |
| [ArchiveFactory](/zip/python-net/aspose.zip/archivefactory/) | Detecta el formato del archivo y crea el objeto [IArchive](/zip/python-net/aspose.zip/iarchive/) apropiado según el tipo de archivo. |
| [ArchiveLoadOptions](/zip/python-net/aspose.zip/archiveloadoptions/) | Opciones con las que se carga el archivo ZIP desde un archivo comprimido. |
| [CancelEntryEventArgs](/zip/python-net/aspose.zip/cancelentryeventargs/) | Argumentos del evento para eventos relacionados con entradas cancelables. |
| [ComHelper](/zip/python-net/aspose.zip/comhelper/) | Proporciona métodos para que los clientes COM carguen archivos en Aspose.Zip. |
| [EntryEventArgs](/zip/python-net/aspose.zip/entryeventargs/) | Argumentos de evento para eventos relacionados con entradas. |
| [IArchive](/zip/python-net/aspose.zip/iarchive/) | Esta interfaz representa un archivo. |
| [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) | Esta interfaz representa una entrada de archivo. |
| [License](/zip/python-net/aspose.zip/license/) | Proporciona métodos para licenciar el componente. |
| [MeteredLicense](/zip/python-net/aspose.zip/meteredlicense/) | Proporciona métodos para establecer la clave medida. |
| [ProgressCancelEventArgs](/zip/python-net/aspose.zip/progresscanceleventargs/) | Clase para datos de evento cancelable que contiene el número de bytes procesados. |
| [ProgressEventArgs](/zip/python-net/aspose.zip/progresseventargs/) | Clase para datos de evento que contiene el número de bytes procesados. |
