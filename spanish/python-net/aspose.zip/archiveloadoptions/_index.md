## ArchiveLoadOptions class

Opciones con las que se carga el archivo ZIP desde un archivo comprimido.

El tipo ArchiveLoadOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ArchiveLoadOptions() | Inicializa una nueva instancia de la clase ArchiveLoadOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| decryption_password | Obtiene o establece la contraseña para descifrar las entradas. |
| encoding | Obtiene o establece la codificación para los nombres de las entradas. |
| skip_checksum_verification | Obtenga o establezca un valor que indique si se debe omitir la verificación de suma de comprobación de las entradas ZIP y se ignoren los desajustes. El valor predeterminado es false. |
