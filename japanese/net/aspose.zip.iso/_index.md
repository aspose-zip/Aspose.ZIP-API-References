Iso 名前空間には、ISO 関連エンティティを表すクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | エントリ関連イベントのイベント引数です。 |
| [EventsBag](./eventsbag/) | [`IsoArchive`](../aspose.zip.iso/isoarchive/) の保存時に使用されるイベントコンテナです。 |
| [IsoArchive](./isoarchive/) | ISO アーカイブ (ISO 9660) を表します。 |
| [IsoEntry](./isoentry/) | ISO アーカイブ内のエントリ (ファイルまたはディレクトリ) を表します。 |
| [IsoLoadOptions](./isoloadoptions/) | 圧縮ファイルから [`IsoArchive`](../aspose.zip.iso/isoarchive/) をロードする際のオプションです。抽出時に発生するイベントを含みます。 |
| [IsoSaveOptions](./isosaveoptions/) | ISO アーカイブを保存するためのオプションです。 |
