Settings 名前空間には、xz アーカイブ設定を表すクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [XzArchiveSettings](./xzarchivesettings/) | このクラスは特定の xz アーカイブの設定セットを含みます。 |
| [XzBcjX86FilterSettings](./xzbcjx86filtersettings/) | xz Bcj X86 フィルタの設定。 |
| [XzFilterSettings](./xzfiltersettings/) | 特定の xz フォーマットフィルタの設定セットの基底クラス。 |
| [XzLoadOptions](./xzloadoptions/) | [`XzArchive`](../aspose.zip.xz/xzarchive/) の読み込みオプション。 |
| [XzLZMA2FilterSettings](./xzlzma2filtersettings/) | xz LZMA2 フィルタの設定セット。 |
## 列挙

| 列挙 | 説明 |
| --- | --- |
| [XzCheckType](./xzchecktype/) | この列挙体は xz アーカイブのチェックサム計算方法を定義します。 |
