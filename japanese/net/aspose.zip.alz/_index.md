Alz 名前空間には、ALZ 関連エンティティを表すクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [AlzArchive](./alzarchive/) | このクラスは ALZ アーカイブ ファイルを表します。ALZ アーカイブを抽出するために使用します。 |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | 圧縮ファイルから ALZ アーカイブを読み込む際のオプション。 |
| [AlzEntry](./alzentry/) | ALZ アーカイブ内のファイル エントリをすべてのメタデータとともに表します。 |
| [AlzEntryEncrypted](./alzentryencrypted/) | 解凍前に復号が必要な ALZ エントリ。 |
| [AlzEntryPlain](./alzentryplain/) | 復号せずに解凍が必要な ALZ エントリ。 |
