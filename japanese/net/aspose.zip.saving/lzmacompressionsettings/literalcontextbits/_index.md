## LzmaCompressionSettings.LiteralContextBits property

リテラルコンテキストビット数を取得します。

```csharp
public int LiteralContextBits { get; }
```

## 備考

リテラルコンテキストビットは、前の非圧縮バイトの最上位ビットのうち何ビットを次のリテラルバイトのビット予測に使用するかを定義します。0 から 8 の範囲で指定する必要があります。
