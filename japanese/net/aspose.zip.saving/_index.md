Saving 名前空間には、アーカイブの保存を伴う操作に必要なクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [AesEcryptionSettings](./aesecryptionsettings/) | ZIP アーカイブ内の AES 暗号化および復号化アルゴリズムの設定。 |
| [ArchiveEntrySettings](./archiveentrysettings/) | エントリを圧縮または解凍するために使用される設定。 |
| [ArchiveSaveOptions](./archivesaveoptions/) | ZIP アーカイブを保存するためのオプション。 |
| [Bzip2CompressionSettings](./bzip2compressionsettings/) | ZIP アーカイブ内の Bzip2 圧縮の設定。 |
| [CompressionSettings](./compressionsettings/) | 圧縮器または解凍器が動作するために必要な設定。 |
| [DeflateCompressionSettings](./deflatecompressionsettings/) | ZIP アーカイブ内の Deflate 圧縮の設定。 |
| [EncryptionSettings](./encryptionsettings/) | 複数の ZIP 暗号化方式の設定のための基底クラス。 |
| [EnhancedDeflateCompressionSettings](./enhanceddeflatecompressionsettings/) | ZIP アーカイブ内の Enhanced Deflate 圧縮の設定。 |
| [EventsBag](./eventsbag/) | [`Archive`](../aspose.zip/archive/) の保存時に使用されるイベント コンテナです。 |
| [LzmaCompressionSettings](./lzmacompressionsettings/) | ZIP アーカイブ内の LZMA 圧縮の設定。 |
| [ParallelOptions](./paralleloptions/) | 並列圧縮のオプション。 |
| [PPMdCompressionSettings](./ppmdcompressionsettings/) | ZIP アーカイブ内の PPMd 圧縮の設定。 |
| [SelfExtractorOptions](./selfextractoroptions/) | 自己解凍実行可能アーカイブの作成オプション。 |
| [SevenZipAESEncryptionSettings](./sevenzipaesencryptionsettings/) | 7z アーカイブ内の AES 暗号化または復号化アルゴリズムの設定。 |
| [SevenZipArchiveSaveOptions](./sevenziparchivesaveoptions/) | 7Z アーカイブを保存するためのオプション。 |
| [SevenZipBZip2CompressionSettings](./sevenzipbzip2compressionsettings/) | 7z アーカイブ内の BZip2 圧縮方式の設定。 |
| [SevenZipCompressionSettings](./sevenzipcompressionsettings/) | 7z 圧縮器または解凍器が動作するために必要な設定。 |
| [SevenZipEncryptionSettings](./sevenzipencryptionsettings/) | 複数の 7z 暗号化方式の設定用の基底クラス。 |
| [SevenZipEntrySettings](./sevenzipentrysettings/) | 7Z エントリを圧縮または解凍するために使用される設定。 |
| [SevenZipLZMA2CompressionSettings](./sevenziplzma2compressionsettings/) | 7z アーカイブ内の LZMA2 圧縮方式の設定。 |
| [SevenZipLZMACompressionSettings](./sevenziplzmacompressionsettings/) | 7z アーカイブ内の LZMA 圧縮方式の設定。 |
| [SevenZipPPMdCompressionSettings](./sevenzipppmdcompressionsettings/) | 7z アーカイブ内の PPMd 圧縮方式の設定。 |
| [SevenZipStoreCompressionSettings](./sevenzipstorecompressionsettings/) | 7z アーカイブ内の Store 圧縮方式の設定。 |
| [SplitArchiveSaveOptions](./splitarchivesaveoptions/) | マルチボリューム ZIP アーカイブを保存するためのオプション。 |
| [SplitSevenZipArchiveSaveOptions](./splitsevenziparchivesaveoptions/) | マルチボリューム 7-zip アーカイブを保存するためのオプション。 |
| [StoreCompressionSettings](./storecompressionsettings/) | ZIP アーカイブ内の Store 圧縮の設定。 |
| [TraditionalEncryptionSettings](./traditionalencryptionsettings/) | ZIP アーカイブ内の従来の ZipCrypto アルゴリズムの設定。 |
| [XzCompressionSettings](./xzcompressionsettings/) | ZIP アーカイブ内の Xz 圧縮の設定。 |
| [ZstandardCompressionSettings](./zstandardcompressionsettings/) | ZIP アーカイブ内の Zstandard 圧縮の設定。 |
