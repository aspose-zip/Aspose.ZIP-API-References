## LzipArchiveSettings.CompressionThreads property

圧縮スレッド数を取得または設定します。値が 1 より大きい場合、マルチスレッド圧縮が使用されます。

```csharp
public int CompressionThreads { get; set; }
```

### 例外

| 例外 | 条件 |
| --- | --- |
| ArgumentOutOfRangeException | スレッド数は 100 を超えています。 |

## 備考

この数値を CPU コア数以上に設定しないでください。
