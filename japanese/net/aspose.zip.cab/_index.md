Cab 名前空間には、Cab アーカイブ関連エンティティを表すクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [CabArchive](./cabarchive/) | このクラスは CAB アーカイブ ファイルを表します。 |
| [CabCompressionSettings](./cabcompressionsettings/) | CAB コンプレッサが機能するために必要な設定です。 |
| [CabEntry](./cabentry/) | CAB アーカイブ内の単一ファイルを表します。 |
| [CabEntrySettings](./cabentrysettings/) | CAB エントリの書き込み方法を制御する設定です。 |
| [CabLoadOptions](./cabloadoptions/) | 圧縮ファイルからアーカイブを読み込む際のオプションです。 |
| [CabMsZipCompressionSettings](./cabmszipcompressionsettings/) | MSZip（デフレート）圧縮を使用して CAB データブロックをエンコードする圧縮設定です。 |
| [CabSaveOptions](./cabsaveoptions/) | CAB アーカイブを保存するためのオプションです。 |
| [CabStoreCompressionSettings](./cabstorecompressionsettings/) | CAB データブロックを非圧縮のまま保持する圧縮設定です。 |
