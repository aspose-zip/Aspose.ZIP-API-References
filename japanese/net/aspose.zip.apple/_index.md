Apple 名前空間には、Apple Archive 関連エンティティを表すクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [AppleArchive](./applearchive/) | このクラスは Apple アーカイブ (.aar) ファイルを表します。Apple アーカイブ ファイルを作成するために使用します。 |
| [AppleArchiveEntry](./applearchiveentry/) | [`AppleArchive`](../aspose.zip.apple/applearchive/) 内のファイルシステム エントリを表します。 |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | [`AppleArchive`](../aspose.zip.apple/applearchive/) 内のエントリを作成するために使用される設定。 |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | 圧縮ファイルから [`AppleArchive`](../aspose.zip.apple/applearchive/) を読み込む際のオプション。 |
| [AppleCompressionSettings](./applecompressionsettings/) | Apple アーカイブ エントリの圧縮に必要な設定。 |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Apple アーカイブ (.aar) ファイル内の LZ4 圧縮の設定。 |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Apple アーカイブ (.aar) ファイル内の LZFSE 圧縮の設定。 |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Apple アーカイブ (.aar) ファイル内の LZMA 圧縮の設定。 |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Apple アーカイブ (.aar) ファイル内のストア（圧縮なし）設定。 |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Apple アーカイブ (.aar) ファイル内の Zlib 圧縮の設定。 |
