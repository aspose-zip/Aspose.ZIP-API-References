## AppleArchive.IsSolid property

アーカイブがソリッド圧縮を使用しているかどうかを示す値を取得します。ソリッドモードでは、すべてのエントリデータが単一のストリームとして圧縮され、個別のエントリ抽出は利用できません。代わりに [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/) を使用してください。

```csharp
public bool IsSolid { get; }
```
