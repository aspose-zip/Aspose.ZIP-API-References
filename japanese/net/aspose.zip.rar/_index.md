Rar 名前空間には、RAR アーカイブ関連エンティティを表すクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [RarArchive](./rararchive/) | このクラスは RAR アーカイブファイルを表します。RAR アーカイブの抽出に使用してください。 |
| [RarArchiveEntry](./rararchiveentry/) | アーカイブ内の単一ファイルを表します。 |
| [RarArchiveEntryEncrypted](./rararchiveentryencrypted/) | 復号付きで解凍する必要がある Zip エントリです。 |
| [RarArchiveEntryPlain](./rararchiveentryplain/) | 復号せずに解凍する必要がある Rar エントリです。 |
| [RarArchiveLoadOptions](./rararchiveloadoptions/) | 圧縮ファイルから [`RarArchive`](../aspose.zip.rar/rararchive/) をロードする際のオプションです。 |
## 列挙

| 列挙 | 説明 |
| --- | --- |
| [RarDictionaryStorageMode](./rardictionarystoragemode/) | RAR 解凍辞書がどのように保存されるかを指定します。 |
