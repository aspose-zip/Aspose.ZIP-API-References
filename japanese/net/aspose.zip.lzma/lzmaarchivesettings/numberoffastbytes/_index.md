## LzmaArchiveSettings.NumberOfFastBytes property

LZMA アルゴリズムで高速マッチ検索に使用されるバイト数を取得または設定します。

```csharp
public int NumberOfFastBytes { get; set; }
```

## 備考

値を大きくすると、コンプレッサがより長いマッチを検索できるようになり、圧縮率がわずかに向上する可能性がありますが、圧縮速度が低下します。
