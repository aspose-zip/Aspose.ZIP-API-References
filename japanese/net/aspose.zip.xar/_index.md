Xar 名前空間には、Xar アーカイブに関連するエンティティを表すクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [CancelEntryEventArgs](./cancelentryeventargs/) | キャンセル可能なエントリ関連イベントのイベント引数です。 |
| [EntryEventArgs](./entryeventargs/) | エントリ関連イベントのイベント引数です。 |
| [EventsBag](./eventsbag/) | [`XarArchive`](../aspose.zip.xar/xararchive/) の保存時に使用されるイベント コンテナです。 |
| [XarArchive](./xararchive/) | このクラスは xar アーカイブ ファイルを表します。 |
| [XarBzip2CompressionSettings](./xarbzip2compressionsettings/) | Bzip2 圧縮方式の設定。 |
| [XarCompressionSettings](./xarcompressionsettings/) | コンプレッサが機能するために必要な設定。 |
| [XarDirectoryEntry](./xardirectoryentry/) | xar アーカイブ内のディレクトリ エントリを表します。 |
| [XarEntry](./xarentry/) | xar アーカイブ内の単一エントリを表します。 |
| [XarFileEntry](./xarfileentry/) | xar アーカイブ内のファイル エントリを表します。 |
| [XarLoadOptions](./xarloadoptions/) | 圧縮ファイルから XAR アーカイブをロードする際のオプション。 |
| [XarSaveOptions](./xarsaveoptions/) | xar アーカイブを保存するためのオプション。 |
| [XarStoreCompressionSettings](./xarstorecompressionsettings/) | Store 圧縮方式の設定。 |
| [XarZlibCompressionSettings](./xarzlibcompressionsettings/) | Zlib 圧縮方式の設定。 |
