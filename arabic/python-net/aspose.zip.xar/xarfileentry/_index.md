## XarFileEntry class

يمثل إدخال ملف داخل أرشيف xar.

يعرض نوع XarFileEntry الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على اسم العنصر داخل الأرشيف. |
| المسار_الكامل | يحصل على المسار الكامل للمدخل داخل الأرشيف. |
| is_directory | يحصل على قيمة تشير إلى ما إذا كان العنصر يمثل دليلًا. |
| الأصل | يحصل على الدليل الأصل الذي ينتمي إليه الإدخال. |
| وقت_الإنشاء | يحصل على وقت إنشاء الملف أو الدليل. |
| وقت_آخر_وصول | يحصل على آخر وقت وصول للملف أو الدليل. |
| وقت_آخر_كتابة | يحصل على وقت تعديل الملف أو الدليل. |
| modification_time | يحصل على وقت تعديل الملف أو الدليل. |
| length | يحصل على طول العنصر بالبايت. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| extract(path) | يستخرج العنصر إلى نظام الملفات باستخدام المسار المحدد. |
| extract(destination) | يستخرج العنصر إلى الدفق المحدد. |
| open() | يفتح الإدخال للاستخراج ويوفر تدفقًا بمحتوى الإدخال. |
