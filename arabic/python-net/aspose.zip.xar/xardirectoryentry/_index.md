## XarDirectoryEntry class

يمثل إدخال دليل داخل أرشيف xar.

يعرض النوع XarDirectoryEntry الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على اسم العنصر داخل الأرشيف. |
| المسار_الكامل | يحصل على المسار الكامل للمدخل داخل الأرشيف. |
| is_directory | يحصل على قيمة تشير إلى ما إذا كان العنصر يمثل دليلًا. |
| الأصل | يحصل على الدليل الأصل الذي ينتمي إليه الإدخال. |
| وقت_الإنشاء | يحصل على وقت إنشاء الملف أو الدليل. |
| وقت_آخر_وصول | يحصل على آخر وقت وصول للملف أو الدليل. |
| وقت_آخر_كتابة | يحصل على وقت تعديل الملف أو الدليل. |
| modification_time | يحصل على وقت تعديل الملف أو الدليل. |
| files_and_directories | يسترجع إدخالات من النوع [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/) التي تُشكل الدليل. |
| directories | يسترجع إدخالات من النوع [XarDirectoryEntry](/zip/python-net/aspose.zip.xar/xardirectoryentry/) التي تُشكل الدليل. |
| files | يسترجع إدخالات من النوع [XarFileEntry](/zip/python-net/aspose.zip.xar/xarfileentry/) التي تُشكل الدليل. |
| all_entries | يسترجع جميع الإدخالات من النوع [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/) التي تُشكل الدليل بشكل متكرر. |
