## SevenZipArchiveEntry class

يمثل ملفًا واحدًا داخل أرشيف 7z.

يعرض نوع SevenZipArchiveEntry الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على اسم العنصر داخل الأرشيف. |
| modification_time | يحصل على تاريخ ووقت التعديل الأخير. |
| uncompressed_size | يحصل على حجم الملف الأصلي. |
| compressed_size | يحصل على حجم الملف المضغوط. |
| is_directory | يحصل على قيمة تشير إلى ما إذا كان العنصر يمثل دليلًا. |
| compression_settings | يحصل على الإعدادات للضغط أو فك الضغط. |
| length | يحصل على طول العنصر بالبايت. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| extract(path, password) | يستخرج العنصر إلى نظام الملفات باستخدام المسار المحدد. |
| extract(destination, password) | يستخرج العنصر إلى الدفق المحدد. |
| extract(path) | يستخرج العنصر إلى نظام الملفات باستخدام المسار المحدد. |
| extract(destination) | يستخرج العنصر إلى الدفق المحدد. |
| open(password) | يفتح الإدخال للاستخراج ويوفر تدفقًا بمحتوى الإدخال. |
