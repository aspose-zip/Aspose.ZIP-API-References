## LzxArchiveEntry class

تمثل ملفًا واحدًا داخل أرشيف LZX.

نوع LzxArchiveEntry يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على اسم العنصر. |
| تعليق | يحصل على التعليق. |
| length | يحصل على طول العنصر بالبايت. |
| uncompressed_size | يحصل على حجم الملف الأصلي. |
| compressed_size | يحصل على حجم الملف المضغوط. |
| is_directory | يحصل على قيمة تشير إلى ما إذا كان هذا الإدخال دليلًا. |
| modification_time | يحصل على وقت التعديل الأخير للإدخال. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| extract(path) | يستخرج إدخال أرشيف Lzx إلى نظام الملفات حسب المسار. |
| extract(destination) | يستخرج العنصر إلى الدفق المحدد. |
