## XzArchiveSettings class

الفئة تحتوي على مجموعة من الإعدادات لأرشيف xz معين.

يعرض نوع XzArchiveSettings الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| XzArchiveSettings() | ينشئ مثيلاً جديداً من الفئة [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) باستخدام ضغط LZMA2 أحادي. |
| XzArchiveSettings(filters, block_size, check_type) | ينشئ مثيلاً جديداً من الفئة [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) بمعلمات مخصصة. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| compression_threads | يحصل أو يضبط عدد خيوط الضغط. إذا كانت القيمة أكبر من 1، سيتم استخدام الضغط متعدد الخيوط. |
| fastest_speed | يحصل على مثيل الفئة [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) <br/>            بحجم القاموس يساوي 65536 بايت في مرشح LZMA2، وحجم الكتلة يساوي 1 ميغابايت وتحقق CRC32. |
| fast_speed | يحصل على مثيل الفئة [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) <br/>            بحجم القاموس يساوي 1 ميغابايت في مرشح LZMA2، وحجم الكتلة يساوي 4 ميغابايت وتحقق CRC32. |
| normal | يحصل على مثيل الفئة [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) <br/>            بحجم القاموس يساوي 16 ميغابايت في مرشح LZMA2، وحجم الكتلة يساوي 64 ميغابايت وتحقق CRC32. |
| high_compression | يحصل على مثيل الفئة [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) <br/>            بحجم القاموس يساوي 32 ميغابايت في مرشح LZMA2، وحجم الكتلة يساوي 128 ميغابايت وتحقق CRC32. |
| maximum_compression | يحصل على مثيل الفئة [XzArchiveSettings](/zip/python-net/aspose.zip.xz.settings/xzarchivesettings/) <br/>            بحجم القاموس يساوي 64 ميغابايت في مرشح LZMA2، وحجم الكتلة يساوي 256 ميغابايت وتحقق CRC32. |
