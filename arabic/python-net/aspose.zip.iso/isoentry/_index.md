## IsoEntry class

يمثل إدخالًا (ملفًا أو دليلًا) داخل أرشيف ISO.

يعرض نوع IsoEntry الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على اسم العنصر. |
| is_directory | يحصل على قيمة تشير إلى ما إذا كان العنصر دليلًا. |
| length | يحصل أو يضبط تاريخ ووقت الإنشاء. |
| modification_time | يحصل أو يضبط تاريخ ووقت التعديل الأخير. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| extract(path) | يستخرج العنصر إلى نظام الملفات باستخدام المسار المحدد. |
| extract(destination) | يستخرج العنصر إلى الدفق المحدد. |
