## LzmaArchiveSettings class

إعدادات أرشيف lzma.

## المُنشئات
| الاسم | الوصف |
| :- | :- |
| LzmaArchiveSettings() | ينشئ مثيلاً جديدًا من الفئة [LzmaArchiveSettings](/zip/python-net/aspose.zip.lzma/lzmaarchivesettings/) بحجم القاموس الافتراضي، وهو 16 ميغابايت، وعدد البايتات السريعة يساوي 32، وعدد بتات سياق الحرف الحرفي يساوي 3. |

| :- | :- |
