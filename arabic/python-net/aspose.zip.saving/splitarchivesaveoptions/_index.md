## SplitArchiveSaveOptions class

خيارات حفظ أرشيف ZIP متعدد الأحجام.

يعرض نوع SplitArchiveSaveOptions الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| SplitArchiveSaveOptions(file_name, segment_size) | ينشئ إعدادات لحفظ أرشيف ZIP متعدد الأحجام. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| segment_size | يسترجع حجم الجزء. |
| file_name | يسترجع اسم المقاطع بدون امتداد. |
| archive_comment | يحصل أو يضبط التعليق الاختياري لملف Zip. |
| encoding | يحصل أو يضبط الترميز لتحويل أسماء الملفات والسلاسل الأخرى إلى بايتات. |
| close_entry_source | يحصل أو يضبط قيمة تشير إلى ما إذا كان يجب إغلاق مصادر الإدخالات مباشرةً بعد ضغط الإدخال. |
| events_bag | يحصل أو يعيّن حاوية الأحداث التي تُرفع عند حفظ الأرشيف. |
