## SevenZipEntrySettings class

الإعدادات المستخدمة لضغط أو فك ضغط مدخلات 7Z.

يعرض نوع SevenZipEntrySettings الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| SevenZipEntrySettings(compression_settings, encryption_settings) | ينشئ مثيلاً جديدًا من الفئة [SevenZipEntrySettings](/zip/python-net/aspose.zip.saving/sevenzipentrysettings/). |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| compression_settings | يحصل على إعدادات روتين الضغط أو فك الضغط. |
| encryption_settings | يحصل على إعدادات التشفير أو فك التشفير. قد تختلف إعدادات الإدخال المحدد. |
| compress_header | يحصل أو يضبط القيمة التي تشير إلى ما إذا كان يجب ضغط رأس الأرشيف. |
| solid | يحصل أو يضبط القيمة التي تشير إلى ما إذا كان يجب ربط الإدخالات ومعاملتها ككتلة بيانات واحدة. |
