## SevenZipLZMA2CompressionSettings class

إعدادات طريقة ضغط LZMA2 داخل أرشيف 7z.

يعرض النوع SevenZipLZMA2CompressionSettings الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| SevenZipLZMA2CompressionSettings(dictionary_size) | يُنشئ مثلاً جديداً من الفئة SevenZipLZMA2CompressionSettings |
| SevenZipLZMA2CompressionSettings(dictionary_size, fast_bytes) | يُنشئ مثلاً جديداً من الفئة SevenZipLZMA2CompressionSettings |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| طريقة | يحصل على طريقة الضغط أو فك الضغط. |
| compression_threads | يحصل أو يضبط عدد خيوط الضغط. إذا كانت القيمة أكبر من 1، سيتم استخدام الضغط متعدد الخيوط. |
| dictionary_size | حجم القاموس (مخزن التاريخ) يشير إلى عدد البايتات من البيانات غير المضغوطة التي تمت معالجتها مؤخرًا والتي تُحفظ في الذاكرة. |
| fast_bytes | يحصل على عدد الـ fast bytes المتحكم به المستخدم بواسطة ضاغط LZMA2. |
