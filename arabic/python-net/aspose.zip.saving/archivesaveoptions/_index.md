## ArchiveSaveOptions class

خيارات لحفظ أرشيف ZIP.

نوع ArchiveSaveOptions يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ArchiveSaveOptions() | ينشئ مثيلاً جديداً من الفئة ArchiveSaveOptions. |

| الاسم | الوصف |
| :- | :- |
| encoding | يحصل أو يضبط الترميز لتحويل أسماء الملفات والسلاسل الأخرى إلى بايتات. |
| archive_comment | يحصل أو يضبط التعليق الاختياري لملف Zip. |

| close_entry_source | يحصل أو يضبط قيمة تشير إلى ما إذا كان يجب إغلاق مصادر الإدخالات مباشرةً بعد ضغط الإدخال. |
