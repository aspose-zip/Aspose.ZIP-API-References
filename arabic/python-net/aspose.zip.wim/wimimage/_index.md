## WimImage class

| الاسم | الوصف |
| :- | :- |
| root_directory | يحصل على إدخال الدليل الجذر للصورة. |
| all_entries | يحصل على إدخالات من نوع [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) التي تشكل الصورة بشكل متكرر. |

| الاسم | الوصف |
