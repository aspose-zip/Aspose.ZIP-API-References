## WimArchive class

هذه الفئة تمثل ملف أرشيف wim.

يعرض نوع WimArchive الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| WimArchive(source_stream, load_options) | ينشئ مثيلًا جديدًا من الفئة [WimArchive](/zip/python-net/aspose.zip.wim/wimarchive/) ويكوّن قائمة إدخالات يمكن استخراجها من الأرشيف. |
| WimArchive(path, load_options) | ينشئ مثيلًا جديدًا من الفئة [WimArchive](/zip/python-net/aspose.zip.wim/wimarchive/) ويكوّن قائمة إدخالات يمكن استخراجها من الأرشيف. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| images | يحصل على إدخالات من نوع [WimImage](/zip/python-net/aspose.zip.wim/wimimage/) التي تشكل الأرشيف. |
| entries | يحصل على إدخالات من نوع [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) التي تشكل الأرشيف. |
| guid | يحصل على GUID التعريفي للأرشيف. |
| boot_image_index | يحصل على الفهرس (المبني على الصفر) للصورة القابلة للتمهيد. |
| file_format_version | يحصل على نسخة تنسيق الملف. |
| manifest | يحصل على البيان المدمج الذي يصف الملف والصور المحتواة. |
| file_entries | يسترجع الإدخالات من نوع [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) التي تشكل الأرشيف. |
| الصيغة | يحصل على صيغة الأرشيف. |
