## RarArchive class

هذه الفئة تمثل ملف أرشيف RAR. استخدمها لاستخراج أرشيفات RAR.

نوع RarArchive يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| RarArchive(path, load_options) | يُنشئ مثيلاً جديدًا لفئة [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) ويُكوّن قائمة إدخالات يمكن استخراجها من الأرشيف. |
| RarArchive(source_stream, load_options) | يُنشئ مثيلاً جديدًا لفئة [RarArchive](/zip/python-net/aspose.zip.rar/rararchive/) ويُكوّن قائمة إدخالات يمكن استخراجها من الأرشيف. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| entries | يحصل على الإدخالات من نوع [RarArchiveEntry](/zip/python-net/aspose.zip.rar/rararchiveentry/) التي تُكوّن أرشيف RAR. |
| file_entries | يسترجع الإدخالات من نوع [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) التي تشكل الأرشيف. |
| الصيغة | يحصل على صيغة الأرشيف. |
