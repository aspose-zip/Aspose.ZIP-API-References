## IArchiveFileEntry class

هذه الواجهة تمثل إدخال ملف أرشيف.

نوع IArchiveFileEntry يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على اسم العنصر. |
| length | يحصل على طول العنصر بالبايت. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| extract(path) | يستخرج العنصر إلى نظام الملفات باستخدام المسار المحدد. |
| extract(destination) | يستخرج العنصر إلى الدفق المحدد. |
