## ArchiveLoadOptions class

الخيارات التي يتم من خلالها تحميل أرشيف ZIP من ملف مضغوط.

نوع ArchiveLoadOptions يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ArchiveLoadOptions() | ينشئ مثيلًا جديدًا من الفئة ArchiveLoadOptions. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| decryption_password | يحصل أو يحدد كلمة المرور لفك تشفير العناصر. |
| encoding | يحصل أو يحدد الترميز لأسماء العناصر. |
| skip_checksum_verification | احصل أو عيّن قيمة تشير إلى ما إذا كان يجب تخطي التحقق من مجموع التحقق لعناصر ZIP وتجاهل عدم التطابق. القيمة الافتراضية هي false. |
| forward_only | يتم استخراج الأرشيف من تدفق للقراءة فقط. |
