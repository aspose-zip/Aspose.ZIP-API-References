## UueSaveOptions class

خيارات حفظ ملف uuencoded.

يعرض نوع UueSaveOptions الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| UueSaveOptions(file_name, new_line) | يُهيئ الخيارات باستخدام اسم الملف الذي يقدمه المستخدم وسطر جديد. |
| UueSaveOptions(file_name) | يُهيئ الخيارات باستخدام اسم الملف الذي يقدمه المستخدم وسطر جديد. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| new_line | يحصل على الحرف الذي ينهي كل سطر، عادةً "\n" أو "\r\n". |
| file_name | يحصل على اسم الملف الذي سيُستخدم عند إعادة إنشاء البيانات المفككة. |
| unix_file_permissions | يحصل على أذونات ملف Unix للملف. |
