## LzipArchiveSettings class

الفئة تحتوي على إعداد لأرشيف lzip معين.

يعرض نوع LzipArchiveSettings الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| LzipArchiveSettings(dictionary_size, max_member_size) | ينشئ مثيلاً جديداً من [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) بحجم قاموس معين. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| fastest_speed | يحصل على مثيل [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) الفئة<br/>            بحجم القاموس يساوي 65536 بايت في مرشح LZMA. |
| fast_speed | يحصل على مثيل [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) الفئة<br/>            بحجم القاموس يساوي 1 ميغابايت في مرشح LZMA. |
| normal | يحصل على مثيل [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) الفئة<br/>            بحجم القاموس يساوي 16 ميغابايت في مرشح LZMA. |
| high_compression | يحصل على مثيل [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) الفئة<br/>            بحجم القاموس يساوي 32 ميغابايت في مرشح LZMA. |
| maximum_compression | يحصل على مثيل [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) الفئة<br/>            بحجم القاموس يساوي 64 ميغابايت في مرشح LZMA. |
| dictionary_size | يحصل على حجم القاموس المستخدم في ضغط LZMA. |
| max_member_size | يحصل على الحد الأقصى لحجم عضو واحد في أرشيف lzip معروض بالبايت. |
| compression_threads | يحصل أو يضبط عدد خيوط الضغط. إذا كانت القيمة أكبر من 1، سيتم استخدام الضغط متعدد الخيوط. |
