## AppleArchiveEntry class

تمثل إدخال ملف أو دليل داخل [AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/).

يعرض نوع AppleArchiveEntry الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على مسار الإدخال داخل الأرشيف. |
| length | يحصل على الطول غير المضغوط للإدخال بالبايت. |
| is_directory | يحصل على قيمة تشير إلى ما إذا كان العنصر يمثل دليلًا. |
## الطرق
| الاسم | الوصف |
| :- | :- |
