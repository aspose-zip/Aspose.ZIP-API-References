## XzArchive class

هذه الفئة تمثل ملف أرشيف xz. استخدمها لإنشاء واستخراج أرشيفات xz.

يعرض نوع XzArchive الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| XzArchive(settings) | ينشئ مثلاً جديداً من الفئة [XzArchive](/zip/python-net/aspose.zip.xz/xzarchive/) ويُكوّن الأرشيف بتنسيق xz. |
| XzArchive(source, options) | ينشئ مثلاً جديداً من الفئة [XzArchive](/zip/python-net/aspose.zip.xz/xzarchive/) مُجهّزاً لفك الضغط. |
| XzArchive(path, options) | ينشئ مثلاً جديداً من الفئة [XzArchive](/zip/python-net/aspose.zip.xz/xzarchive/) مُجهّزاً لفك الضغط. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| uncompressed_size | الحجم غير المضغوط لبيانات الملف بالبايت. |
| file_entries | يسترجع الإدخالات من نوع [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) التي تشكل الأرشيف. |
| الصيغة | يحصل على صيغة الأرشيف. |
| name | يحصل على اسم العنصر. |
| length | يحصل على طول العنصر بالبايت. |
