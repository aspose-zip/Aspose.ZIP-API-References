## LhaArchiveEntry class

تمثل ملفًا واحدًا داخل أرشيف Lha.

يعرض نوع LhaArchiveEntry الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على اسم العنصر. |
| length | يحصل على طول العنصر بالبايت. |
| is_directory | يحصل على قيمة تشير إلى ما إذا كان هذا الإدخال دليلًا. |
| last_modified | يحصل على وقت التعديل الأخير للإدخال. |
| modification_time | يحصل على وقت التعديل الأخير للإدخال. |
| path | يحصل على المسار الكامل للإدخال. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| extract(path) | يستخرج إدخال أرشيف Lha إلى نظام ملفات حسب المسار. |
| extract(destination) | يستخرج العنصر إلى الدفق المحدد. |
| extract(file_info) | يستخرج إدخال أرشيف Lha إلى ملف. |
