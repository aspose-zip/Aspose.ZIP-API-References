## AlzEntry class

Bir ALZ arşivindeki tüm meta verileri içeren dosya girdisini temsil eder.

AlzEntry türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| compressed_size | Dosya verisinin sıkıştırılmış boyutu (bayt cinsinden). |
| uncompressed_size | Dosya verisinin sıkıştırılmamış boyutu bayt cinsinden. |
| length | Girdinin uzunluğunu bayt cinsinden alır. |
| is_directory | Bu giriş bir dizini temsil ediyorsa true döndürür. |
| name | Dosya adı (yol olmadan). |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract(path, password) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination, password) | Girişi sağlanan akıma çıkarır. |
| extract(path) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
| open(password) | Girdiyi çıkartma için açar ve sıkıştırması çözülmüş içerik akışı sağlar. |
