## IsoEntry class

ISO arşivinde bir giriş (dosya veya dizin) temsil eder.

IsoEntry türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Girişin adını alır. |
| is_directory | Girişin bir dizin olup olmadığını gösteren bir değeri alır. |
| length | Oluşturma tarih ve saatini alır veya ayarlar. |
| modification_time | Son değiştirilme tarih ve saatini alır veya ayarlar. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract(path) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
