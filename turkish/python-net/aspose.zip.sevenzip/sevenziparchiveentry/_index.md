## SevenZipArchiveEntry class

7z arşivi içinde tek bir dosyayı temsil eder.

SevenZipArchiveEntry türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Arşiv içindeki girdinin adını alır. |
| modification_time | Son değiştirilme tarih ve saatini alır. |
| uncompressed_size | Orijinal dosyanın boyutunu alır. |
| compressed_size | Sıkıştırılmış dosyanın boyutunu alır. |
| is_directory | Girdinin bir dizin olup olmadığını gösteren bir değeri alır. |
| compression_settings | Sıkıştırma veya sıkıştırma çözme ayarlarını alır. |
| length | Girdinin uzunluğunu bayt cinsinden alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract(path, password) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination, password) | Girişi sağlanan akıma çıkarır. |
| extract(path) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
| open(password) | Girişi çıkartma için açar ve giriş içeriğiyle bir akış sağlar. |
