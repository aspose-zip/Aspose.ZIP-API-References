## LhaArchiveEntry class

Lha arşivi içinde tek bir dosyayı temsil eder.

LhaArchiveEntry türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Girdinin adını alır. |
| length | Girdinin uzunluğunu bayt cinsinden alır. |
| is_directory | Bu girişin bir dizin olup olmadığını gösteren bir değer alır. |
| last_modified | Girişin son değiştirilme zamanını alır. |
| modification_time | Girişin son değiştirilme zamanını alır. |
| path | Girişin tam yolunu alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract(path) | Lha arşiv girişini yola göre bir dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
| extract(file_info) | Lha arşiv girişini bir dosyaya çıkarır. |
