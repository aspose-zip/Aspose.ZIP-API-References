## SevenZipLZMA2CompressionSettings class

7z arşivi içinde LZMA2 sıkıştırma yöntemi için ayarlar.

SevenZipLZMA2CompressionSettings türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| SevenZipLZMA2CompressionSettings(dictionary_size) | SevenZipLZMA2CompressionSettings sınıfının yeni bir örneğini başlatır |
| SevenZipLZMA2CompressionSettings(dictionary_size, fast_bytes) | SevenZipLZMA2CompressionSettings sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| metot | Sıkıştırma veya açma yöntemini alır. |
| compression_threads | Sıkıştırma iş parçacığı sayısını alır veya ayarlar. Değer 1'den büyükse çok iş parçacıklı sıkıştırma kullanılacaktır. |
| dictionary_size | Sözlük (geçmiş tamponu) boyutu, son işlenen sıkıştırılmamış verinin kaç baytının bellekte tutulduğunu gösterir. |
| fast_bytes | LZMA2 sıkıştırıcısı tarafından kullanılan hızlı baytların kontrol sayısını alır. |
