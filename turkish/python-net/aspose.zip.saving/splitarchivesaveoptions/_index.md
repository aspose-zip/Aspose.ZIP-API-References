## SplitArchiveSaveOptions class

Çok bölümlü ZIP arşivi kaydetme seçenekleri.

SplitArchiveSaveOptions türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| SplitArchiveSaveOptions(file_name, segment_size) | Çok bölümlü bir ZIP arşivi kaydetmek için ayarları oluşturur. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| segment_size | Segmentin boyutunu alır. |
| file_name | Uzantısı olmadan segmentlerin adını alır. |
| archive_comment | Zip dosyası için isteğe bağlı yorumu alır veya ayarlar. |
| encoding | Dosya adlarını ve diğer dizeleri baytlara dönüştürmek için kodlamayı alır veya ayarlar. |
| close_entry_source | Bir girdinin sıkıştırılmasının hemen ardından girdilerin kaynaklarının kapatılıp kapatılmayacağını gösteren bir değeri alır veya ayarlar. |
| events_bag | Arşiv kaydedilirken tetiklenen olayların konteynerini alır veya ayarlar. |
