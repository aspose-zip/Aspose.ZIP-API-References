## TarEntry class

Tar arşivi içinde tek bir dosyayı temsil eder.

TarEntry türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Arşiv içindeki girdinin adını alır veya ayarlar. |
| length | Girdinin uzunluğunu bayt cinsinden alın. |
| uncompressed_size | Orijinal dosyanın boyutunu alır. |
| is_directory | Girdinin bir dizin olup olmadığını gösteren bir değeri alır. |
| modification_time | Dosyanın veya dizinin değiştirilme zamanını alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract(path) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
| open() | Girişi çıkartma için açar ve giriş içeriğiyle bir akış sağlar. |
