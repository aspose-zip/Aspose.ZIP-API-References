## SevenZipCipher class

7-zip şifrelemesi için kullanılan AES şifreleme algoritmasının temel sınıfı.

SevenZipCipher türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| can_reuse_transform | Mevcut dönüşümün yeniden kullanılabilir olup olmadığını belirten bir değeri alır. |
| can_transform_multiple_blocks | Birden fazla bloğun dönüştürülebilir olup olmadığını belirten bir değeri alır. |
| input_block_size | Girdi blok boyutunu alır. |
| output_block_size | Çıktı blok boyutunu alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| transform_block(input_buffer, input_offset, input_count, output_buffer, output_offset) | Giriş bayt dizisinin belirtilen bölgesini dönüştürür ve ortaya çıkan dönüşümü çıkış bayt dizisinin belirtilen bölgesine kopyalar. |
| transform_final_block(input_buffer, input_offset, input_count) | Belirtilen bayt dizisinin belirtilen bölgesini dönüştürür. |
