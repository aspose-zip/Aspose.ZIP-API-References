## CabEntry class

CAB arşivi içinde tek bir dosyayı temsil eder.

CabEntry türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Arşiv içindeki girdinin adını alır. |
| length | Girdinin uzunluğunu bayt cinsinden alır. |
| modification_time | Son değiştirilme tarih ve saatini alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract(path) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
| open() | Girişi çıkartma için açar ve giriş içeriğiyle bir akış sağlar. |
