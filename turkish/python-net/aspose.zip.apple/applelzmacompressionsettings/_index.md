## AppleLzmaCompressionSettings class

Bir Apple Archive (.aar) dosyası içinde LZMA sıkıştırması için ayarlar.

AppleLzmaCompressionSettings türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| AppleLzmaCompressionSettings(block_size, dictionary_size) | AppleLzmaCompressionSettings sınıfının yeni bir örneğini başlatır |
| AppleLzmaCompressionSettings(block_size, dictionary_size, fast_bytes) | AppleLzmaCompressionSettings sınıfının yeni bir örneğini başlatır |
| AppleLzmaCompressionSettings() | [AppleLzmaCompressionSettings](/zip/python-net/aspose.zip.apple/applelzmacompressionsettings/) sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| lz4 | Varsayılan parametrelerle [AppleLz4CompressionSettings](/zip/python-net/aspose.zip.apple/applelz4compressionsettings/) örneği. |
| lzfse | Varsayılan parametrelerle [AppleLzfseCompressionSettings](/zip/python-net/aspose.zip.apple/applelzfsecompressionsettings/) bir örnek. |
| lzma | Varsayılan parametrelerle [AppleLzmaCompressionSettings](/zip/python-net/aspose.zip.apple/applelzmacompressionsettings/) bir örnek. |
| store | Varsayılan parametrelerle [AppleStoreCompressionSettings](/zip/python-net/aspose.zip.apple/applestorecompressionsettings/) bir örnek. |
| zlib | Varsayılan parametrelerle [AppleZlibCompressionSettings](/zip/python-net/aspose.zip.apple/applezlibcompressionsettings/) bir örnek. |
| block_size | Sıkıştırmadan önce her veri bloğunun boyutunu alır. |
| dictionary_size | Sıkıştırma için kullanılan sözlük boyutunu alır. |
| fast_bytes | Sıkıştırma için kullanılan hızlı bayt sayısını alır. |
