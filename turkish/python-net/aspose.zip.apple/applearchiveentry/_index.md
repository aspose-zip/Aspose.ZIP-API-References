## AppleArchiveEntry class

[AppleArchive](/zip/python-net/aspose.zip.apple/applearchive/) içinde bir dosya veya dizin girdisini temsil eder.

AppleArchiveEntry türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Arşiv içindeki girişin yolunu alır. |
| length | Girişin sıkıştırılmamış uzunluğunu bayt cinsinden alır. |
| is_directory | Girdinin bir dizin olup olmadığını gösteren bir değeri alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract(path) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
| open() | Girişi çıkarma için açar ve giriş içeriğiyle bir akış sağlar. |
