## LzxArchiveEntry class

LZX arşivi içinde tek bir dosyayı temsil eder.

LzxArchiveEntry türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Girdinin adını alır. |
| yorum | Yorumu alır. |
| length | Girdinin uzunluğunu bayt cinsinden alır. |
| uncompressed_size | Orijinal dosyanın boyutunu alır. |
| compressed_size | Sıkıştırılmış dosyanın boyutunu alır. |
| is_directory | Bu girişin bir dizin olup olmadığını gösteren bir değer alır. |
| modification_time | Girişin son değiştirilme zamanını alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract(path) | Lzx arşiv girişini yola göre bir dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
