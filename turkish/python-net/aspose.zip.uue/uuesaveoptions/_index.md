## UueSaveOptions class

uuencoded dosyasını kaydetme seçenekleri.

UueSaveOptions türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| UueSaveOptions(file_name, new_line) | Seçenekleri, kullanıcı tarafından sağlanan dosya adı ve yeni satır ile başlatır. |
| UueSaveOptions(file_name) | Seçenekleri, kullanıcı tarafından sağlanan dosya adı ve yeni satır ile başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| new_line | Her satırı sonlandıran karakteri alır, genellikle "\n" veya "\r\n". |
| file_name | Kod çözülmüş veriyi yeniden oluştururken kullanılacak dosya adını alır. |
| unix_file_permissions | Dosyanın Unix dosya izinlerini alır. |
