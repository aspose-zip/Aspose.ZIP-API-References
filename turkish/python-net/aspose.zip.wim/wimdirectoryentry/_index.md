## WimDirectoryEntry class

wim arşivi içinde tek bir dizini temsil eder.

WimDirectoryEntry türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| archive | Girişin ait olduğu archive'ı alır. |
| image | Girişin ait olduğu image'ı alır. |
| parent | Girişin ait olduğu parent dizini alır. |
| name | Image içindeki girişin adını alır. |
| short_name | Image içindeki girişin kısa adını alır. |
| full_path | Image içindeki girişin tam yolunu alır. |
| change_time | Dosya veya dizinin son değiştirildiği zamanı alır. |
| creation_time | Dosya veya dizinin oluşturulma zamanını alır. |
| last_access_time | Dosya veya dizinin son erişim zamanını alır. |
| last_write_time | Dosyanın veya dizinin değiştirilme zamanını alır. |
| modification_time | Dosyanın veya dizinin değiştirilme zamanını alır. |
| alternate_data_streams | Bir dosya veya dizin için alternatif veri akışlarının adlarını alır. |
| hard_link | Dosya veya dizinin hardlink kimliğini alır. |
| has_hard_links | Dosya veya dizinin başka adlarla bilinip bilinmediğini alır. |
| is_directory | Girdinin bir dizin olup olmadığını gösteren bir değeri alır. |
| directories | [WimDirectoryEntry](/zip/python-net/aspose.zip.wim/wimdirectoryentry/) türündeki girdileri alır ve dizini oluşturur. |
| files | [WimFileEntry](/zip/python-net/aspose.zip.wim/wimfileentry/) türündeki girdileri alır ve dizini oluşturur. |
| files_and_directories | [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) türündeki girdileri alır ve dizini oluşturur. |
| all_entries | [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) türündeki tüm girdileri alır ve dizini yinelemeli olarak oluşturur. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract_to_directory(destination_directory) | Sağlanan dizine, geçerli dizindeki tüm dosyaları çıkarır. |
