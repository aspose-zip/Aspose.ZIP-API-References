## WimArchive class

Bu sınıf bir wim arşiv dosyasını temsil eder.

WimArchive türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| WimArchive(source_stream, load_options) | Yeni bir [WimArchive](/zip/python-net/aspose.zip.wim/wimarchive/) sınıfı örneği başlatır ve arşivden çıkarılabilecek bir giriş listesi oluşturur. |
| WimArchive(path, load_options) | Yeni bir [WimArchive](/zip/python-net/aspose.zip.wim/wimarchive/) sınıfı örneği başlatır ve arşivden çıkarılabilecek bir giriş listesi oluşturur. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| images | Arşivi oluşturan [WimImage](/zip/python-net/aspose.zip.wim/wimimage/) türündeki girişleri alır. |
| entries | Arşivi oluşturan [WimEntry](/zip/python-net/aspose.zip.wim/wimentry/) türündeki girişleri alır. |
| guid | Arşiv için tanımlayıcı GUID'yi alır. |
| boot_image_index | Önyüklenebilir görüntünün (sıfır tabanlı) dizinini alır. |
| file_format_version | Dosya formatının sürümünü alır. |
| manifest | Dosyayı ve içinde bulunan görüntüleri tanımlayan gömülü manifest'i alır. |
| file_entries | [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) türündeki arşivi oluşturan girişleri alır. |
| biçim | Arşiv biçimini alır. |
