## ArchiveEntryEncrypted class

Şifreleme ile sıkıştırılması veya şifre çözme ile açılması gereken zip girişi.

ArchiveEntryEncrypted türü aşağıdaki üyeleri ortaya çıkar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| compressed_size | Sıkıştırılmış dosyanın boyutunu alır. |
| name | Arşiv içindeki girdinin adını alır. |
| comment | Arşiv içindeki girdinin yorumunu alır. |
| uncompressed_size | Orijinal dosyanın boyutunu alır. |
| modification_time | Son değiştirilme tarih ve saatini alır veya ayarlar. |
| is_directory | Girdinin bir dizin olup olmadığını gösteren bir değeri alır. |
| data_source | Girdi arşive eklendiyse ve çıkarılmadıysa kaynak. |
| compression_settings | Sıkıştırma veya sıkıştırma çözme ayarlarını alır. |
| encryption_settings | Şifreleme veya şifre çözme ayarlarını alır. |
| length | Girdinin uzunluğunu bayt cinsinden alır. |
## Yöntemler

| extract(path) | Girişi sağlanan yol ile dosya sistemine çıkarır. |
| extract(destination) | Girişi sağlanan akıma çıkarır. |
| open(password) | Girdiyi çıkartma için açar ve sıkıştırması çözülmüş içerik akışı sağlar. |
