## XarDirectoryEntry class

xar arşivi içindeki dizin girdisini temsil eder.

XarDirectoryEntry türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| name | Arşiv içindeki girdinin adını alır. |
| full_path | Arşiv içindeki girdinin tam yolunu alır. |
| is_directory | Girdinin bir dizin olup olmadığını gösteren bir değeri alır. |
| parent | Girişin ait olduğu parent dizini alır. |
| creation_time | Dosya veya dizinin oluşturulma zamanını alır. |
| last_access_time | Dosya veya dizinin son erişim zamanını alır. |
| last_write_time | Dosyanın veya dizinin değiştirilme zamanını alır. |
| modification_time | Dosyanın veya dizinin değiştirilme zamanını alır. |
| files_and_directories | Dizini oluşturan [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/) türündeki girdileri alır. |
| directories | Dizini oluşturan [XarDirectoryEntry](/zip/python-net/aspose.zip.xar/xardirectoryentry/) türündeki girdileri alır. |
| files | Dizini oluşturan [XarFileEntry](/zip/python-net/aspose.zip.xar/xarfileentry/) türündeki girdileri alır. |
| all_entries | Dizini yinelemeli olarak oluşturan [XarEntry](/zip/python-net/aspose.zip.xar/xarentry/) türündeki tüm girdileri alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| extract_to_directory(destination_directory) | Sağlanan dizine, geçerli dizindeki tüm dosyaları çıkarır. |
