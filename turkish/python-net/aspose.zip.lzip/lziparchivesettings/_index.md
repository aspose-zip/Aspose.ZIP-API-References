## LzipArchiveSettings class

Sınıf, belirli bir lzip arşivi için ayar içerir.

LzipArchiveSettings türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| LzipArchiveSettings(dictionary_size, max_member_size) | Belirli bir sözlük boyutuyla [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| fastest_speed | [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) sınıfının örneğini alır<br/>            LZMA filtresinde sözlük boyutu 65536 bayt olarak. |
| fast_speed | [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) sınıfının örneğini alır<br/>            LZMA filtresinde sözlük boyutu 1 megabayt olarak. |
| normal | [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) sınıfının örneğini alır<br/>            LZMA filtresinde sözlük boyutu 16 megabayt olarak. |
| high_compression | [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) sınıfının örneğini alır<br/>            LZMA filtresinde sözlük boyutu 32 megabayt olarak. |
| maximum_compression | [LzipArchiveSettings](/zip/python-net/aspose.zip.lzip/lziparchivesettings/) sınıfının örneğini alır<br/>            LZMA filtresinde sözlük boyutu 64 megabayt olarak. |
| dictionary_size | LZMA sıkıştırması tarafından kullanılan sözlüğün boyutunu alır. |
| max_member_size | lzip arşivindeki bir üyenin maksimum boyutunu bayt olarak alır. |
| compression_threads | Sıkıştırma iş parçacığı sayısını alır veya ayarlar. Değer 1'den büyükse çok iş parçacıklı sıkıştırma kullanılacaktır. |
