## LzipArchive class

Bu sınıf bir Lzip arşiv dosyasını temsil eder. Lzip arşivlerini oluşturmak veya çıkarmak için kullanın.

LzipArchive türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| LzipArchive(settings) | [LzipArchive](/zip/python-net/aspose.zip.lzip/lziparchive/) sınıfının yeni bir örneğini başlatır. |
| LzipArchive(source_stream, options) | Açma işlemi için hazırlanmış [LzipArchive](/zip/python-net/aspose.zip.lzip/lziparchive/) sınıfının yeni bir örneğini başlatır. |
| LzipArchive(path, options) | Açma işlemi için hazırlanmış [LzipArchive](/zip/python-net/aspose.zip.lzip/lziparchive/) sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| uncompressed_size | Dosya verisinin sıkıştırılmamış boyutu bayt cinsinden. |
| settings | Belirli bir lzip arşivinin ayarını alır. |
| file_entries | [IArchiveFileEntry](/zip/python-net/aspose.zip/iarchivefileentry/) türündeki arşivi oluşturan girişleri alır. |
| biçim | Arşiv biçimini alır. |
| name | Girdinin adını alır. |
| length | Girdinin uzunluğunu bayt cinsinden alır. |
