Namespace Apple berisi kelas yang mewakili entitas terkait Apple Archive.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [AppleArchive](./applearchive/) | Kelas ini mewakili file Apple Archive (.aar). Gunakan untuk menyusun file Apple Archive. |
| [AppleArchiveEntry](./applearchiveentry/) | Mewakili entri sistem file dalam [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | Pengaturan yang digunakan untuk menyusun entri di dalam [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | Opsi yang digunakan untuk memuat [`AppleArchive`](../aspose.zip.apple/applearchive/) dari file terkompresi. |
| [AppleCompressionSettings](./applecompressionsettings/) | Pengaturan yang diperlukan untuk kompresi entri Apple Archive. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Pengaturan untuk kompresi LZ4 dalam file Apple Archive (.aar). |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Pengaturan untuk kompresi LZFSE dalam file Apple Archive (.aar). |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Pengaturan untuk kompresi LZMA dalam file Apple Archive (.aar). |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Pengaturan untuk penyimpanan (tanpa kompresi) dalam file Apple Archive (.aar). |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Pengaturan untuk kompresi Zlib dalam file Apple Archive (.aar). |
