## AppleArchive.IsSolid property

Mengembalikan nilai yang menunjukkan apakah arsip menggunakan kompresi solid. Dalam mode solid, semua data entri dikompresi sebagai satu aliran dan ekstraksi entri individual tidak tersedia. Gunakan [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/) sebagai gantinya.

public bool IsSolid { get; }
