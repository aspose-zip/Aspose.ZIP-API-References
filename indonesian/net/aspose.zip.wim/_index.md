Namespace Wim berisi kelas yang mewakili entitas terkait arsip WIM.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [WimArchive](./wimarchive/) | Kelas ini mewakili file arsip wim. |
| [WimDirectoryEntry](./wimdirectoryentry/) | Mewakili satu direktori dalam arsip wim. |
| [WimEntry](./wimentry/) | Mewakili satu file atau direktori dalam citra wim. |
| [WimFileEntry](./wimfileentry/) | Mewakili satu file dalam arsip wim. |
| [WimImage](./wimimage/) | Mewakili satu citra dalam arsip wim. |
| [WimLoadOptions](./wimloadoptions/) | Opsi yang digunakan untuk memuat arsip dari file terkompresi. |
