## LzmaArchiveSettings.LiteralContextBits property

Mendapatkan atau mengatur jumlah bit konteks literal.

```csharp
public int LiteralContextBits { get; set; }
```

## Catatan

Bit Konteks Literal menentukan berapa banyak bit paling signifikan dari byte tidak terkompresi sebelumnya yang digunakan untuk memprediksi bit byte literal berikutnya. Harus antara 0 hingga 8.
