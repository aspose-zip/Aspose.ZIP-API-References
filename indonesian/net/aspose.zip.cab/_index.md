Namespace Cab berisi kelas yang mewakili entitas terkait arsip Cab.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [CabArchive](./cabarchive/) | Kelas ini mewakili file arsip CAB. |
| [CabCompressionSettings](./cabcompressionsettings/) | Pengaturan yang diperlukan agar kompresor CAB berfungsi. |
| [CabEntry](./cabentry/) | Mewakili satu file dalam arsip CAB. |
| [CabEntrySettings](./cabentrysettings/) | Pengaturan yang mengontrol cara penulisan entri CAB. |
| [CabLoadOptions](./cabloadoptions/) | Opsi yang digunakan untuk memuat arsip dari file terkompresi. |
| [CabMsZipCompressionSettings](./cabmszipcompressionsettings/) | Pengaturan kompresi yang mengkodekan blok data CAB menggunakan kompresi MSZip (deflate). |
| [CabSaveOptions](./cabsaveoptions/) | Opsi untuk menyimpan arsip CAB. |
| [CabStoreCompressionSettings](./cabstorecompressionsettings/) | Pengaturan kompresi yang menjaga blok data CAB tetap tidak terkompresi. |
