Namespace Rar berisi kelas yang mewakili entitas terkait arsip RAR.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [RarArchive](./rararchive/) | Kelas ini mewakili file arsip RAR. Gunakan untuk mengekstrak arsip RAR. |
| [RarArchiveEntry](./rararchiveentry/) | Mewakili satu berkas dalam arsip. |
| [RarArchiveEntryEncrypted](./rararchiveentryencrypted/) | Entri Zip yang perlu didekompresi dengan dekripsi. |
| [RarArchiveEntryPlain](./rararchiveentryplain/) | Entri Rar yang perlu didekompresi tanpa dekripsi. |
| [RarArchiveLoadOptions](./rararchiveloadoptions/) | Opsi dengan mana [`RarArchive`](../aspose.zip.rar/rararchive/) dimuat dari file terkompresi. |
## Enumerasi

| Enumerasi | Deskripsi |
| --- | --- |
| [RarDictionaryStorageMode](./rardictionarystoragemode/) | Menentukan bagaimana kamus dekompresi RAR disimpan. |
