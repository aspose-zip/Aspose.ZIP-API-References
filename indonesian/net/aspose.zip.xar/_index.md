Namespace Xar berisi kelas yang mewakili entitas terkait arsip Xar.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [CancelEntryEventArgs](./cancelentryeventargs/) | Argumen peristiwa untuk peristiwa terkait entri yang dapat dibatalkan. |
| [EntryEventArgs](./entryeventargs/) | Argumen peristiwa untuk peristiwa terkait entri. |
| [EventsBag](./eventsbag/) | Kontainer peristiwa yang digunakan saat menyimpan [`XarArchive`](../aspose.zip.xar/xararchive/). |
| [XarArchive](./xararchive/) | Kelas ini mewakili file arsip xar. |
| [XarBzip2CompressionSettings](./xarbzip2compressionsettings/) | Pengaturan untuk metode kompresi Bzip2. |
| [XarCompressionSettings](./xarcompressionsettings/) | Pengaturan yang diperlukan agar kompresor berfungsi. |
| [XarDirectoryEntry](./xardirectoryentry/) | Mewakili entri direktori dalam arsip xar. |
| [XarEntry](./xarentry/) | Mewakili satu entri dalam arsip xar. |
| [XarFileEntry](./xarfileentry/) | Mewakili entri file dalam arsip xar. |
| [XarLoadOptions](./xarloadoptions/) | Opsi dengan mana arsip XAR dimuat dari file terkompresi. |
| [XarSaveOptions](./xarsaveoptions/) | Opsi untuk menyimpan arsip xar. |
| [XarStoreCompressionSettings](./xarstorecompressionsettings/) | Pengaturan untuk metode kompresi Store. |
| [XarZlibCompressionSettings](./xarzlibcompressionsettings/) | Pengaturan untuk metode kompresi Zlib. |
