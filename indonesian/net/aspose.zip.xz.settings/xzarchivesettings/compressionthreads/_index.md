## XzArchiveSettings.CompressionThreads property

Mendapatkan atau mengatur jumlah thread kompresi. Jika nilai lebih besar dari 1, kompresi multithreading akan digunakan.

```csharp
public int CompressionThreads { get; set; }
```

### Pengecualian

| exception | kondisi |
| --- | --- |
| ArgumentOutOfRangeException | Jumlah thread lebih dari 100. |

## Catatan

Jangan atur angka ini lebih dari inti CPU.
