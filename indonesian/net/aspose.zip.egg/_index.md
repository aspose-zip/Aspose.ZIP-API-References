Namespace Egg berisi kelas yang mewakili entitas terkait EGG.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [EggArchive](./eggarchive/) | Kelas ini mewakili file arsip EGG. Gunakan untuk mengekstrak arsip EGG. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Opsi dengan mana arsip EGG dimuat dari file terkompresi. |
| [EggEntry](./eggentry/) | Mewakili entri file dalam arsip EGG dengan semua metadata-nya. |
| [EggEntryPlain](./eggentryplain/) | Entri EGG yang dapat didekompresi tanpa dekripsi. |
