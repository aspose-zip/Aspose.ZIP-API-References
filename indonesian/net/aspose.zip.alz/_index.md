Namespace Alz berisi kelas yang mewakili entitas terkait ALZ.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [AlzArchive](./alzarchive/) | Kelas ini mewakili file arsip ALZ. Gunakan untuk mengekstrak arsip alz. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Opsi yang digunakan untuk memuat arsip ALZ dari file terkompresi. |
| [AlzEntry](./alzentry/) | Mewakili entri file dalam arsip ALZ dengan semua metadata-nya. |
| [AlzEntryEncrypted](./alzentryencrypted/) | Entri ALZ yang perlu didekripsi sebelum dekompresi. |
| [AlzEntryPlain](./alzentryplain/) | Entri ALZ yang perlu didekompresi tanpa dekripsi. |
