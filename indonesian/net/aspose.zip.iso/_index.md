Namespace Iso berisi kelas yang mewakili entitas terkait ISO.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Argumen peristiwa untuk peristiwa terkait entri. |
| [EventsBag](./eventsbag/) | Kontainer peristiwa yang digunakan saat menyimpan [`IsoArchive`](../aspose.zip.iso/isoarchive/). |
| [IsoArchive](./isoarchive/) | Mewakili arsip ISO (ISO 9660). |
| [IsoEntry](./isoentry/) | Mewakili entri (berkas atau direktori) dalam arsip ISO. |
| [IsoLoadOptions](./isoloadoptions/) | Opsi yang digunakan untuk memuat [`IsoArchive`](../aspose.zip.iso/isoarchive/) dari file terkompresi. Berisi peristiwa yang dipicu saat ekstraksi. |
| [IsoSaveOptions](./isosaveoptions/) | Opsi untuk menyimpan arsip ISO. |
