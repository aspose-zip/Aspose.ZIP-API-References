## RarArchiveLoadOptions.TemporaryDirectory property

Obtient ou définit le répertoire utilisé pour les fichiers de dictionnaire temporaires.

```csharp
public string TemporaryDirectory { get; set; }
```

## Remarques

La valeur par défaut est GetTempPath. Une valeur `null` ou vide utilise également le répertoire temporaire du système.
