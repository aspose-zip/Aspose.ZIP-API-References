## RarDictionaryStorageMode enumeration

Spécifie comment le dictionnaire de décompression RAR est stocké.

```csharp
public enum RarDictionaryStorageMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| InMemory | `0` | Stocke le dictionnaire dans des segments de mémoire gérée alloués paresseusement. |
| TemporaryFile | `1` | Stocke le dictionnaire dans un fichier temporaire mappé en mémoire. La résidence en mémoire est gérée par le système d'exploitation. |
