L'espace de noms Apple contient des classes qui représentent des entités liées à Apple Archive.

## Classes

| Classe | Description |
| --- | --- |
| [AppleArchive](./applearchive/) | Cette classe représente un fichier Apple Archive (.aar). Utilisez‑la pour composer des fichiers Apple Archive. |
| [AppleArchiveEntry](./applearchiveentry/) | Représente une entrée du système de fichiers dans un [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveEntrySettings](./applearchiveentrysettings/) | Paramètres utilisés pour composer les entrées à l'intérieur de [`AppleArchive`](../aspose.zip.apple/applearchive/). |
| [AppleArchiveLoadOptions](./applearchiveloadoptions/) | Options avec lesquelles [`AppleArchive`](../aspose.zip.apple/applearchive/) est chargé à partir d'un fichier compressé. |
| [AppleCompressionSettings](./applecompressionsettings/) | Paramètres nécessaires pour la compression des entrées d'Apple Archive. |
| [AppleLz4CompressionSettings](./applelz4compressionsettings/) | Paramètres pour la compression LZ4 dans un fichier Apple Archive (.aar). |
| [AppleLzfseCompressionSettings](./applelzfsecompressionsettings/) | Paramètres pour la compression LZFSE dans un fichier Apple Archive (.aar). |
| [AppleLzmaCompressionSettings](./applelzmacompressionsettings/) | Paramètres pour la compression LZMA dans un fichier Apple Archive (.aar). |
| [AppleStoreCompressionSettings](./applestorecompressionsettings/) | Paramètres pour le stockage (sans compression) dans un fichier Apple Archive (.aar). |
| [AppleZlibCompressionSettings](./applezlibcompressionsettings/) | Paramètres pour la compression Zlib dans un fichier Apple Archive (.aar). |
