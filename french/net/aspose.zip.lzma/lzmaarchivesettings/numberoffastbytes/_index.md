## LzmaArchiveSettings.NumberOfFastBytes property

Obtient ou définit le nombre d'octets utilisés pour la recherche de correspondance rapide dans l'algorithme LZMA.

```csharp
public int NumberOfFastBytes { get; set; }
```

## Remarques

Une valeur plus élevée permet au compresseur de rechercher des correspondances plus longues, ce qui peut améliorer légèrement le taux de compression mais ralentit la compression.
