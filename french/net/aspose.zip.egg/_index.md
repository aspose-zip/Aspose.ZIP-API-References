L'espace de noms Egg contient des classes qui représentent des entités liées à EGG.

## Classes

| Classe | Description |
| --- | --- |
| [EggArchive](./eggarchive/) | Cette classe représente un fichier d'archive EGG. Utilisez‑la pour extraire des archives EGG. |
| [EggArchiveLoadOptions](./eggarchiveloadoptions/) | Options avec lesquelles une archive EGG est chargée à partir d'un fichier compressé. |
| [EggEntry](./eggentry/) | Représente une entrée de fichier dans une archive EGG avec toutes ses métadonnées. |
| [EggEntryPlain](./eggentryplain/) | Entrée EGG qui peut être décompressée sans décryptage. |
