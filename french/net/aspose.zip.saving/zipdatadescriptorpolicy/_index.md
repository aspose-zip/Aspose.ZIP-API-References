## ZipDataDescriptorPolicy enumeration

Options pour la présence du Data Descriptor.

```csharp
public enum ZipDataDescriptorPolicy : byte
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Always | `0` | Le Data Descriptor est toujours présent pour toutes les entrées zip. |
| ForAllFileEntries | `1` | Le Data Descriptor est présent uniquement pour les entrées contenant des données de fichier ; il est omis pour les répertoires. L'utilisation de cette option est découragée. |
