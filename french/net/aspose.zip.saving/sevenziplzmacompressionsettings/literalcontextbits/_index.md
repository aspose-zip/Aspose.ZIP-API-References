## SevenZipLZMACompressionSettings.LiteralContextBits property

Obtient le nombre de bits de contexte littéral.

```csharp
public int LiteralContextBits { get; }
```

## Remarques

Les bits de contexte littéral définissent combien des bits les plus significatifs du octet non compressé précédent sont utilisés pour prédire les bits du prochain octet littéral. Doit être compris entre 0 et 8.
