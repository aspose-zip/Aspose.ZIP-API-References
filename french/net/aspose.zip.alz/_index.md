L'espace de noms Alz contient des classes qui représentent des entités liées à ALZ.

## Classes

| Classe | Description |
| --- | --- |
| [AlzArchive](./alzarchive/) | Cette classe représente un fichier d'archive ALZ. Utilisez‑la pour extraire des archives alz. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Options avec lesquelles l'archive ALZ est chargée à partir d'un fichier compressé. |
| [AlzEntry](./alzentry/) | Représente une entrée de fichier dans une archive ALZ avec toutes ses métadonnées. |
| [AlzEntryEncrypted](./alzentryencrypted/) | Entrée ALZ qui doit être décryptée avant la décompression. |
| [AlzEntryPlain](./alzentryplain/) | Entrée ALZ qui doit être décompressée sans décryptage. |
