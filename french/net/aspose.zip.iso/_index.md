L'espace de noms Iso contient des classes qui représentent des entités liées à ISO.

## Classes

| Classe | Description |
| --- | --- |
| [EntryEventArgs](./entryeventargs/) | Arguments d'événement pour les événements liés aux entrées. |
| [EventsBag](./eventsbag/) | Conteneur d'événements utilisé lors de l'enregistrement de [`IsoArchive`](../aspose.zip.iso/isoarchive/). |
| [IsoArchive](./isoarchive/) | Représente une archive ISO (ISO 9660). |
| [IsoEntry](./isoentry/) | Représente une entrée (fichier ou répertoire) dans une archive ISO. |
| [IsoLoadOptions](./isoloadoptions/) | Options avec lesquelles [`IsoArchive`](../aspose.zip.iso/isoarchive/) est chargé depuis un fichier compressé. Contient l'événement déclenché lors de l'extraction. |
| [IsoSaveOptions](./isosaveoptions/) | Options pour enregistrer une archive ISO. |
