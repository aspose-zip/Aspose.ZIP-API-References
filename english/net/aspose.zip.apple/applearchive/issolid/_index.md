## AppleArchive.IsSolid property

Gets a value indicating whether the archive uses solid compression. In solid mode, all entry data is compressed as a single stream and individual entry extraction is not available. Use [`ExtractToDirectory`](../../../aspose.zip/iarchive/extracttodirectory/) instead.
