## RarDictionaryStorageMode enumeration

Specifies how the RAR decompression dictionary is stored.

```csharp
public enum RarDictionaryStorageMode
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| InMemory | `0` | Store the dictionary in lazily allocated managed memory segments. |
| TemporaryFile | `1` | Store the dictionary in a memory-mapped temporary file. Memory residency is managed by the operating system. |
