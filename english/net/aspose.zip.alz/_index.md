The Alz namespace contains classes which represent ALZ related entities.

## Classes

| Class | Description |
| --- | --- |
| [AlzArchive](./alzarchive/) | This class represents an ALZ archive file. Use it to extract alz archives. |
| [AlzArchiveLoadOptions](./alzarchiveloadoptions/) | Options with which ALZ archive is loaded from a compressed file. |
| [AlzEntry](./alzentry/) | Represents a file entry in an ALZ archive with all its metadata. |
| [AlzEntryEncrypted](./alzentryencrypted/) | ALZ entry that needs to be decrypted before decompression. |
| [AlzEntryPlain](./alzentryplain/) | ALZ entry that needs to be decompressed without decryption. |
